폰 러쉬 효과음 · 기물별 소리

두 번째 시안이에요. 이번에는 기물마다 자기 소리가 있어요. 한 벌 안에서는 걸음부터 마지막 쾅까지 같은 재료(같은 물건·같은 악기)로 소리를 이어 가고, 돌진·팽팽한 줄·날아가는 동안에는 소리를 끊지 않고 깔아 두었어요. 동전처럼 짤랑이는 소리는 뺐어요. 각 기물의 A는 퀸 오브 더 힐에서 고른 소리를 그대로 이어요. Unity에는 아직 넣지 않았어요.

  • 재생 버튼 스킬 한 번을 실제 타이밍대로
  • 작은 버튼 그 순간 소리만
  • 장면 그림 지금 이펙트(Unity 녹화 R90)

기물마다 소리 다섯 벌

A = 퀸 오브 더 힐과 같은 소리(폰·퀸·룩 만화, 비숍 묵직, 나이트 8비트를 낮은 음으로). 두 모드에서 같은 기물이 같은 소리를 내요. 듣기 전 추천은 화면 이펙트와 재료가 같은 폰 C 잉크 도장 · 퀸 B 불꽃 · 룩 C 번개 · 비숍 B 마법 줄 · 나이트 C 바람이에요. 기물마다 따로 골라 주세요.

알아 둘 것

  • 저는 소리를 직접 듣지 못했어요. 파형·소리 그림과 "동전 울림 검사"로만 확인했어요.
  • 동전 울림 검사: 1.8 kHz보다 높은 곳에서 가늘고 맑게 0.09초 넘게 울리는 소리를 찾아요. 퀸 오브 더 힐에서 뺀 넘어짐 소리가 이 검사에 걸리는 것을 먼저 확인했어요(첫 시안 R101도 105개 중 23개가 걸렸어요). 이번 소리 중 걸린 것은 다시 만들거나, 같은 벌의 다른 소리로 바꾸거나, 높은 소리를 살짝 깎았어요. 만화 휘슬(룩 A 돌진)처럼 작게 남은 울림도 있어요. 들어 보고 거슬리면 "룩 A 돌진 바꿔"처럼 말해 주세요.
  • 새로 만든 99개 중 19개는 거의 소리가 없거나 높게 울려서 설명을 고쳐 다시 만들었어요. 짧게 한 번 치는 북 소리는 다시 만들어도 계속 거의 무음이라, 같은 북의 긴 소리 앞부분을 잘라 썼어요(폰 E 걸음·밀침, 룩 E 조준 칸·잠금·맞음). 룩 B 조준 칸, 비숍 C 꽂힘, 나이트 D 착지도 같은 벌의 다른 소리 앞부분이에요.
  • 17개는 첫 시안(R101)에서 같은 재료로 만든 소리를 그대로 가져왔어요: 룩 C 번개 전체, 나이트 B 말발굽과 C 바람의 도약·공중·착지·밟기, 퀸 A 전체와 B 예고, 폰 D 밀침.
  • 비교하기 쉽게 모든 소리의 크기를 비슷하게 맞췄어요. 목소리(기합)는 없어요. 장면 그림 일부는 느리게(×0.3) 찍은 녹화예요.
  • 첫 시안(방향 다섯 개를 모든 기물에 똑같이)은 그대로 남아 있어요. 일레븐랩스 작업판 「폰 러쉬 스킬 효과음 기물별 (R105)」에 이번 소리가 있어요(만들 때 붙인 이름이고, 기록 번호는 R107이에요).
