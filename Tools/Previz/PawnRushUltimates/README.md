# 폰 러시 궁극기 프리비즈 — 다시 기획한 12안

2026-11-21 · 사용자: "얻는 방법을 바꾸라는게 아니라, 연출이랑 스킬 기획을 바꾸란 말이였어. 아예 여러가지 다시 기획하고, 영상으로 프리비즈를 먼저 뽑아보자." 그 전 메시지: 2판 궁극기는 "연출이 밋밋 … 별로 강력하지가 않아. 진짜 몇판에 한번만 사용할 수 있는거니까 그만큼 말도 안되게 강력했으면 좋겠어."

**실제 게임 화면이 아니다.** 기물마다 궁극기 두 안을 three.js로 그린 사전 시각화다. Unity는 쓰지 않았고, 효과음은 자막(♪)으로만 적었다. 사용자가 고른 안만 게임에 만든다.

## 그대로인 것

- 얻는 방법: 팀 게이지 (`Docs/Skills/PAWN_RUSH_2_SKILL_PLANS.md` 8.19) — 왕관, 적에게 넘어짐, 시간, 역전 배율.
- Q 칸 하나에 궁극기 하나.

## 공통 연출 (12안 모두)

1. **Q = 모든 화면 1초 컷인.** 세계는 그동안 0.1초만 흐른다. 팀 색 띠가 화면을 가로지르며 기물 그림, 궁극기 이름, 기보(…!!)가 박힌다. 격투 게임의 필살기 컷인 자리.
2. **판 전체 규모의 본 연출.** 거대화, 하늘에서 떨어지는 것, 판이 뒤집히는 것. 맞는 순간 슬로모, 화면 흔들림, 번쩍임.
3. **결과가 한눈에.** 위쪽 순위 막대의 '선두 차'가 한 번에 뒤집히고, 맞은 적 머리 위에 '쾅! · 납작! · 장외!' 딱지.
4. **기보 도장.** e8=Q!!, O-O-O!!, ½–½!! 처럼 체스 팬이 바로 알아보는 표기가 화면에 찍힌다.

온라인에서 1초 컷인은 그림만 멈추고 호스트 물리는 계속 도는 방식(지금 히트 스톱 D-S2와 같은 길)이 될 것 — 고른 뒤 만들 때 정한다.

사용자: "이 궁극기 시전 연출 자체도 여러 방식으로 생각해볼수 있을거같아." 말로 아홉 가지를 내고(필살기 컷인, 체스 시계, 판 밖의 손, 평가 막대, 1초 체스 문제 화면, 흑백 세계, 진짜 모습 각성, 생중계 해설, 선언하고 둔다) 추천 조합을 영상으로 뽑았다: "그래. 너 추천대로 몇개 프리비즈로 뽑아서 보여줘."

## 나이트 — 긴 호흡 (2026-11-21, 여섯 번째)

```
node record.mjs --clips knightFork --out out/knight-fork.mp4 --rate 5000k --profile <빈 폴더>
```

## 영상 뽑기

이 PC 기준 (헤드리스 Edge + Krita에 든 ffmpeg, libopenh264). 프로젝트 루트가 아니라 이 폴더에서:

```
node record.mjs --clips pawnA,pawnB --out out/pawn.mp4 --profile <빈 폴더>
node record.mjs --sheets pawnA,kingB --profile <빈 폴더>      (장면 9장 모음: out/sheets)
```

브라우저로 보기: 이 폴더를 아무 정적 서버로 열고 `index.html?clip=queenA` (스페이스 멈춤, 화살표 넘기기). three.js와 글꼴은 CDN에서 받는다.

## 파일

- `stage.js` — 코스, 기물, 움직임 사슬(달리기 · 날아가기 · 납작 · 석상 …), 이펙트, 카메라, 화면 색.
- `hud.js` — 제목 카드, 컷인, 기보 도장, 딱지, 순위 막대, 팀 게이지, 자막, 끝 카드.
- `ults.js` — 12안의 장면 대본.
- `casts.js` — 시전 연출 비교 (시계, 손, 진짜 모습, 3D 기보).
- `edits.js` — 체스 에디트 문법 (판정 아이콘, 빛나는 칸, 분석 화살표, 기보 목록, 에디트 컷).
- `hero.js` — 3인칭 그대로의 주인공의 순간 (마을 길, 스포트라이트, 유령 말, 전체 음성 · 음악 · 배너).
- `heroedit.js` — 쇼츠 연출을 3인칭 안에서 (판정 색 타일, 월드 !!·??, 박자, 우주, 깨지는 바닥).
- `knightedit.js` — 나이트 패밀리 포크, 긴 호흡 (회색 세상과 네온, 8칸, 포크 선, 붉은 빛, 꽃잎).
- `main.js`, `index.html` — 페이지. `record.mjs` — 프레임을 찍어 mp4로.
