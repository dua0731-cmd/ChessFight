- **임시 결정(2026-11-10 밤): ④ 렌즈+테두리.** 사용자가 잠들어 답을 기다리지 않고 골랐다. 이유: 디자인 눈은 매끈한 광택 검정에 모서리 반사가 있어 ④가 가장 가깝고, ①③은 눈 안에 머리 면 경계 띠가 생긴다. ②와 ④의 차이는 모서리 반사(높이맵 범프)뿐이라, 아침에 ②로 바꾸려면 노멀맵만 빼면 된다.

### 2.7 남은 일
- 게임 적용 상태: 룩·나이트·비숍은 리깅 세션이 넣었다(브랜치 `JY-piece-rig`, 커밋 108fa58f, Unity 확인 전). 눈을 몸통 메쉬에 합쳤고, 색은 면마다 단색 줄 텍스처로 나눴다(`scripts/pieces/game_export.py`). 폰은 몸통 텍스처가 나온 뒤 바꾼다(그때 `strip_old_pawn_face.py`). 그 커밋은 하이라이트 법선을 바꾸기 전 파일로 만들었으니 다시 내보내야 한다.

- 확인되면 표정 메쉬 세트를 만든다(기본 눈에서 `eye_draw.py`의 표정 모양으로).
- 흑팀 전용 메쉬가 필요하면 따로 만든다(흑팀 디자인 눈이 4.5% 작고 조금 낮음).
- 리깅 세션이 붙인 뒤 Unity에서 사용자 확인.
- 몸통이 바뀌면(예: 비숍 최종 모델) `mesh_calib.py`로 다시 맞춘다.
