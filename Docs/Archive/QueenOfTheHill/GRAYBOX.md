# 퀸 오브 더 힐 — 그레이박스 맵 (7차: 7개 층 + 8랭크, R49, 2026-09-27)

[DESIGN §3](DESIGN.md)의 "하늘 궁전"을 **실제 크기의 상자 맵**으로 만든 것이다. 아트는 없다. 목적: **오르는 재미와 시간 확인.**

> **R48 → R49로 바뀐 것.** 사용자가 R48 그레이박스를 Unity에서 보고 "가운데 탑에 층마다 승강기만 있어 단조롭다, 컨셉 아트와 전혀 다르다"고 했다. 요구: **탑은 체스처럼 7개 층, 8번째가 꼭대기(폰이 승격하는 8랭크)**, 층마다 **훨씬 다양하고 복잡한 지형지물**, 오르는 것 자체가 재미있어야 한다. 그래서 맵을 처음부터 다시 짰다(아래). R48의 "탈것 13 m + 벽 5 m" 반복 구조는 버렸다.

**Unity에서 아직 열어 보지 않았다.** 확인 순서는 §4와 [VALIDATION](../../Network/VALIDATION.md) 최상단 표. 미리보기 그림은 Unity 없이 `Tools/QueenHill/preview`로 만든다([Tools/QueenHill/README](../../../Tools/QueenHill/README.md)).

## 1. 여는 법

Unity 위쪽 메뉴 **`ChessFight > Scenes > Queen of the Hill (offline graybox)`** → Play.

- 맵은 **Play를 누를 때 데이터로 만들어진다**(`QueenHillLevel`이 `Assets/Resources/QueenHill/QueenHillLayout.json`을 읽음). 편집 화면에는 안 보인다.
- 맵 데이터는 **`Tools/QueenHill/build_layout.py` 한 곳**에서 만든다. JSON을 손으로 고치지 않는다. 스크립트를 고치고 `python3 Tools/QueenHill/build_layout.py`를 다시 돌린다(`Tools/run-tests-linux.sh`가 JSON이 스크립트와 같은지 검사한다).
- 캐릭터는 래그돌 폰(백팀), 오프라인 1인.

## 2. 조작

| 키 | 동작 |
|---|---|
| WASD · Space · Shift | 이동(카메라 기준) · 점프 · 전력질주 |
| 마우스 | 시점(게임 화면을 한 번 클릭, Esc로 풀림). 휠 = 거리 |
| 좌클릭 / 우클릭 | 밀치기 / 잡기·벽 매달리기(우클릭 꾹 + W = 벽 오르기, Space = 벽 점프). 사슬·그네도 우클릭 |
| **E → 좌클릭 꾹 → 떼기** | 폰의 갈고리(다리 끝에서만) |
| F | 종 치기, 승격 받침대, 앙파상 |
| R / Backspace | 체크포인트로 / 처음부터 |
| **PageUp / PageDown** | 다음 / 이전 랭크로 순간이동 |
| F11 · V | 종 초기화 · 자유 카메라 |

오른쪽 위 = 층별 기록(1~7층), 아래 가운데 = 스테미나.

## 3. 맵 구성 — 체스판을 세운 탑

| 랭크 | 높이 | 무엇 |
|---|---|---|
| 바다·다리 | 0 · +12 m | 백팀은 남쪽, 흑팀은 북쪽 다리에서 시작. 부서진 끝에서 갈고리 |
| **1랭크** | 16 m | 절벽 꼭대기(1층 바닥). 갈고리를 짧게 던지면 여기, **가득 던지면 아치 회랑 지붕(23 m) = 2칸 이동** |
| 2~7랭크 | 36 · 56 · 76 · 96 · 116 · 136 m | 층마다 탑을 두르는 바닥(테라스)과 네 귀퉁이 정원(휴식). 가운데 탑 안에는 빛의 기둥 |
| **8랭크** | 156 m | 정상. **체스 1열처럼 여덟 칸(a8~h8): 룩·나이트·비숍·퀸·킹·비숍·나이트·룩.** 칸의 받침대에서 F = 그 기물로 승격. d8은 퀸 보석판 자리(퀸 규칙은 아직 없음) |

**층마다 두세 갈래 길**(빠르고 위험한 길 / 느리고 안전한 길). 1~3층, 5~6층은 팀마다 자기 쪽(백 남쪽, 흑 북쪽, 똑같은 코스). **4층(판 한가운데)과 7층(마지막)은 두 팀이 같은 구조물을 쓴다.**

| 층 | 이름 | 길 |
|---|---|---|
| 1층 (1→2랭크) | 폭포 테라스 · 대계단 | **대계단**: 세 번 꺾이는 계단, 첫 계단을 가로지르며 미는 돌, 둘째 계단은 가운데가 무너져 뛰어넘기, 계단참은 돌기둥 위 정원 · **아치 회랑**: 기둥 6 m → 지붕 → 탑 7 m → 외나무다리 → 계단참 · 갈고리 2칸이면 회랑 지붕에서 시작 |
| 2층 (2→3랭크) | 사슬 곤돌라 | **체크 큐브 5개**가 사슬에 매달려 번갈아 오르내림(위에 있는 것에서 다음 것으로, 1.5 m씩) → 팔 위를 걸어 3랭크 · **사슬 사다리**: 기둥의 사슬 세 줄, 쉬는 발코니 두 곳, 옆을 지나가는 흔들리는 추 |
| 3층 (3→4랭크) | 떠오르는 석판 · 나이트 · 비숍 | **석판 나선**: 떠 있는 기둥을 도는 석판 12개(1 m씩, 살짝 오르내림) → 기둥 꼭대기 → 벽 7 m → 공중 다리 · **나이트 도약대**: 밟으면 위 6 m + 옆 3 m, 세 번 연속(가장 빠름) · **비숍 레일**: 대각선으로 두 번 움직이는 발판(가장 안전) |
| 4층 (4→5랭크) | 궤도 고리 · 룩의 탑 (공용) | **기울어 도는 체크 고리 두 개**: 반 바퀴 돌면 9 m 위로 실어 준다. 백은 남쪽 부두에서 안쪽 고리 A → 북쪽 탑의 턱 → 벽 9 m, 흑은 북쪽 부두에서 바깥 고리 B → 남쪽 탑. **두 팀이 여기서 서로 반대쪽으로 건너간다**(고리 사이 3 m 점프로 상대 고리에 뛰어들 수도 있음) · **룩의 탑**(네 귀퉁이): 바깥 벽 6.5 m씩 세 번 |
| 5층 (5→6랭크) | 시계 태엽 | **시계 관람차**: 늘 수평인 곤돌라 8개, 아래 부두에서 타고 꼭대기 부두로 · **시계판 오르기**: 20 m 벽, 돌아가는 바늘 두 개를 피하며, 쉬는 턱 두 곳 · **태엽 스프링**: 5초마다 9 m, 11 m 두 번 |
| 6층 (6→7랭크) | 공중 정원 | **섬 잇기**: 오르내리는 섬 두 개 → 폭포 섬 → 사슬 6 m → 그네로 8 m 건너기 → 오르는 섬 · **담쟁이 버팀벽**: 시계탑 꼭대기 턱에서 6~7 m씩 세 번 |
| 7층 (7→8랭크) | 궁전 대발코니 · 빛의 계단 (공용) | **두 갈래 나선 계단**(남·북에서 시작, 1¼바퀴, 가운데 높이를 쓸어내는 팔) · **빛의 계단**: 켜졌다 꺼지는 발판 19칸(물결처럼) → 정상 다리 |

**가운데 탑(코어)**: 층마다 남·북에 문이 있고 안쪽이 빛의 기둥이다. **층 k의 종**(k+1랭크, 코어 안 가운데 통로)을 먼저 친 팀이 **층 k의 빛 승강기**(k랭크 → k+1랭크, 약 6초)를 연다. 20초는 친 팀만, 그 뒤 누구나. 층마다 승강기가 서쪽·동쪽 칸을 번갈아 써서 겹치지 않는다.

**체크포인트**: 2~8랭크 각 층이 체크포인트, 다시 나오는 곳은 코어 안 가운데 통로. 규칙은 M9(내 최고 vs 팀 최고 − 1).

**떨어지면**: 바다 위면 바다가 받고(5초 둥둥), 아래층 구조물 위로 크게 떨어지면(초속 15 m 이상) 물과 같이 체크포인트로(플레이테스트 규칙, [DESIGN §7](DESIGN.md)의 결정 대기).

**신호 색**: 초록 = 휴식, 금 = 움직임, 파랑·금 체크 = 노출, 크림 = 오를 벽, 하늘색 = 열린 길·빛, **루비색 = 맞으면 밀려나는 것**(미는 돌, 흔들리는 추, 시곗바늘, 쓸어내는 팔).

## 4. Unity 확인 순서 (처음 한 번)

1. `ChessFight > Scenes > Queen of the Hill (offline graybox)` → Play. Console에 빨간 오류가 없는지. 오류가 있으면 첫 줄을 AI에게.
2. **V**(자유 카메라, Shift = 빠르게)로 탑을 한 바퀴 둘러본다: 층이 7개, 층마다 구조물이 다른지, 정상의 여덟 칸.
3. V로 돌아와 갈고리: 짧게(절벽 가장자리) / 가득(오른쪽 아치 회랑 지붕 = 2칸 이동).
4. 1층을 두 길로 한 번씩(대계단, 아치 회랑). 오른쪽 위에 1층 시간이 찍힌다.
5. 2랭크 코어 문으로 들어가 가운데 종 앞에서 F → 서쪽 칸에 빛 승강기.
6. PageUp으로 층을 올리며 층마다 길 하나 이상 해 본다. 특히 **4층 궤도 고리**(실려서 올라가는지), **5층 관람차·시곗바늘**, **6층 그네**, **7층 빛의 계단**.
7. 층별 시간과 "막힌 곳·너무 쉬운 곳·재미없는 곳"을 알려 준다. 숫자(간격·높이·속도)는 `build_layout.py`에서 바로 고친다.

## 5. 알고 있는 빈 곳

| 항목 | 상태 |
|---|---|
| 편집 화면에 맵이 안 보임 | Play 중에만 만들어진다. 구조가 확정되면 층별 프리팹으로 옮긴다 |
| 떨어져 아래층에 부딪히면 | 플레이테스트만 "물과 같이" 처리. 경기 규칙은 사용자 결정 대기 |
| 퀸 보석판(d8) | 자리 표시만. 5초 버티기 규칙은 아직 없음 |
| 열리는 길 | 모든 층이 빛의 기둥 승강기. 층마다 다른 열리는 길(사슬 사다리, 캐슬링 도개교 등)은 다음 단계 |
| 미는 돌·추·바늘·팔 | 물리로 민다(래그돌이 밀려 떨어짐). 넘어뜨리는 세기는 래그돌 쪽 조정이 필요할 수 있다 |
| 흑팀 쪽 | 코스는 똑같이 있고 V로 볼 수 있다. 사람은 백팀 하나 |
| 로비에서 이 모드 | 아직 "준비 중"(네트워크 래그돌 M14가 필요) |
| 아트 | 없음. 층별 시간과 재미가 맞은 뒤 이미지 A 방향 모듈로 바꾼다 |
