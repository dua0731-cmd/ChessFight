## 5. 문제 하나씩

### 5-1. 입장 화면의 코스 공개가 실제 판과 다름 — 중간

**사실(로그):** 다섯 판 모두 경기 씬을 켤 때 `[PawnRush] 입장 화면이 공개한 N번 구간 …이 실제 판의 …과 다릅니다: 코스 이름표(Resources/Loading/PawnRushCourse.txt)가 구간 목록보다 오래되었습니다.` 1 ~ 4판은 1번 칸, 5판은 2번 칸. 이 경고는 첫 번째로 틀린 칸만 적고 멈춘다(`PawnRushRound.cs:199 ~ 209`의 `return`) — 그 뒤 칸들도 틀렸을 수 있다.

**사실(저장소):** 입장 화면은 씬을 불러오기 전에 같은 씨앗으로 코스 이름표에서 이름을 뽑는다(R548). 이름표는 구간 목록과 **같은 순서 · 같은 개수**여야 같은 구간을 뽑는다. main의 `Assets/Resources/Loading/PawnRushCourse.txt`에는 `Late_3-2_RoyalObservatory` 줄이 없다 — R727(3e7bc232)은 `PawnRushSections.asset`만 바꾸고 이름표를 다시 만들어 올리지 않았다. 후보 수가 하나 달라 같은 씨앗이라도 뽑는 자리가 밀린다.

**이미 고쳐진 파일이 이 PC에 있다:** 이 PC 편집기가 Play 때 이름표를 다시 썼다(`Editor.log`: "코스 이름표를 다시 썼습니다 … (17개 구간). 저장소에 같이 올려 주세요.") — 그 결과가 지금 커밋 안 된 변경으로 남아 있다(`git diff`: 천문대 줄 한 줄 추가). 이번 R728은 문서만이라 같이 올리지 않았다(§8).

**영향:** 입장 화면에서 보여 준 코스와 실제로 달린 코스가 다름(사용자 화면 확인 전). 게임 진행 · 동기화에는 영향 없음(실제 판은 구간 목록으로 뽑음).

### 5-2. 프로토콜 v59 빌드에 천문대가 들어 있음 — 중간

**§5-1(입장 화면의 코스 공개가 실제와 다름)의 원인 — 천문대 줄이 빠진 것이 아니다.**
- 구간은 칸 순서대로 난수 하나로 하나씩 뽑는다(`PawnRushSections.Choose`). 1번 칸은 맨 먼저 뽑히므로 5번 칸 후보 수(천문대 줄이 있든 없든)와 상관없다 → 1 ~ 4판의 1번 칸 경고는 천문대 줄로 설명되지 않는다.
- Core의 `PawnRushCourseTable.PickNames`를 다섯 판 씨앗으로 직접 돌려 봤다(저장소 밖 임시 프로그램):
  - **빌드에 든 구간 목록:** 후반 칸이 **[왕의 서재, 왕실 천문대]**일 때만 다섯 판이 모두 실제와 같다. main R727 목록(작전실 · 서재 · 천문대)이면 2판 후반 칸이 '국왕 작전실'로 나와 실제(서재)와 다르다.
  - **빌드에 든 이름표:** 1번 칸이 **'왕실 마차뜰' 하나뿐**일 때 다섯 경고(1 ~ 4판 1번 칸 '마차뜰', 5판 2번 칸 '정문 의장 광장')가 모두 맞는다. main 이름표(16줄)든 이 PC에서 다시 쓴 17줄이든 1 ~ 4판 1번 칸은 '왕실 수로 정원'으로 맞게 나온다. 1번 칸이 마차뜰 하나뿐인 이름표는 git 어느 커밋에도 없다.
- → 이 빌드는 main R727도 'R727 작업 도중'(§5-2)도 아니고, **후반 칸에서 작전실을 뺀 시험용 작업 트리**로 뽑은 것이다(v59는 §2의 DLL 문자열대로). 빌드할 때 이름표를 다시 쓰는 코드(`PawnRushCourseTableWriter.OnPreprocessBuild`)가 있는데 낡은 이름표가 남은 까닭은 모른다 — 뽑은 사람에게 물어볼 것.
- main 이름표에 천문대 줄이 없던 것(§5-1 '사실, 저장소')은 맞아서 R729에서 넣었다. 다만 main으로 뽑으면 빌드 때 다시 써지므로 이번 경고의 원인은 아니다.

**§5-3 · §5-4(1판 · 4판을 나간 이유) — 먼저 나간 사람:**
- **1판:** 트레푸스(방 주인 · 물리 담당)가 먼저 "경기에서 나감"(그때 방 인원 4) → 성한(물리 담당이 된 3초 뒤) → jiseong0923 → kerrigancap(물리 담당 2.5초 뒤 나가고 게임을 껐다 켬). 그때 트레푸스와 kerrigancap은 둘 다 정원 보트 건너기에서 막혀 있었다 — 10-4(가).
- **4판:** 나갈 때 찍힌 방 인원이 kerrigancap 3 · 트레푸스 2이고, 트레푸스는 jiseong0923에게 물리 담당을 넘겼다 → 순서는 **성한 → kerrigancap → 트레푸스**. 입장 화면은 또 '왕실 마차뜰'이라 했고 실제는 또 수로 정원이었다. *(추정)* 마차뜰 · 천문대를 보려고 다시 뽑은 것 — 5판에 둘 다 나왔다.
