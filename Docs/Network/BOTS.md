# AI 봇

사용자 요구(R2): 12명 테스트 인원을 구하기 어려우니 파티에 AI 봇을 넣게 해 달라. 구현 `3abe230`. 공개 매치 규칙(M6)은 `01dd655`.

## 1. 정체

봇은 **Steam 계정이 없는 명단 항목**이다.
- 로비에 입장하지 않는다. 예약 정원만 차지한다.
- 경기 호스트가 이동을 계산한다(`BotDirector` → `BotBrain`).
- 봇에게는 절대 패킷을 보내지 않고, 봇에게서 받지도 않는다.
- `BotBrain`은 지점을 골라 걷고 가끔 뛰는 수준이다. **게임 AI가 아니다.**

## 2. ID

`[4비트 태그 0xB][44비트 소유 파티장 ID 하위][12비트 인덱스]` — `Core/BotIdentity.cs`

- 개인 SteamID64는 최상위 니블이 0이라 `0xB` 태그와 절대 겹치지 않는다.
- 소유자가 ID에 들어 있어 파티끼리 충돌하지 않고, 호스트가 "이 봇이 이 파티장 것인가"를 검증한다. 남의 봇을 사칭한 예약은 거절된다.
- **봇 ID는 `BotIdentity`만 만든다.**

## 3. 두 가지 사용법

| | 파티 봇 | 방 채우기 봇 |
|---|---|---|
| 누가 | 파티장, 매칭 전 | 경기 호스트, 시작 전 |
| API | `SetPartyBots(n)` (HUD `-` `+`) | `FillRoomWithBots()` / `ClearRoomBots()` |
| 상한 | 6 - 파티원 수 | 남은 자리 전부 |
| 예약 | `queuedMembers`에 포함되어 채팅 예약 | 호스트 로컬 `ReserveBots` |
| 용도 | PC 2대 × (1인 + 봇 5) = 6v6 | PC 1대로 12인 부하 측정 |

- PC 1대 12인: `+` 다섯 번 → `비공개 방 만들기` → `12명 채우기`.
- PC 2대 6v6: 양쪽 파티 봇 5 → 각자 빠른 매칭 → 예약 12면 자동 시작(개발 빌드).
- 명단에는 `BOT n`으로 보이고, Steam 로비 인원에는 안 보인다.

## 4. 공개 매치 규칙 (M6)

| 빌드 | 공개 매칭에 봇 | 비공개 테스트 방에 봇 |
|---|---|---|
| Editor, 개발 빌드 (`Debug.isDebugBuild`) | 허용 | 허용 |
| 릴리스 빌드 | **금지**: 빠른 매칭 버튼 꺼짐, `FindMatch` 거부, 호스트가 봇 포함 예약 거절(`|bots`), 공개 방 `12명 채우기` 불가 | 허용 |

개발 빌드와 릴리스 빌드는 build 값이 달라(`-dev`) 서로 매칭되지 않으므로 규칙이 섞이지 않는다.

## 5. 한계

- 호스트 한 대가 전부 시뮬레이션한다. 12인 봇 방의 호스트 CPU·대역폭은 미측정.
- Steam 로비 정원(사람)과 우리 예약 정원(사람 + 봇)이 다르다.
- 공개 방을 봇으로 채우면 사람이 못 들어온다(개발 빌드).
