## 실행한 자동 검증

`Tools/Test-NetworkCore.ps1` — 18개 Core + 7개 세션 테스트.

`Tools/Test-NetworkCompile.ps1` — Unity의 .NET Standard 2.1 및 UnityEngine/UnityEditor 어셈블리, Steamworks.NET 공식 소스와 함께 컴파일. 더미 Steam API로 컴파일 통과를 주장하지 않는다. 더미 서비스는 세션 **행동 테스트에서만** 사용한다.

Core 테스트 실행은 게임 엔진에 의존하지 않는다. 세션 모의 서비스는 Steam 이벤트 흐름과 소유권·정원을 재현하지만 실제 백엔드 전파 지연이나 네트워크 전송을 재현하지는 않는다.

## 다음 실기 검증 순서

1. 실제 Unity에서 패키지 자동 설치와 프로젝트 컴파일을 확인하고 생성된 manifest/lock 커밋.
2. 2계정 비공개 테스트: 양방향 이동·점프·늦은 입장·퇴장·재매칭.
3. 파티장/파티원 각각의 취소, 강제 종료, 호스트 종료 후 명단/캡슐 정리.
4. 6인 파티 두 개, 3+3+2+2+1+1 조합, 4+4+4 거절, 부분 입장 실패.
5. 여러 PC에서 동시에 검색하여 방 분산/재시도/통합 여부 확인.
6. 지연·손실 조건과 12인 상태에서 이동 보정·수신 중단·대역폭 측정.
