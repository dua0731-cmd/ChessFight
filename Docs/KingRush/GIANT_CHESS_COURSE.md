# 거인 GM 체스판 통과 코스 — R113

2026-10-26. 사용자 제공 41수 기보를 재생하는 **독립 오프라인 프로토타입**. 기존 타이머 씬은 변경하지 않는다. 두 GM이 기물을 옮기는 거대 체스판을 가로질러 반대편에 도착한다. 온라인/다음 씬 전환은 미연결이다.

## 실행

Unity 메뉴 **ChessFight → Minigames → Open Giant GM Chess Course**, 또는 `Assets/Scenes/GiantChessCourse.unity`를 열고 **Play → Enter**. 지형/기물/12명 래그돌은 Play 때 생성된다.

- WASD: 카메라 기준 이동, Space: 점프, 기존 질주 키 사용. 마우스 좌: 밀치기, 우: 잡기.
- Tab: 12명 중 선택 캐릭터 변경. B: 봇 켜기/끄기. R: 선택 캐릭터 입구 복귀.
- Esc: 기보/봇 진행 정지 및 커서 해제(물리 시뮬레이션 자체는 계속됨). Enter: 진행.
- N: 현재 연출 단계 종료를 앞당김. 수를 건너뛰지 않고 이동→경고→공격→휴식 순서를 유지한다.
- F3: 기보/기물/도착 기록/캐릭터 초기화. 다시 Enter로 시작.
- 양 팀 도착 인원을 HUD에 표시한다. 4인 통과 조건은 이전 제안일 뿐 확정하지 않았으므로 적용하지 않았다. 개인이 출구 선을 넘으면 기록되고 계속 조작 가능하다.

## 공간과 공격

한 칸18m, 판144×144m, 입구/출구 각20m. 기본 이동5m/s 기준 한 칸 약3.6초(질주/물리 영향 제외). 좌우 거인은 단순 메시로 만든 임시 외형이며 이동하는 손/팔로 수를 둔다. 기물5종은 기존 FBX를 공유하되 밑면 폭8.64m로 키우고, 킹은 퀸 모델에 십자가를 붙인 임시 모델이다. 정식 킹/GM 아트는 후속 작업이다.

**Replay Speed 기본8배: 실제 휴식0.25초 → 이동0.375초(착지 칸 표시) → 공격 경고0.625초 → 공격/발광0.0625초**. Inspector의 원래 단계 시간(2/3/5/0.5초)을 배속으로 나눈다. 플레이어/물리 시간은 가속하지 않는다. 방금 놓은 기물 하나의 공격 범위만 발동한다. 이동한 기물 자체의 칸은 범위 공격에서 제외하고 착지 시 별도 피격한다. 공격은 경고 종료 시 해당 칸에 있는 플레이어에게 한 번 적용한다. 높이 -2~25m의 칸 전체를 검사하여 점프만으로 무조건 회피하지 못한다. 힘은 입구 방향24m/s+위9m/s, 기절1.2초(착지1초). 숫자는 조정용 초안이며 실제 비행 거리는 래그돌 중력/충돌에 따라 달라진다. 전선 퍼즐의 폰 방향 예외를 가져오지 않고 **이 기보의 실제 백/흑 폰 방향**을 사용한다.

룩/비숍/퀸은 당시 배치의 첫 기물에서 공격 광선이 막힌다. 첫 기물 칸 자체는 체스의 방어/공격 범위로 포함한다. 나이트는 뛰어넘고 폰/킹도 실제 공격 칸만 표시한다. 안전 경로 보장/기보 변형은 하지 않는다. 실제 기보를 보존하므로 이동시간 대비 피하기 어려운 상황은 warningSeconds를 늘려 시험한다.

캐슬링은 킹 이동 후 룩 위치도 갱신한다(룩은 별도 손 이동/공격 없이 착지 때 위치 변경). 잡힌 기물은 제거한다. 전체82반수를 기본속도로 보면 이론상 약1분47.6초(단계 전환의 프레임 단위 처리로 실제는 조금 더 걸림)다. **코스 통과를 위해 기보 종료를 기다릴 필요는 없다.** 마지막 Rc2# 이후에는 기보가 정지하지만 플레이어가 계속 출구로 이동할 수 있다. 전체 수순을 짧게 압축해 공격 난도를 높이려면 Inspector의 시간을 조정한다.

## Inspector

씬 루트 `Giant GM Chess Crossing`의 `GiantChessCourse`:

| 설정 | 기본 | 용도 |
|---|---|---|
| Replay Speed | 8 | 전체 기보 연출 배속(플레이어/물리 제외) |
| Tile Size | 18 | 한 칸 크기. Stop→Play 필요 |
| Move Seconds | 3 | 들어 옮기는 시간 |
| Warning Seconds | 5 | 착지 후 공격 경고 |
| Rest Seconds | 2 | 공격 사이 휴식 |
| Knockback Speed / Upward Speed | 24 / 9 | 뒤/위 충격 속도 |
| Bots Enabled | true | 선택하지 않은11명의 자동 이동/근접 밀치기 |

봇은 짧은 거리 후보16개를 비교해 전진/기물 회피/위험 칸 회피를 시도하는 시험용이다. 완전한 경로 탐색, 팀 구조 AI, 안전지대 선점 전략은 미구현이다. 플레이어는 기존 잡기/밀치기를 사용하며 별도의 아군 구조 보너스는 아직 없다. 외곽 낙사 시 입구로 복귀한다.

## 90도 회전과 점유 칸 (R112)

입구/출구와 플레이어 진행은 +Z로 유지한다. 체스 좌표를90도 돌려 백 홈랭크는 왼쪽 GM, 흑 홈랭크는 오른쪽 GM 앞에 놓인다. 좌표 변환은 `(rank-3.5, 7-file+0.5)×TileSize`; 위험 판정은 역변환을 사용하므로 SAN/공격 마스크는 원래 기보 그대로다. 기물 방향도 좌우 대국에 맞춰 회전한다.

기물의 충돌 영역은 칸 전체18×18m·높이 최소32m로 확장했다. 금색 테두리가 통행 불가 칸을 표시한다. 기물을 들면 해당 칸 차단/테두리가 해제되고 착지한 칸을 다시 막는다. 포획 대상은 즉시 충돌을 끄고 삭제한다. 착지 칸에 있던 플레이어는 가까운 빈칸(없으면 입구)으로 옮긴 뒤 뒤쪽 충격을 주어 새 충돌체에 끼지 않게 한다. 캐슬링 룩 착지 칸도 예고/탈출 처리한다. 봇의 전방 후보 역시 회전된 체스 좌표로 점유 칸을 피한다. 금색 테두리는 공격 경고와 별개다.

기보82반수 검사는 그대로 통과. 모든64칸의 회전/역변환·백/흑 홈 위치 검사, 구조26·Core108·모의 세션39·런타임7 호환 컴파일 통과. Unity 회전/충돌/실제 속도 재확인 대기.
