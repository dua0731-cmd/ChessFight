# 폰 러시 중반 장애물 · 대계단 현관홀 레벨 디자인 v0.3

Oct 29, 2026 · @성한

## 개요

v0.2부터 대계단 현관홀을 '임페리얼 계단(가운데 대계단이 계단참에서 좌우 두 갈래로 갈라지는 왕궁 계단)' 구조로 다시 짰다. 현관 홀에서 가운데 대계단을 오르는 동안 위에서 석상과 카펫 롤이 굴러떨어지고, 중앙 계단참에서 길이 서쪽·동쪽 날개 계단으로 갈라졌다가, 북쪽 창가 회랑을 지나 홀 가운데의 왕실 단에서 다시 만난다. 마지막은 왕실 발코니와 대문이다.

### 먼저 정할 것

- **시간 목표.** 이 구조는 혼잡을 포함해 약 3분이다. 4분 목표를 지키려면 7절의 손잡이로 약 1분을 늘린다(날개 계단 한 번 더 꺾기, 대계단 3층, 회랑 분사구 추가, 승강 2단). 3분으로 두면 장애물 구간 3개가 약 9분이라 한 판 10\~12분 목표와 맞는다. v0.1에서 짚은 '구간 4분이면 한 판 15분' 문제가 여기서 갈린다.
- **무작위 굴림과 샹들리에 낙하는 새 코드가 필요하다.** 물리로 굴리면 온라인에서 PC마다 위치가 달라지므로, 공유 시계로 위치를 정하는 움직임(판 시드로 정한 시각에 정한 자리)으로 만든다(5절).
- **날개 두 갈래는 똑같다.** 공정성을 위해 장애물·위상을 거울로 맞췄다. 사람이 한쪽으로 몰리면 반대쪽이 빈다는 것이 갈림길의 선택이다.

## 공간 구성

홀은 가운데 축을 따라 남쪽에서 북쪽으로 올라가는 좌우 대칭 공간이다. 가운데 축 위에 대계단, 중앙 계단참, 왕실 단, 왕실 발코니가 차례로 있고, 그 사이를 좌우 날개 계단과 북쪽 회랑이 잇는다. 경로는 위에서 볼 때 겹치지 않는다. 대신 중앙 계단참에서 6 m 위의 왕실 단이, 날개 계단에서 반대쪽 날개의 상대가 보인다.

> 이 배치를 1 m 격자 회색 블록으로 쌓은 [대계단 현관홀 3D 블록아웃 v0.3](https://claude.ai/artifact/KWXmUFNu7UE4rdzLaLWudZ)에서 비트별로 돌려 볼 수 있다. 석상과 카펫 롤이 무작위 레인으로 굴러 내려오고, 중앙 계단참에는 샹들리에가 무작위 자리에 떨어진다. '무작위 다시 뽑기'로 시드를 바꿔 볼 수 있고, 팀 인원을 3대3으로 바꾸면 날개 하나가 쇠살문으로 닫힌다.

### 공간의 순서

1. **현관과 포이어 (y 0):** 남쪽 현관문으로 들어서면 기둥이 두 줄로 선 넓은 포이어. 정면에 폭 16 m 대계단이 보이고, 그 위 중앙 계단참의 왕 석상과 더 위의 왕실 발코니가 한 시선에 들어온다.
2. **대계단 (y 0 → 8):** 아래 계단, 중간 계단참, 위 계단. 굴림 레인 4개를 따라 석상과 카펫 롤이 굴러 내려온다.
3. **중앙 계단참 (y 8):** 홀 한가운데의 넓은 단. 북쪽에 왕 석상이 서 있고, 천장의 샹들리에가 무작위 자리에 떨어진다. 여기서 길이 좌우로 갈라진다.
4. **날개 계단 (y 8 → 14):** 서쪽·동쪽으로 오르는 계단 → 홀 모퉁이의 꺾임 계단참(뒤로 흐르는 카펫) → 북쪽으로 오르는 계단. 계단 위에 샹들리에가 흔들린다.
5. **북쪽 창가 회랑 (y 14):** 북쪽 벽의 높은 창을 따라 홀 가운데로 돌아온다. 창에서 바람이 홀 쪽으로 분다.
6. **왕실 단 (y 14):** 홀 가운데 북쪽, 공중에 뜬 단. 양쪽 회랑에서 들리는 다리로 건너와 두 갈래가 다시 만난다.
7. **왕실 발코니와 대문 (y 14 → 20):** 승강 계단참으로 발코니에 오르고, 근위 나이트를 피해 시계 문(대문)을 지나 다음 미니게임으로.

**좌표 규칙:** 구간 로컬 좌표 (x, y, z), 단위 m. 원점은 현관 입구 문턱 가운데, +z = 북쪽(처음 진행 방향), +x = 동쪽, y = 바닥 윗면. 동쪽 날개는 서쪽 날개의 x 부호만 바꾼 거울이다.

### 난이도 곡선의 원칙

- **세기 순서:** 넘어짐(석상) → 넘어짐(떨어지는 샹들리에) → 미끄러짐(샹들리에·카펫) → 날아감(바람) → 틈(다리) → 넘어짐(기병). 낭떠러지 실패는 비트 4·5 두 곳에만 둔다.
- **새 규칙은 한 번에 하나, 섞기는 뒤에서:** 비트 1·2·4는 한 종류, 비트 3·5·6은 두 종류를 섞는다. 섞을 때는 앞에서 이미 본 장애물만 섞는다(기병은 처음이지만 혼자 나온다).
- **센 장애물 바로 앞에 체크포인트:** 낭떠러지가 있는 회랑과 다리 앞에 체크포인트를 둬서 실패해도 15초 안쪽만 잃는다.
- **5초 안에 읽힌다:** 굴림 레인은 위쪽 굴림 구멍이 0.8초 먼저 빛나고, 떨어질 샹들리에는 바닥의 그림자 원, 흔들리는 샹들리에는 반복 박자, 바람은 경고 0.8초, 다리는 깜빡임, 기병은 착지 예고 원과 돌진 띠로 '언제 가면 되는지'를 보여 준다.

| 종류 | 어디서 | 비용 |
| --- | --- | --- |
| 넘어짐·미끄러짐 | 비트 1, 2, 3, 6 | 1.5\~5초. 계단에서는 몇 계단 아래로 밀린다 |
| 아래층으로 떨어짐 (8 m 이하) | 승강 계단참, 왕실 발코니 남쪽 끝 | 약 6초. 왕실 단으로 떨어져 승강판을 다시 탄다 |

## 비트별 상세

각 비트를 '배치 → 플레이 흐름 → 상대를 방해하는 자리 → 실패와 비용 → 튜닝 손잡이' 순서로 적었다. 좌표는 2절 규칙, 위상은 공유 시계(`ObstacleClock`)에 더하는 초다. 날개(비트 3\~5)는 서쪽만 적고, 동쪽은 x 부호를 바꾼 거울이다.

## 신규 장애물: 무작위 굴림과 샹들리에 낙하

두 장애물 모두 '언제, 어디서'가 매번 다르다. 대신 무작위가 불공정하게 느껴지지 않도록, 피할 곳이 항상 남게 하는 규칙을 함께 둔다.

### 무작위를 온라인에서 맞추는 법

- 판 시작 때 방장이 정한 시드(미니게임 뽑기에 쓰는 판 시드에 구간 번호를 섞은 값)로 정수 난수를 만든다.
- 각 장애물은 이 난수로 '사건 목록'(몇 초에, 어느 레인·어느 자리에, 무엇이)을 처음부터 차례로 만든다. 모든 PC가 같은 시드로 같은 목록을 만들므로, 자리를 따로 보내지 않는다.
- 물체의 위치는 사건 목록과 `ObstacleClock` 시각만으로 계산한다. 물리로 굴리거나 떨어뜨리지 않으므로 PC마다 위치가 어긋나지 않는다. 부딪힘 판정은 다른 장애물처럼 방장만 한다.
- 사람이 물체에 밀리지, 물체가 사람에 밀리지 않는다. 폰이 부딪혀도 석상은 멈추거나 튕기지 않는다.

### 무작위 굴림 (비트 1)

대계단 꼭대기의 굴림 구멍 네 개 중 하나에서 옆으로 누운 폰 석상 또는 말린 카펫이 굴러 나와, 그 레인을 따라 계단 아래 배수구까지 굴러 내려간다.

| 항목 | 값 |
| --- | --- |
| 레인 | 4개, 가운데 x −6 / −2 / 2 / 6, 폭 3.6 m. 계단 폭 16 m를 빈틈없이 덮는다 |
| 경로 | 굴림 구멍 (x, 8, 51.5) → 위 계단 → 중간 계단참 → 아래 계단 → 배수구 (x, 0, 13). 길이 약 38 m |
| 속도 | 경로를 따라 수평 4 m/s. 약 9.5초에 다 내려간다 |
| 생성 간격 | 1.6\~2.6초 사이 무작위 (평균 2.1초. v0.2의 레인 4개 × 8초와 같은 밀도) |
| 레인 | 네 개 중 무작위 (아래 규칙에 걸리면 다시 뽑음) |
| 종류 | 석상 2개 + 카펫 3개를 한 묶음으로 섞어 차례로 꺼낸다. 묶음을 다 쓰면 다시 섞는다. 같은 종류가 길게 이어지지 않는다 |
| 규칙 1 | 같은 레인은 3초 안에 다시 뽑지 않는다 (한 레인에 연달아 몰리지 않게) |
| 규칙 2 | 석상은, 바로 옆 레인에서 1.5초 안에 석상이 나왔다면 그 레인에 나오지 않는다 (옆으로 비킬 자리가 항상 남게) |
| 규칙 3 | 4초 안에 석상은 최대 2개 |
| 큰 것: 폰 석상 | 지름 1.6 m, 길이 2.6 m. 점프로 못 넘는다. 닿으면 10 + 위 3 (넘어짐), 계단 아래 방향 |
| 작은 것: 말린 카펫 | 지름 0.5 m, 길이 3.4 m. 점프로 넘는다. 닿으면 6 + 위 1 (휘청) |
| 경고 | 굴러 나오기 0.8초 전 그 레인의 굴림 구멍이 빛나고 소리가 난다 |
| 겉모습 | 계단 한 단마다 0.15 m 튀며 구르는 것처럼 보이게. 판정 크기는 튀지 않는다 |

**경험.** 외울 수 없으니 매번 구멍과 굴러오는 것을 읽어야 한다. 규칙 2 덕분에 석상이 올 때 옆 레인 둘 중 적어도 하나는 비어 있지만, 그 자리를 노리는 사람이 나 말고도 있다. 그래서 석상이 올 때마다 옆 레인으로 몰리는 밀치기가 일어나고, 이것이 대계단의 우당탕 장면이 된다.

### 샹들리에 낙하 (비트 2)

10 떨어지는 체스 말을 바탕으로, 떨어지는 자리와 시각만 시드로 정하게 바꾼 동작이다.

| 항목 | 값 |
| --- | --- |
| 영역 | 중앙 계단참 x −13\~13, z 54\~65 (가장자리 1 m 안쪽). 왕 석상 자리(x −2\~2, z 61\~65)는 뺀다 |
| 간격 | 0.7\~1.4초 사이 무작위 (평균 약 1초) |
| 자리 | 영역 안 무작위. 아직 끝나지 않은 다른 낙하(경고 중이거나 막 떨어진 것)의 중심에서 6 m 이상 떨어진 곳만. 계단 도착 띠 z 52\~54에는 중심을 두지 않는다 |
| 경고 | 1.2초: 바닥의 그림자 원(반지름 2.5 m)이 점점 진해지고, 천장의 샹들리에가 흔들리며 삐걱거린다 |
| 떨어짐 | 0.4초 만에 바닥까지 |
| 충돌 | 안쪽 원(반지름 2.5 m): 12 + 위 4 (크게 넘어짐). 바깥 고리(2.5\~4.5 m): 7 + 위 2 (휘청) |
| 잔해 | 깨진 조각이 1.5초 동안 남았다가 사라진다. 겉모습만, 부딪힘 없음 |
| 막는 것 | 왕 석상 뒤는 충격파가 닿지 않는다 |

**경험.** 계단참에 서면 그림자 원이 보통 한두 개 진해지고 있다. 원끼리 6 m 이상 떨어져 생기므로 원 사이로 빠져나갈 길은 언제나 있다. 무작위라 한 판 안에서도 지날 때마다 모양이 다르고, 사람이 원 사이 틈으로 몰리면서 밀치기가 생긴다.

### 만드는 법

- `SeededSchedule`: 판 시드 + 구간 번호로 정수 난수(예: mulberry32)를 만들고, 위 규칙대로 사건 목록을 차례로 만든다.
- `RollingSpawner`: 레인 경로, 속도, 생성 간격 범위, 종류 묶음, 규칙 세 개, 종류별 판정 크기와 세기. 물체는 레인마다 두세 개를 미리 만들어 돌려 쓴다.
- `ChandelierRain`: 영역, 간격 범위, 최소 거리, 경고·낙하·잔해 시간, 안쪽 원·바깥 고리 세기. 샹들리에 모델은 서너 개를 돌려 쓴다.
- 모델: 옆으로 누운 폰 석상, 말린 붉은 카펫, 샹들리에, 굴림 구멍과 배수구, 바닥 그림자 원.
- 이 구간의 P0 작업이다. 둘 다 없으면 비트 1·2가 성립하지 않는다.

### Claude Code 제작 지시

- **프리팹 하나:** `Assets/Prefabs/PawnRush/Sections/Mid_2-1_GrandStairHall.prefab`. 2절 좌표 그대로, 원점은 현관 입구 문턱 가운데. 앞뒤 구간과는 입구(z −12, 폭 12)와 출구(미니게임 입구 띠 z 132, 폭 12)로만 잇는다.
- **빌더 메뉴:** `ChessFight/Pawn Rush/Build Mid 2-1 Grand Stair Hall`이 4절 표로 프리팹을 만든다. 다시 실행해도 결과가 같다. 동쪽 날개는 서쪽 날개를 x 거울로 만든다(회전 방향, 컨베이어·바람 방향 포함).
- **재질:** 1 m 격자. 걷는 바닥은 파란 격자, 오를 수 없는 면은 회색 격자 + `NoClimbSurface`, 장애물은 주황, 체크포인트·쉼터는 하늘색.
- **무작위:** `SeededSchedule`, `RollingSpawner`, `ChandelierRain`(5절). 물체 위치는 사건 목록과 `ObstacleClock` 시각으로만 계산하고, 판정은 방장에서.
- **기존 장애물:** 원본 프리팹을 인스턴스로 놓고 6절 표의 값만 바꾼다.
- **인원별 켜기:** 6절 표대로 날개 쇠살문과 승강 계단참 묶음을 켜고 끈다. 3대3·4대4에서 열 날개는 같은 시드로 정한다.
- **리스폰 영역:** 홀 바닥(y −4) 전체.
