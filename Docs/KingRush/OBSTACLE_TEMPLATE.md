## 한 줄 요약

(예: 트랙을 가로질러 도는 막대. 점프로 넘거나 타이밍을 맞춰 지나간다.)

## 플레이어 경험

- 무엇을 요구하는가: 점프 타이밍 / 좌우 회피 / 협동(잡아당기기·밀기) / 경로 선택
- 실패하면: 넘어짐(래그돌) / 밀려남 / 추락 → 체크포인트
- 난이도: ☆☆☆☆☆ (1~5)
- 코스의 어느 구간에 어울리는가: 초반 / 중반 / 후반

## 움직임

| 항목 | 값 | 비고 |
|---|---|---|
| 유형 | Spinner / Oscillator / Pendulum / 새 유형 | 새 유형이면 `Evaluate` 수식을 아래에 |
| 크기 (m) | | 캐릭터 키 약 2m, 점프 높이 약 1.1m(임시)·1.76m(래그돌) |
| 속도·주기 | | |
| 위상 | | 여러 개를 엇박자로 둘 때 |

새 유형이면 **시간 → 위치·회전** 수식:

```text
(예) 높이 = (sin(2π · t / 주기) + 1) / 2 × 최대높이
```

누적(`매 프레임 += 속도`)이 아니라 **시간 t만으로 계산되는 식**이어야 한다.
