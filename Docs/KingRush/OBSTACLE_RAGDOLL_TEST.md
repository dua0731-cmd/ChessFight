# 래그돌 장애물 시험장 — 15종 (R68)

## 실행

1. `main`을 Pull하고 **Unity 6000.3.11f1**로 프로젝트를 연다.
2. **ChessFight → Obstacles → Open Ragdoll Test (15 Obstacles)**를 선택한다.
   씬 파일을 직접 열어도 된다: `Assets/Scenes/ObstacleRagdollTest.unity`.
3. Play 후 Game 화면에서 이동한다. **Tab**으로 장애물 선택 메뉴를 연다.

| 조작 | 기능 |
|---|---|
| WASD / Space / Shift | 이동 / 점프 / 질주 (기존 GameSettings 키 설정 사용) |
| 마우스 / 휠 | 시점 / 줌 |
| 좌클릭 / 우클릭 | 기존 래그돌 태클 / 잡기 |
| R | 현재 시험대의 금색 출발 표식으로 복귀 |
| `[` / `]` | 이전 / 다음 장애물 시험대로 바로 이동 |
| Tab / Esc | 선택 메뉴 열기·닫기, 커서 해제·잠금 |

메뉴에서 15종 중 하나를 누르면 해당 시험대의 안전한 출발점으로 이동한다.
낙사(Y < -6)하면 **현재 시험대**로 자동 복귀한다. 메뉴는 일시정지가 아니며 장애물과 물리는 계속 움직인다.
다른 창에서 돌아오면 메뉴가 열리고, 계속하기를 눌러 조작을 재개한다.

## 씬 구성

5열 × 3행의 독립 시험대. 간격은 X 42m, Z 64m이며 각 시험대 바닥은 24×42m다.
금색 표식이 출발점, 파란 표식이 반대쪽 도착 영역이다. 선택된 장애물의 시험 방법은 화면 왼쪽 위에 표시한다.

| 번호 | 장애물 | 시험 내용 |
|---|---|---|
| 01 | 회전 원판 | 중앙·외곽의 운반, 점프 이탈 |
| 02 | 점프 발판 | 발사, 공중 자세, 넓은 바닥에 착지 |
| 03 | 왕복 밀대 | 통과 타이밍, 측면 넉백 |
| 04 | 회전 해머 | 정면·스침 피격, 회복 |
| 05 | 승강 타일 | 탑승·운반·반대편 이동, 아래 구멍으로 낙하 |
| 06 | 슬라이딩 벽 | 벽 사이 통과·접촉·끼임 확인 |
| 07 | 하중 다리 | 양 끝으로 이동해 기울기·미끄러짐 확인, 아래 구멍 |
| 08 | 컨베이어 | 걷기·점프·착지 시 운반 |
| 09 | 체스 시계 게이트 | 개폐 타이밍·닫히는 문 접촉 |
| 10 | 낙하 체스 기물 | 경고 회피·충격파 점프 |
| 11 | 진자 공 | 통과 타이밍·부위별 피격 |
| 12 | 접이식 다리 | 접힘·탑승·낙하, 이동 방향으로 90° 회전 배치 |
| 13 | 바닥 피스톤 | 중앙·가장자리 발사, 바닥에 샤프트 공간 확보 |
| 14 | 스프링 기둥 | 접근·회피·재진입, 출발점 쪽을 향하게 배치 |
| 15 | 공기 분사구 | 바람 안팎의 걷기·점프·관성, 출발점 쪽으로 분사 |

기존 `Assets/Maps/ImportedChessFight/Prefabs/Obstacles/01~15` 프리팹 인스턴스를 사용한다.
씬의 `15 Obstacle Stations` 아래에서 직접 편집할 수 있다. 시험대 바닥과 복귀 위치도 저장된 일반 오브젝트다.
승강 타일·하중 다리·접이식 다리·피스톤 아래를 바닥으로 막지 않는다.

캐릭터는 기존 `RagdollPawn.prefab`, `RagdollTuning.asset`, `RagdollDriver`, `LabCamera`를 사용한다.
`ObstacleRagdollTest`는 캐릭터 생성·입력·시험대 선택·복귀·안내만 담당한다.
힘과 이동 표면은 기존 ImportedObstacles 어댑터를 통해 적용된다. 공통 캐릭터·장애물 프리팹·튜닝은 수정하지 않았다.
PhysicsProfile은 120Hz/24 solver iterations를 적용하며, 씬 종료 시 물리 설정·중력·커서를 복구한다.

이 씬은 오프라인 작업용이다. 기존 맵, 로비 흐름, Build Settings, Steam 프로토콜은 변경하지 않는다.
앞서 분석한 `BJH_KingRushTest`가 아니라, 래그돌과 장애물 어댑터가 이미 통합된 **`main`**에 추가했다.

## 확인 상태

- Linux: Core **83**, 모의 Steam 세션 **39** 통과. 기존 검사 도구의 경계·장애물 시계·맵 JSON 검사 통과.
- Unity 2021.3 참조 DLL을 사용하는 기존 Roslyn 검사: 새 시험장 런타임을 포함한 **7개 어셈블리** 컴파일 통과. Editor 코드는 이 검사에서 제외된다.
- 씬 정적 검사: **499개 기록·1,353개 참조**, 장애물 15종 각각 1개, 바닥 위 복귀 지점 15개, 바닥으로 막히지 않은 구멍 4곳 확인.
- **Unity import·Play·PhysX·실제 키/마우스 조작은 미확인.** 현재 클라우드에 Unity Editor 및 사용자 PC 연결 도구가 없어 실행하지 못했다. 테스트 통과를 실제 게임 동작 확인으로 해석하지 않는다.
- Unity에서 먼저 캐릭터 생성, 이동·점프, 메뉴 이동, R/낙사 복귀를 확인한 뒤 15종의 발사·피격·발판 운반을 직접 확인한다. 자동으로 장애물 수치나 공통 래그돌 물리를 보정하지 않았다.

## R69 — 원판 회전·점프 높이 조절

Hierarchy에서 시험대 안의 **01_SpinningDisc** 또는 **02_JumpPad** 프리팹 루트를 선택하고 Inspector의 **Spinning Disc** 또는 **Jump Pad**를 편집한다(R70에서 전용 클래스로 분리). 두 값은 private `[SerializeField]`로 저장된다.

- **Diameter**: 원판 지름(m), 기본 **8**, 최소 **0.1**. 바닥·회전 고리·충돌 영역의 가로 크기를 함께 바꾸고 높이는 유지한다. 프리팹 루트 Transform의 Scale은 추가 배율이다.
- **Rotation Direction**: 위에서 보았을 때 **Clockwise**(시계방향, 기본) / **Counterclockwise**(반시계방향).
- **Rotation Speed**: 초당 회전 각도, 0 이상의 값. 기본 **45**, **0**은 정지. 표시되는 원판 고리와 캐릭터 운반에 같은 방향·속도를 쓴다. **Rotors/Size 배열은 제거**되어 원판 개수를 늘리는 설정은 없다(R72).
- **Jump Height**: 발사 위치에서 더 올라갈 목표 높이(m), 기본 **10**. 현재 중력으로 수직 발사 속도를 계산한다. 전방 자동 발사 대신 밟기 전 수평 관성을 유지한다(R73). **Air Move Speed**(기본 6 m/s)는 방향키 입력의 목표 최대 속도, **Air Acceleration**(기본 12 m/s²)은 공중 가속·제동 강도다. 키를 놓으면 관성을 유지하고 반대 키는 제동 후 역방향으로 이동한다. 빠른 진입 속도를 발사 순간 강제로 잘라내지는 않는다.
- 값을 계속 보존하려면 Play를 멈춘 상태에서 편집하고 씬을 저장한다. 프리팹에 Apply하면 기존 이식 맵에도 적용된다. Play 중 편집한 값은 Play 종료 시 복원된다.

원판의 의도적 외향 속도를 없애고 `ISurfaceTransport`로 접지한 이동 기준점에 원형 변위를 적용한다. 몸의 스프링 지연을 매 프레임 외향 이동으로 누적하지 않으며, 피격·얽힘에서는 기존 물리 추종을 허용한다. 공중에서는 원판 운반을 끊고 기존 접선 관성을 유지한다(원 중심에서 점프하면 회전 관성은 0). 다른 발판·컨베이어는 이 경로를 사용하지 않는다. 몸을 고정하거나 관절을 순간이동시키지 않는다.

R69 자동 검사: Core 83·모의 세션 39·7개 런타임 어셈블리 컴파일 통과. **Unity/PhysX 실기는 미확인**: 중앙/외곽에서 30초 서 있기, 양방향 회전, 점프 이탈·재착지, 높이 2/5/10 m를 비교한다. 아주 빠른 회전, 충돌, 넘어진 몸은 물리 반응에 따라 이탈할 수 있다.

## R70 — 15종별 자식 클래스

모두 공통 `Obstacle`을 상속한다. 원판에는 회전 설정, 점프 패드에는 발사 설정, 컨베이어에는 운반 설정만 표시된다. 밀대·해머·벽은 타격 힘도 전용 컴포넌트에서 조절한다. [전체 상속 구조와 15종 Inspector 위치](OBSTACLE_CLASSES.md). 구조 회귀 7개·Core83·모의 세션39·7개 런타임 컴파일 통과, Unity import/Play 재확인 대기.

## R74 — 03·04 속도와 밀치기 설정 (2026-10-11)

Hierarchy에서 **03_ReciprocatingPusher → Moving pusher**, **04_RotatingHammer → Hammer pivot**를 선택한다. Inspector의 각 전용 컴포넌트에 private SerializeField로 다음 값이 표시된다.

- 03 **Move Speed**: 왕복 중 최고 이동 속도(m/s). 끝에서는 감속하고 중앙에서 가장 빠른 기존 사인 왕복이다. 기본 약 7.07 m/s로 이전 Distance 4.5 m·Period 4초를 유지한다. Distance는 중심에서 끝까지의 거리이며 왕복 시간은 2π × Distance / Move Speed다. 0은 이동 정지(Phase 위치).
- 04 **Rotation Speed**: 회전 속도(°/초), 기본 70. 0 정지, 음수 역회전.
- 두 장애물 **Push Force**: 충돌 시 추가 수평 속도(m/s), 03 기본 9, 04 기본 12. 커질수록 세게 밀며 이동/회전 속도와 독립이다. **Lift**는 위로 튀는 정도, **Hit Cooldown**은 연속 타격 간격이다. Push Force 0에서도 Lift와 콜라이더 물리 반응은 남는다.

기존 프리팹·이식 맵 직렬화 값은 새 이름으로 이전했다. 기존 이름은 FormerlySerializedAs로 보존하며 예전 Period는 숨겨진 legacyPeriod에서 Awake/OnValidate 때 속도로 환산한다. 이동은 ObstacleClock 시간의 순수 함수로 유지한다. 구조12·Core83·세션39·7개 런타임 컴파일 통과. Unity/PhysX 실기는 미확인.
