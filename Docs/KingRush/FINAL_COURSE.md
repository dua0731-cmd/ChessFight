# R56 · 왕의 계단 / 체크메이트 결승

2026-09-27, `JY-kingrush`. 사용자는 R55 직접 테스트는 나중에 하고 다음 단계를 진행하도록 요청했다. **R55/R56 사용자 확인은 대기**다. 기획 §7.3/§8.3의 1차 안으로 세 번째 코스와 결승을 연결하며, 상용 완성/온라인 완료가 아니다.

## 실행

같은 프로젝트에서 **ChessFight → King Rush → Open Opening Course → Play**. 시소의 다음 문을 지나면 왕의 계단이다. 기존 씬/프리팹18개를 재생성하지 않고6개 구간을 추가했다. 총24개 구간 프리팹, 개인 체크포인트16개, 승격 발판9개(2/3/4), 집결벽3개.

- **F8**: 왕의 계단 입구에12명 배치. **Shift+F8**: 결승에12명 배치하고 백팀 킹 조종. 시험용 정지 더미이며 AI가 아니다.
- **F2** 백팀 킹 / **Shift+F2** 흑팀 킹. Tab 다음 말.
- **F7**: 현재 빨강 끝의 실제 승격→10초→양 팀 미도착자 집결 시험. 마지막은 퀸/룩/비숍/나이트4자리다.
- F3 전체 초기화, F6 다음 체크포인트, R 현재 구간 복귀. **결승 R도5초 재진입 대기**이며 초읽기에는 탈락한다. 대기/탈락 중 R로 우회할 수 없다.
- Esc 안내, Esc 상태에서 Backspace 로비. 로비의 KingRush 선택은 아직 이전 캡슐 버전이다.

## 왕의 계단 블록아웃

높이3m인 시소 출구에서40m까지 올라간다. z442~654, 최종 아트가 아닌 연결 경로다. 기존 이동/점프/등반/질주/태클/잡기·물리 튜닝은 그대로다.

1. **폭0.8m 외나무 지름길**: 왼쪽,84m 직선 오르막/높이18m. 시간 함수 횡풍이 몸을 옆으로 민다.
2. **긴 계단**: 오른쪽, 사각 탑을 한 바퀴 돌아 올라가는4개 계단과 위쪽 통로. 넓이4m, 시각 단차0.25m. 첫 시험에서 계단 모서리에 래그돌이 걸려 **실제 보행 충돌면은 연속 경사**로 다듬었다. 빠른 길보다 길다. 회전 발판 바깥에는 넘어져 미끄러지는 몸을 받는1m 난간, 위쪽 통로에는 낮은 난간.
3. **무너졌다 돌아오는 칸**: 4×8칸, 칸당3m. 1초 붉게 흔들린 뒤 떨어지고4초 뒤 돌아온다. 두 열씩 반대 위상, 전진하는 파형을 따라 건너도록 배치했다.
4. **거대한 손**: 1.5초 그림자 예고 뒤2초 동안 가로로 쓴다. 실제 충돌/넉다운. 대기 구간과 마지막 계단으로 이어진다.
5. **마지막 계단**: 높이21→40m,76개 단차. 위의4자리 승격이 정해지면 기존과 같은10초 집결 후 결승 문이 열린다.

빨강 낙하는 기존 물5초/개인 체크포인트 복귀다. 기획의 낙하 비용15~20초·전체10~13분은 아직 측정된 밸런스가 아니다. 장애물은 `ObstacleClock`의 함수이며 돌아오는 물체의 순간 복귀 중 충돌을 잠깐 끈다. 공통 물리 보정으로 통과시키지 않는다.

## 결승 규칙

- 높이40m의24×24m(8×8) 체스판, 높이1m의6×6m 단상, 가운데 왕좌 표시/등받이. 외곽 탑 섬4개.
- **T0 = 두 킹이 실제 판에 올라온 시각과 첫 킹 도착+25초 중 빠른 때**. 집결이나 일반 폰 입장만으로 시작하지 않는다.
- 킹 골반이 왕좌 안에 있고, 지면에 서 있으며 잡힘/비행/물/넉다운 상태가 아니면 왕좌를 점유한다. 한 번에 한 킹만 점유한다. 둘이 동시에 들어와 기존 점유자가 없으면 한 명만 남을 때까지 점유를 보류한다.
- 적의 몸이 단상 바닥부터3m 높이 공간 안에 하나라도 있으면 게이지가 멈춘다. 기존 `CountsAsBody`(물·잡힘·대포 비행 제외)를 사용한다. **미구현 승천/매달림/탑승 능력까지 구현했다고 보지 않는다.**
- 깨끗한 단상에서 점유한 시간을 **누적8초** 채우면 승리. 왕좌를 빼앗겨도 이미 모은 시간은 줄지 않는다. 왕좌에서 E 체크! 사용 가능. 왕을 고정 관절/무적으로 붙이지 않으므로 물리로 밀어낼 수 있다.
- 현재 왕좌 점유는 위치 판정이다. 세밀한 앉는 애니메이션·킹 외형은 후속이다.

### 붕괴 / 재진입 / 종료

| T0 이후 | 상태 |
|---|---|
| 47초 | 흰 칸30개가 붉게3초 경고(단상 아래2흰 칸 제외) |
| 50초 | 흰 칸 붕괴. 검은 칸30개+단상 아래4칸 유지 |
| 97/100초 | 바깥 두 줄의 검은 칸 경고/붕괴. 안쪽 검은6칸+단상 |
| 137/140초 | 나머지 칸 경고/붕괴. 진입 계단/연결 통로도 제거, 단상만 유지 |
| 140초~ | 재진입 종료. 게이지2배, 킹 추락 즉시 패배 |
| 180초 | 남은 누적 게이지가 큰 팀 승리 |

단상은 영구 바닥이다. 붕괴 자세/판정은 T0로 계산하고 한 칸에 여러 신체가 닿아도 추가 득점이 없다. 추락 판정은 결승 몸 높이32m 미만(판보다8m 아래)이다.

140초 전 추락하면5초 뒤 탑 섬에서 **비행 중에도 살아 있을 칸**을 향해 기존 모드 발사 보조로 날린다. 이미 무너졌거나6초 안에 사라질 칸은 목표로 잡지 않는다. R도 같은 비용. 140초를 넘긴 대기자는 재진입하지 못하며, 킹이면 패배한다. 같은 물리 스텝에 두 킹이 떨어지거나180초 동률이면 **시험용 무승부**(원문에 없는 경계 처리, 최종 밸런스 결정 아님).

경기 종료는 한 번 확정되고 이후 바뀌지 않는다. 결과 문구/승리 킹 왕관/패배 킹 쓰러짐, 입력 잠금, F3 재시작과 로비 돌아가기를 제공한다. 공유 `Time.timeScale`을 바꾸지 않는다. 음악/바람·심장 음향/0.5초 시각 슬로모션은 이번에 구현하지 않았다.

## 구조와 남은 일

`KingRushFinalRules`(Unity 없는 규칙) → `KingRushFinalBoard`(타일/왕좌/재진입 목표) → `KingRushOpening.Final`(기존 래그돌 연결). `KingRushSkyMotion`은 시간 함수 장애물이다. Steam·KR1/CFR4/CFS3·다른 모드 변경 없음. 킹 체크! 원만 현재 발밑 높이를 따라가게 해 공중 경기장에서도 예고가 보인다.

다음은 사용자 플레이 후 길이/시야/난이도/목표 가독성 수정. 남은 능력4개, 실제 밧줄, 외형/음향/결승 자세, 온라인 연결은 별도 작업이다. 전체 모드 완성이라고 표시하지 않는다.

## 자동 검사

Core **62개**·모의 세션 **20개**, 실제 Unity DLL 전 어셈블리 컴파일, 참조 경계 검사 통과. 사용자 플레이 확인을 대신하지 않는다.

- Windows 빌드6: **결승 먼저→계단→마지막 집결29/0**. 처음 계단 회전부에서 넘어져 추락하던 경로가 실제로 난간에 멈추고 일어나 통과함을 위치/상태 기록으로 확인했다.
- Windows 빌드4: 기존 장난감/상자·집결·성벽/시소 전체 **68/0**. 새 결승 검사는 별도 실행이므로 이68개를 전체 모드 완성이라고 읽지 않는다.
- 최종 Windows 빌드7: **계단→마지막 집결→결승29/0**, 이어 실행한 기존 기능 시험장 **80/0**.1280×720, 추가 이동 캡처/기록 없이 실제 입력 통과를 재검사했다. 임시 자산 수정 메서드를 제거했고 결과/재진입 안내와 한글 HUD 렌더를 확인했다. 빌드/실행 예외 없음. 로그 `Logs/kingrush-r56-build-7.log`, `Logs/kingrush-r56-final-7.log`; 캡처 `Logs/R56`(Git 제외).

자동 실행 옵션: `-kingRushOpeningTest -kingRushFinalOnly`(계단→집결→결승), 여기에 `-kingRushFinalFirst`로 순서 변경, `-kingRushTest`로 기존 기능80개 이어 실행. `-kingRushSkyOnly`는 계단만, `-kingRushWalkTrace`는 이동 중 위치/상태 기록. 옵션 없이 실행하면 평소 플레이이며 텔레포트 시험 배치는 통과 근거로 세지 않는다.
