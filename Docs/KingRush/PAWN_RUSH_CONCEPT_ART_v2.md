# 폰 러시 · 4분 장애물 코스 컨셉아트 v2

작성일: 2026-10-28 · 최종 정리: 2026-10-29

기존 15개 장소를 **6대6, 실패·재시도를 포함한 평균 약4분**의 장애물 코스로 다시 구성한다. 장소마다 한두 장애물만 보여 주던 장면에서, 여섯 구간이 이어지고 마지막에 미니게임이 보이는 전체 코스 컨셉으로 확장한다. 사용자가 제공한 「폰 러쉬 장애물 목록」의 동작과 제한을 우선한다.

이 문서는 아트와 레벨 설계안이다. 프로젝트 코드를 확인하거나 Unity에서 12인 플레이를 실행하지 않았으므로, 아래의 시간·용량·원활한 네트워크 동작은 검증 결과가 아니다. 기존 원본 아트와 프리팹을 수정하지 않는다.

## 4분의 의미와 길이

사용자 확인: **실패·재시도를 포함한 일반 플레이어의 평균 약4분**이다. 처음에는 12인 테스트의 평균을 3분30초~4분30초 범위에 맞추고, 중앙값·느린 플레이어·실패 횟수도 함께 본다. 더 잘하는 플레이어가 짧게 통과하는 것은 허용한다.

| 시간 예산 | 제안값 | 뜻 |
| --- | ---: | --- |
| 기본 이동 | 120초 | 장치와 재시도가 없을 때 실제 경로를 이동하는 시간 |
| 장치 대응·등반·자연 대기 | 65초 | 기본 이동 시간에 추가되는 시간만 계산 |
| 실패·일어나기·국소 재시도 | 40초 | 체크포인트부터 다시 시도하는 손실 |
| 미니게임 경계 읽기 | 15초 | 안전 테라스에서 장치와 진입 방향을 파악하고 내려가는 시간 |
| 합계 | **240초** | 첫 테스트의 설계 예산, 확정 플레이 시간 아님 |

문서에 적힌 현재 달리기/질주는 **2.5/3.6m/s**다. 사용자 표현인 ‘폴가이즈보다 약간 빠름’을 특정m/s로 환산할 근거는 없다. 따라서 그림의 길이는 확정하지 않고 다음 식으로 조절한다.

**기준 경로 길이 L ≈ 장애물 없는 같은 경로에서 측정한 이동 평균속도 ×120초.** 질주와 스테미나, 회전·코너를 포함한 실제 이동 평균을 쓴다. 장애물 대기나 재시도를 넣어 측정하면 위 예산과 중복된다.

| 이동 평균의 예시 | 같은 이동 예산에 필요한 경로 | 해석 |
| ---: | ---: | --- |
| 2.5m/s | 300m | 문서의 달리기 속도만 사용하는 단순 예시 |
| 3.0m/s | 360m | 실제 이동 평균이 이 값으로 측정되는 경우 |
| 4.5m/s | 540m | 향후 더 빠른 설정을 쓴다는 가정 |
| 6.0m/s | 720m | 더 빠른 설정에 대한 민감도 예시 |

이 표는 폴가이즈 속도에 대한 주장이 아니다. 현재 코스01의398m를 장소마다 그대로 복사하면4분이 보장되지 않는다. 속도가 달라지면 연결 구간과 장면 간 거리를 조정하고, 기본 점프 틈·장치 충돌 크기까지 함께 확대하지 않는다.

## 여섯 구간의 공통 리듬

| 구간 | 누적 목표 시간 | 경험 |
| --- | --- | --- |
| 1 | 0:00–0:35 | 장소와 대표 규칙을 읽는 넓은 진입 |
| 2 | 0:35–1:15 | 같은 규칙의 엇박자·방향 변형, 이후 안전 체크포인트 |
| 3 | 1:15–2:00 | 높이 변화와 이동 발판, 넓은 착지 |
| 4 | 2:00–2:40 | 장소의 대표 장치, 이후 안전 체크포인트 |
| 5 | 2:40–3:25 | 앞에서 배운 규칙 두 가지의 조합, 회복 공간 확보 |
| 6 | 3:25–4:00 | 마지막 짧은 도전 → 안전 동선 → 미니게임 조망 |

각 시간은 설계 예산이다. 정해진 시간 동안 플레이어를 문 앞에서 기다리게 하지 않는다. 31.2초 주기의 캐슬링 다리나13.5초 주기의 들리는 다리를 연속 배치해 시간을 채우지 않는다.

장소별 장치 수량은 콘텐츠 분량을 가늠하는 초안이며 네트워크 처리 용량의 보장치가 아니다. 같은 기능도 입구의 단순한 상황, 엇박자 변형, 마지막 조합으로 다른 경험을 만든다.

## 이번 구성의 장치 선택

문서상 재료는22종이다. 코스에 쓰인11종, 아직 코스에 쓰지 않은 온라인 대응8종, 오프라인 전용3종으로 나뉜다. 출발 막대는 판 시작에 한 번만 쓰고 각 장소마다3초 대기를 반복하지 않는다.

| 분류 | 사용 방식 |
| --- | --- |
| 기존 사용 장치 | 낮은 회전 점프봉, 표면 회전 원판01, 미닫이벽06, 원형 회전 체스판, 낙하기물10, 진자11, 조정된 점핑발판02, 시계문09, 룩벽, 해머04를 재배치 |
| 온라인 대응 표기·코스 미사용 | 밀대03, 승강타일05, 컨베이어08, 들리는다리12, 바람15, 나이트17, 캐슬링다리18을 장소별로 선택. 온라인 대응 표기는12인 실측 완료를 뜻하지 않음 |
| 제한적으로 검토 | 피스톤13은 기본 위18m/s 발사가 지나치게 강하므로 이번 필수 구간은 승강타일05 또는 조정된02로 대체하는 것을 우선 |
| 현재 제외 | 무게다리07·스프링기둥14·금가는대리석16. 플레이어 상태에 반응하는 현재 오프라인 전용 장치 |

새 제안은 주로 **기존 동작에 장소별 외형과 조합을 입히는 방식**이다. 예를 들어 왕궁 주방의 밀대는03, 보물 잠금 셔터는09, 왕의 망토는11의 지정된 진자 움직임을 사용한다. 천·사슬·물·금화는 장식 표현이며 실제 다중 관절·유체·동적 파편 시뮬레이션을 요구하지 않는다. 이러한 새 외형은 프로젝트에 이미 구현됐다는 뜻이 아니다.

## 앞선 그림에서 바로잡는 점

- **밀대03:** 높이1.6m라 기본 점프로 넘지 못한다. 밀대가 빠져나간 시간창으로 달리는 장면을 그린다.
- **원판01:** 원판 자체보다 표면 속도가 폰을 돌리고 밀어낸다. 실제 회전판이 필요하면20초 주기의 코스 원형 회전 체스판과 구분한다.
- **들리는다리12:** 판 안쪽 끝이 위로 들린다. 바닥 아래로 접히는 함정처럼 표현하지 않는다.
- **승강타일05:** 낮을 때 타고 올라간다. 폰이3m 단을 기본 점프로 뛰어넘지 않는다.
- **점핑발판02:** 현재 코스의 위9/앞4.5m/s는 조정의 출발점이다. 새로운 이동 속도에서 착지 지점을 재측정한다. 발판을 병렬로 두고 착지 공간을 넓혀12명 진입을 분산한다.
- **접시 덮개·금화 단:** 무조건 강하게 발사하는 피스톤 대신 승강타일 외형을 우선한다.
- **낙하기물10:** 예고 원과 단순한 충격파 판정을 활용하고, 엄폐물이 충격파를 막는 성질을 조합한다.
- 기본 필수 틈은현재 검증기 기준1.5m이하, 점프턱은보수적으로0.6m이하를 유지한다. 속도가 빨라졌다는 이유로 검증 없이 점프 간격을 늘리지 않는다.

## 6대6 동선과 네트워크 전제

1. **장치 위치는 공유 시계 기준.** 기존 `ObstacleClock`과 시작시각·주기·위상을 재사용한다. 플레이어가 다가올 때마다 각PC가 독립적으로 새 움직임을 시작하는 방식을 추가하지 않는다.
2. **장애물 힘은 방장 기준.** 문서의 방장 힘 계산을 유지하고, 시각 효과와 실제 타격 판정을 분리한다. 물리 충돌만 사용하는 회전봉·룩벽은 힘 스크립트 장치와 판정 경로가 다르므로 함께 확인한다.
3. **평탄한 양옆 우회로를 만들지 않는다.** 주동선은권장8–12m, 입출구12m. 두 갈래를 쓸 때도 양쪽 모두 같은 구간의 장치를 통과하고 바로 합류한다. 조형물 바깥길로 위험 전체를 건너뛰지 않는다.
4. **줄서기와 연속 타격을 줄인다.** 문 앞과 착지대는 넓게 두고, 강한 장치 뒤에는 최소1초 이상의 회복 여유를 속도에 맞춰 확보한다. 이를 고정1m 간격으로 오해하지 않는다.
5. **재시도는 가까운 곳에서.** 구간2·4뒤와 마지막 테라스에 안전 체크포인트를 제안한다. 낙하 범위가 다음 체크포인트나 미니게임 밑으로 침범하지 않게 한다.
6. **움직이는 장치에 매달릴 수 있는지 확인한다.** 문서상 아직 못오름 표시가 없는 경우가 있으므로 의도한 등반면 외에는 `NoClimbSurface` 적용을 검토한다. 난간 그림만으로 우회 차단을 보장하지 않는다.
7. **효과의 복잡도를 제한한다.** 거대한 밀대·해머·진자는 단순 충돌체와 정해진 궤적으로 다룬다. 증기·거품·천·사슬·파편은 시각 효과로 처리하는 제안이다. 화면 밖 효과를 줄이더라도 각PC가 임의로 게임 판정을 끄는 방식으로 만들지 않는다.

## 미니게임으로 이어지는 경계

**마지막 장치 → 넉백 없는 정리 동선 → 안전 테라스와 체크포인트 → 열린 아치 → 넓은4단 계단 → 미니게임 입구 띠**의 순서를 모든 코스에서 공유한다.

| 요소 | 제안 규격과 역할 |
| --- | --- |
| 정리 동선 | 마지막 강한 장치 뒤12–18m를 우선 확보. 기존 최소6m보다 넓힌 새 제안이며 최종 속도·넉백 궤적으로 검증 |
| 착지 테라스 | 폭12m×깊이6m. 미니게임보다1m높음. 장애물 없고 체크포인트 배치 |
| 열린 아치 | 안쪽폭12m·높이5m이상. 여닫는 문 없음. 랭크3/5/7표시는 이 위치 |
| 계단 | 0.25m×4단 하강. 전폭에 가깝게 넓은 진입 |
| 입구 띠 | 깊이4m. 팀 스테이션 방향에 승격 발판·작은 팀색 깃발 |
| 광장 | 기존44×25m, 양쪽20×20m스테이션과가운데4m통로라는 문서규격을 유지할 계획. 실제 치수 정합은 구현에서 확인 |

강한 넉백을 광장 방향으로 쏘는 배치를 피하고, 물·낭떠러지 리스폰 영역이 경계 밑까지 이어지지 않게 분리한다. 관문 아치 앞 마지막6m안에는 어떤 장애물도 두지 않는다. 테라스는 코스의 소품, 아치 안쪽은 뽑힌 미니게임의 교체 가능한 소품을 쓴다. 그림의 다음 광장은 구체적인 게임을 고정하지 않는 연결 예시다.

초반은 돌·화분, 중반은 나무 판벽·등불, 후반은 대리석·묶은 보라 벨벳으로 경계를 구별한다. 팀색은 아치나 테라스 장식에 쓰지 않고 스테이션 소유 표시로 한정한다. 미니게임 반대편 큰 중앙문은 장식이고 팀 출구는 좌우문이라는 기존 구조와, 지금 진입하는 열린 아치를 혼동하지 않는다.

## 다음 제작 검증

먼저 한 장소를 회색 블록으로 만들고, 실제12명으로 정상 환경과 목표 지연·손실 조건에서 비교한다. 구체적인 지연 수치와 합격 성능 기준은 프로젝트 목표 장치·서버 방식이 확인된 뒤 정한다.

- 구간별 평균/중앙값/느린 플레이어 통과시간, 실패 횟수, 체크포인트 재시도 길이
- 문·점핑발판·착지대 앞의 대기열,12명이 동시에 들어올 때 진입 분산
- 방장과 참가자에게 보이는 장치 위상, 타격/발사 중복·누락, 이동 발판 위 보정 튐
- 방장의 프레임·물리 처리시간과 네트워크 사용량, 현재 성능 기준 대비 증가
- 낙하영역 경계, 미니게임 진입 중 충격·리스폰 침범, 등반 우회

**한 판 전체 시간도 달라진다.** 장애물3곳×4분 +기존 미니게임3곳×30초~1분 +마지막 접근·결승 약1분이면 약14.5~16분이다. 이전10~12분 목표와 동시에 고정할 수 없으므로 이번 안은 사용자가 새로 지정한 구간당4분을 우선한다.
