# 장애물 기획서 — 장난감 상자 R54

첫 코스의 원형 장애물 묶음. 기획안 §7.1의 임시 수치이며 사용자 난이도/손맛 확인 전이다.

| 장애물 | 요구 동작 / 실패 | 크기·속도·위상 | 시간 함수 |
|---|---|---|---|
| 팽이 폰 | 빈틈 선택 / 밀림, 일반 물리 충격은 남음 | 높이2.75m, 반경2m 원,7초/회전,4개 | 중심+(sin,0,cos)×2, yaw=360t/7 |
| 폰 머리 | 약15° 경사에서 레인 변경 / 넉다운 | 지름2.4m,3레인,주기8초,위상0/2.4/4.8초 | 65% 동안22m 내리막;7% 아래로,21% 코스 아래 복귀,7% 위로. 회전=−1080t/8 |
| 체스 시계 | 점프/발판 타이밍 / 물에5초 부유 후 체크포인트 | 두 판16×7.5m,틈0.5m,주기3초,위상0/1.5초 | y=배치높이+0.4cos(2πt/3)−0.25 |
| 도약대 연못 | 노란 발판 밟기 / 물 부활 | 유효면8×2.5m,15m 전방 착지,높은 쪽 위4m 정점 | 기존 LaunchPad의 중력 포물선 |

- 세 이동 유형 모두 `KingRushToyMotion : Obstacle`, `Evaluate`는 누적 없는 시간 함수. 프리팹은 `Assets/Prefabs/KingRushOpening/02_...`, `03_...`, `05_...`.
- 머리만 `RagdollHazard(minImpact=1)`로 강제 넉다운. 팽이에는 강제 넉다운을 붙이지 않는다. 달려 부딪힌 결과까지 절대 넘어지지 않는다는 보장은 하지 않으며 공통 물리는 유지한다.
- 여러 명은 같은 폭16m 코스를 사용한다. 서로 밀기/잡기 가능. 도약대는 각 몸을 한 번씩 같은 착지점으로 발사하므로 착지할 때 엉킬 수 있다.
- 출발/중간/끝의 판은 겹침 없는 연속 높이로 이어진다. 경사·움직이는 발판은 기존 이동 표면 계약을 쓴다.
- 자동 검사: 실제 래그돌로 연속 통과한 경로는 `OPENING_COURSE.md` 참조. 12명이 동시에 조작할 때 난이도, 태클이 달리기보다 빠른지, 강한 충돌 느낌은 사람 확인 전이다.
- 최종 아트/효과음·변형 배치·두 번째/세 번째 코스 장애물은 별도 작업.
