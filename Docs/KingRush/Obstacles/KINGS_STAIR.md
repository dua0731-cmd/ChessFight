# 왕의 계단 장애물 · R56

기획 목표: 같은 높이로 가는 빠르고 좁은 길/길고 넓은 길, 붕괴 박자, 그림자로 예고하는 손. 기존18개 구간 뒤에 `18_KingsStairFork`~`23_SkyWater`를 추가한다. [전체 흐름/검사](../FINAL_COURSE.md).

- 외나무: 폭0.8m, 길이84m, 상승18m. 횡풍은 오른쪽 방향 `sin(2π × ObstacleClock / 8) × 0.6m/s²`. 이 코스의 지면에 선 몸에만 적용한다.
- 긴 길: 폭4m의4회전 계단, 시각 단차0.25m. 발 접촉면은 연속 경사, 시각 계단의 충돌은 꺼서 모서리 걸림을 없앤다. 회전 발판 바깥에1m 난간을 두어 넘어져도 일어날 여유를 준다. 높은 연결 통로에 낮은 난간. 최종 계단은76단/19m 상승.
- 돌아오는 칸: 3×3m,32개. 주기8초, 안정0~3초, 붉은 경고3~4초, 낙하4~8초. 위상은 `-행×0.65 + 열%2×4`. 순간 복귀 직후0.15초 충돌 유예로 아래에서 올라오는 칸이 사람을 쏘아 올리는 것을 피한다.
- 손: 주기8초. 그림자0~1.5초 → x−16~16m 쓸기1.5~3.5초 → 위로10m 치워 대기 → 반복. 손/손가락이 실제 충돌한다. 그림자는 충돌 없는 평면이다.
- 결승 타일은 반복 장애물이 아니다. 경기 T0에 대한 붕괴 함수50/100/140초와3초 예고를 쓴다. 판4개 중앙 칸/단상은 영구 보존한다.

위치·회전은 시간 함수이며 콜백 안에서 캐릭터를 이동하지 않는다. 실제 통과 시험과 사람 플레이 확인은 구분한다. 음악·최종 구름/손 아트는 별도다.
