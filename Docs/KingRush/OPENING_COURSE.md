# R54 · 첫 연결 코스: 장난감 상자 → 잡은 말 상자

2026-09-27, `JY-kingrush`. 사용자의 **“능력보다 맵(미션·코스) 먼저”** 요청에 따라 순서를 변경했다. 전체 3막/결승이 아니라 **첫 빨강 코스 + 첫 파랑 미션 + 다음 구간 출구**를 이어 붙인 오프라인 플레이 버전이다. 새 능력·공통 조작 튜닝·소드파이트·기존 로비 라우팅은 바꾸지 않는다.

## 열기

Unity Hub에서 `C:/Users/trews/.codex/worktrees/jy-kingrush/ChessFight`를 열고, **ChessFight → King Rush → Open Opening Course → Play**.
씬: `Assets/Scenes/KingRushOpening.unity`. 빌드: `Builds/KingRushOpening/ChessFight.exe`.
기존 능력 시험장은 **Open Mechanics Test**로 그대로 연다. **로비의 KingRush는 아직 옛 캡슐 코스**이며 새 코스는 Steam에 연결하지 않았다.

- WASD 이동, Shift 질주, Space 점프, 좌클릭 태클, **우클릭으로 잡은 채 좌클릭 던지기**. 턱을 넘겨 던질 때 점프를 함께 쓴다.
- **F4**: 첫 미션으로 바로 이동하고 양 팀 정지 더미를 배치한다. 점수는 주지 않는다. 혼자 미션을 시험할 때 사용.
- **Tab**: 12명 중 조종 대상 변경. 나머지는 가만히 있는 물리 더미이며 AI가 아니다.
- **R**: 현재 개인 체크포인트/파랑 입구로 복귀. 상자에 잡힌 대기시간은 건너뛰지 못한다.
- **F3**: 경기·승격·다리·대기·개인 체크포인트 초기화. **F6**: 빨강에서 다음 체크포인트로 이동하는 개발용 단축키.
- **Esc**: 안내/커서 전환(시간은 계속 흐름). Esc 후 Backspace: 로비.

## 상자 미션의 실제 규칙

- 첫 캐릭터가 파랑 경기장에 들어오면 공통 미션 시계 시작. 뒤에 있는 캐릭터의 구간/능력은 그대로.
- 각 팀의 북쪽 구석에 입구4×4m, 테두리0.8m, 깊이2m 상자. 바닥에 실제 구멍이 있으며 경기장 안에는 물이 없다. **정면 폭2.5m·길이3.3m의 짧은 경사**는 R54에서 추가한 임시 맵 조정이다. 평지에서 잡아 던지는 자동 시험이 턱에 막혀, 공통 던지기 힘을 바꾸지 않고 접근 지형을 조정했다. 실제 잡고 운반·점프/던지기로 득점하는 재검사 통과. 최종 난이도는 사용자 확인 후 조정한다.
- **골반 중심**이 상자 테두리 아래에 들어가면 판정. 손·머리 접촉만으로 득점하지 않는다. 잡힌 몸/날아가는 몸도 허용(일반 몸 수 제외 조건을 적용하지 않음).
- 적: 1점=판자2m 한 칸, 다음 Update에 선반 이동,3초 후 파랑 입구. 킹도1점. 자기 편: 점수 없이2초 대기. 같은 몸은 실제 복귀할 때까지 중복 예약하지 않음.
- 선반12칸은 캐릭터마다 따로 배정. 대기 중 이동/능력/R은 차단한다. 대기 시간은 포획 판정 시각 기준이며 손 흔들기 연출은 아직 없음.
- 6칸 완성 시 자기 문 즉시 열림. 상대 문은 상대가 먼저6칸 완성하거나 첫 완료20초 뒤 열림.
- **20초 구제 개방 시 부족한 다리도 채워 준다.** 실제 획득 칸 수는 올리지 않고 통행할 길만 보장한다.
- 첫 입장120초 이후10초마다 두 팀 자동1칸. 해석을 명확히 하기 위해 **첫 자동 칸은130초**, 이후140·150…180초로 구현했다. 큰 시간 간격에도 완료 시각은 예정 시각을 사용한다.
- 닫힌 문 및 상대 팀 문은 통과 불가. 열린 자기 문을 지나면 비킹 기물은 폰으로 복귀한다.

## 편집과 코드

- `Assets/Prefabs/KingRushOpening/01_Start`~`10_Water`(상자 진입로 `08b_BoxApproaches` 포함11개): 구간별 프리팹, 재질은 같은 폴더의 Materials. 씬에는 프리팹 인스턴스와 게임/카메라/조명만 배치한다. 공동 작업 시 구간을 나눠 편집한다.
- `KingRushOpeningBuilder`: **없는 씬/프리팹만 생성**. 기존 씬을 메뉴로 다시 열어도 재생성하지 않는다. 이후 아트 수정은 프리팹/씬에서 한다.
- `KingRushToyMotion`: 팽이/머리/시계 모두 시간 함수. 머리는 코스 아래로 돌아오므로 주기 경계에 캐릭터를 가로질러 순간이동하지 않는다. [장애물 기획](Obstacles/TOY_BOX.md).
- `KingRushCourseCheckpoint`, `KingRushCaptureBox`: 몸 중심 범위. 후자는 별도 고정 스케일 오브젝트로 판정 범위를 설정한다.
- `KingRushCaptureRules`: Unity 없는 득점·대기 예약·자동 다리. `KingRushRules`의 기존 문 완료 시각을 사용한다. **KR1에 미션 상태를 넣은 것은 아니며 온라인 지원으로 간주하지 않는다**.
- `KingRushOpening`: 모드 시간/명단/입력/개인 체크포인트/포획 예약, 실제 이동은 Update. `KingRushPawn.Captured`는 모드 전용 입력/능력 차단이며 공통 Pawn 수정 없음.
- 안내판은 실행 때 OS 한글 폰트/재질을 재연결한다. 편집기에서 만든 동적 폰트 atlas를 그대로 저장해 사용하지 않는다. 모드 전용 `KingRushCourseText` 셰이더로 벽/앞 간판에 가려진 뒤쪽 글자는 숨긴다. 공통 캐릭터 이름표/HUD는 변경하지 않는다.
