# 폰 러시 구간 프리팹 — 한 판 7구간과 2-1 대계단 현관홀 (R149)

2026-11-02. 기획: [대계단 현관홀 레벨 디자인 v0.3](PAWN_RUSH_GRAND_STAIR_HALL_DESIGN_v0.3.md)(성한 님, 사용자 첨부 원문), 참고: [4분 장애물 코스 컨셉아트 v2](PAWN_RUSH_CONCEPT_ART_v2.md), [장소별 4분 코스 설계](PAWN_RUSH_PLACES_4MIN.md), [미니게임 경계 설계](PAWN_RUSH_MINIGAME_BOUNDARY.svg). 사용자: "폰 러시는 장애물 구간 3개와 미니게임 구간 3개, 마지막 구간 1개 총 7개의 구간이 한 판을 이룰거야. 따라서 각 구간들은 해당 구간에서 나올 수 있는 프리팹 목록 중 랜덤으로 한 가지 프리팹을 뽑아 등장하고 조합되어 한 판을 이룰거야."
**상태: Linux 컴파일·Core 테스트·파이썬 좌표 점검만. Unity에서 사람이 본 적 없음.** 확인 목록은 [VALIDATION](../Network/VALIDATION.md) 최상단 R149 표.

## 1. 여는 법

1. Unity 메뉴 **ChessFight → Pawn Rush → Build Mid 2-1 Grand Stair Hall** (처음 한 번). 코드가 홀 전체를 만들어 프리팹 `Assets/Prefabs/PawnRushSections/Mid_2-1_GrandStairHall.prefab`에 굽고 검증기를 돌린다(Console에 "구간 검증 통과"). 두 번 눌러도 같다. **굽기 전에는 프리팹을 열면 뿌리만 보인다**(Play하면 코드가 그때 만든다).
2. **ChessFight → Pawn Rush → Open Section Test** → **Play**. `PawnRushRound`가 판 씨앗으로 7구간을 뽑아 이어 붙인다. 지금은 구간 프리팹이 대계단 현관홀(슬롯 3, 중반 장애물) 하나라서 그것만 놓이고 나머지 슬롯은 건너뛴다(Console "이번 판 구간 …"). 래그돌 폰(백팀)이 현관(z −12 아치 안쪽)에 선다.

| 키 | 동작 |
|---|---|
| WASD·Space·Shift·좌클릭·우클릭·마우스 | 래그돌 기본 조작 |
| **F5** | 백팀 ↔ 흑팀(처음부터) |
| **F8** | 새 판: 새 씨앗으로 다시 뽑고 이어 붙임 — 굴러오는 순서·샹들리에 자리·3대3에서 열리는 날개가 바뀜 |
| **F9** | 팀 인원 3 → 4 → 5 → 6대(3·4대는 날개 하나만 열리고 승강 계단참 1묶음) |
| R / Backspace | 마지막 체크포인트로 / 처음부터 |
| V | 자유 카메라 |

오른쪽 위: 판 씨앗·팀 인원·지금 구간과 비트·낙하/맞은 횟수·판 구성(슬롯 7개). 비트 입장·퇴장, 홀 바닥으로 떨어짐, 석상·카펫·샹들리에에 맞음은 `Logs/PawnRush/sections_날짜.csv`(열: 비트, 사건, 초, 팀, 씨앗, 팀 인원) — 기획서 §8 "비트별 입장·퇴장 시각과 실패 횟수".

## 3. 한 판 = 7구간

| 슬롯 | 종류 | 프리팹 목록(지금) |
|---|---|---|
| 1 | 장애물 1 (초반 · 바깥뜰 1-x) | 없음 |
| 2 | 미니게임 1 | 없음 |
| 3 | 장애물 2 (중반 · 아랫궁 2-x) | **Mid_2-1_GrandStairHall** |
| 4 | 미니게임 2 | 없음 |
| 5 | 장애물 3 (후반 · 윗궁 3-x) | 없음 |
| 6 | 미니게임 3 | 없음 |
| 7 | 마지막 구간 | 없음 |

- **목록**: `Assets/Settings/PawnRushSections.asset`(`PawnRushSectionSet`). 새 구간은 프리팹을 해당 슬롯 목록에 끌어 넣기만 하면 된다. 같은 프리팹을 여러 슬롯에 넣어도 된다(예: 미니게임 하나를 세 미니게임 슬롯 모두에).
- **뽑기**(Core `PawnRushSections.Choose`, 씨앗 있는 순수 함수): 슬롯마다 목록에서 하나. 여러 슬롯 목록에 든 프리팹은 그 슬롯에 다른 것이 있는 한 **한 판에 한 번만**, 같은 슬롯의 **직전 판 것은 빼고**(다른 것이 있을 때). 같은 씨앗 = 같은 판(방장은 씨앗만 보내면 됨). Core 테스트로 고정.
- **이어 붙이기**(`PawnRushRound`): 구간마다 입구·출구(문턱 가운데, 바닥 높이, 나아가는 쪽 = +z). 첫 구간의 입구를 판 원점에, 다음 구간의 입구를 앞 구간의 출구에. 빈 슬롯은 건너뛴다(다음 구간이 앞 구간에 바로 붙음). 출구를 돌리면(`exitYaw`) 다음 구간도 돈다.
- **구간 씨앗** = 판 씨앗과 슬롯 번호를 섞은 값(`SectionSeed`), 구간 안의 무작위 장애물은 여기에 자기 번호를 또 섞는다(굴림 1, 샹들리에 2, 날개 3).
- **체크포인트 번호** = 슬롯 × 100 + 구간 안 번호(대계단 현관홀은 200~205). 플레이테스트는 가장 높은 번호에서 다시 하므로 구간을 넘어가도 맞다.
- **팀 인원**·씨앗·판 시작 시각은 `PawnRushSection.Configure`로 들어가 `ISectionPart`(구간 안의 장애물·스위치)에 전달된다.
- **새 구간 프리팹의 약속**: 뿌리에 `PawnRushSection`(id, 이름, 종류, 입구·출구, 비트). 판의 값이 필요한 것은 `ISectionPart`를 구현. 체크포인트는 `CourseCheckpoint`(번호 0~99). 입구 폭 12 m·출구는 미니게임 입구 띠 끝(경계 설계 SVG: 테라스 +1 m → 0.25 m × 4단 → 입구 띠 4 m).
- **온라인**: 아직 연결하지 않았다. 방장이 판 씨앗과 판 시작 시각(공유 장애물 시계)을 보내면 모든 PC가 같은 판·같은 사건을 만든다. 맞음 판정은 이미 방장만(`ObstacleClock.Authority`).

## 4. 2-1 대계단 현관홀

구간 좌표: 원점 = 현관 안쪽 문턱(z 0) 가운데, +z 북쪽, +x 동쪽, y = 바닥 윗면(기획서 §2). 입구 z −12(폭 12), 출구 (0, 19, 132). 동쪽 날개는 서쪽 날개와 같은 코드를 x 부호만 바꿔 만든다(진자 방향, 컨베이어·바람 방향 포함).

```text

  Content
    B1_GrandStair      현관·입구 아치, 포이어(기둥 6), 굴림 배수구, 아래 계단·중간 계단참·위 계단(보이는 단 + 걷는 경사면),
                       난간, 굴림 구멍 4, Rolling lanes (RollingSpawner)
    B2_CentralLanding  중앙 계단참, 난간(날개 입구 z 56~64 빼고), 왕 석상, Chandelier rain (ChandelierRain)
    Wing_West          날개 계단 1(진자 2 + 들보), 꺾임 계단참(컨베이어 2), 날개 계단 2(진자 1), 창가 회랑(바람 4·창·쉼터),
                       CP2·CP3, 들리는 다리, 날개 쇠살문(3·4대에서 닫힌 쪽만)
    Wing_East          서쪽의 거울
    B5_RoyalDais       왕실 단, 승강 계단참(05 ×2), 승강로 벽·바닥, 동쪽 묶음 대신 벽(3·4대)
    B6_RoyalBalcony    왕실 발코니, 기병 감실 받침 2, 나이트 2, 시계 문 + 막음 벽, 정리 동선, 출구 테라스(CP 끝), 아치, 4단, 입구 띠
    Hall               홀 벽, 홀 바닥(y −4, 리스폰) + 낙사 영역, 매달린 샹들리에(그림)
    Checkpoints        CP0 현관, CP1 중앙 계단참, CP4 왕실 단, CP5 출구 테라스
    ProgressPath       서쪽 날개 길(백) · 동쪽 날개 길(흑), 각 215.7 m
```

## 7. 검증기 (Validate Sections, Build 메뉴 뒤에도)

1. 장애물마다 길 폭 전체를 덮는지(`ObstacleSpan`, 광선으로 실제 걸을 수 있는 폭을 잼): 굴림 레인(계단 폭 16), 샹들리에(계단참), 진자 6(날개 계단 폭), 바람 8(회랑 폭 6), 나이트 2(감실 사이), 시계 문(막음 벽 사이).
2. 서쪽·동쪽 날개 길 길이 차 ≤ 0.1 m, 필수 경로 틈 ≤ 1.5 m(승강은 수직이라 뺌).
3. 체크포인트 부활 자리 아래 바닥.
4. 회색 격자 = `NoClimbSurface`, 그리고 홀·포이어·현관 벽, 기둥, 날개 계단 난간, 왕 석상, 감실, 쇠살문, 승강로 벽, 막음 벽, 발코니 벽, 승강 타일, 3·4대용 동쪽 벽이 오를 수 없는지.
5. 리스폰 바닥(낙사 영역), 입구·출구 바닥.

## 8. 사람이 결정·확인할 것

- 기획서 "결정할 것": 구간 시간 3분 / 4분(§7 손잡이), 무작위 세기(석상 40%, 굴림 2.1초, 샹들리에 1초), 날개 하나만 여는 인원(지금 4대4 이하), 샹들리에가 비트 2·3에 연달아, 다리 9초, 회랑 남쪽 0.3 m 턱.
- 이번 구현에서 생긴 것: 날개 계단 2 진자 30°, 계단 경사면 방식, 감실 받침으로 발코니 폭 좁힘.
- 하지 않은 것: 온라인 연결(판 씨앗·시작 시각을 방장이 보내기 — `SteamPawnRushLink`는 코스 01 전용), 다른 6개 슬롯의 프리팹, 미니게임 구간을 프리팹으로 만들기(지금 미니게임은 코스 01의 스테이션), 마지막 구간, 효과음(구멍 소리·샹들리에 삐걱), 굴러오는 석상이 넘어진 폰을 "계단 아래로 2~3 m" 미는 정도는 맞음 세기로만.

## 9. 자동으로 확인한 것과 못 한 것
