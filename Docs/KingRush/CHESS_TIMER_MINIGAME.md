# 체스 타이머 폭탄 미니게임 프로토타입

R84 · 2026-10-17. 사용자의 거대한 체스 타이머/팀별 폭탄/인원 분배 기획을 시험하는 **독립 오프라인 씬**이다. Steam 경기·실제 다음 맵 로딩에는 연결하지 않았다.

## 열기

Unity 메뉴 **ChessFight → Minigames → Open Chess Timer Prototype**, 또는 `Assets/Scenes/ChessTimerMinigame.unity`를 연 뒤 Play한다. Enter 또는 화면의 게임 시작 버튼으로 시간을 시작한다. 기존 RagdollPawn·tuning·LabCamera·PhysicsProfile을 사용한다.

씬 파일에는 카메라·조명·프로토타입 설정이 저장되어 있다. 체스 바닥·거대 시계·발판·계단·해체 장치·문·래그돌 12명은 Play 시 생성된다. 정지 상태에서는 경기장 전체가 보이지 않는다. 최종 아트/맵 조립용 프리팹 제작 전의 동작 검증용 구성이다. Play 중 Hierarchy의 Chess Timer Minigame 루트 아래에서 생성된 부품을 확인할 수 있다.

## 조작

| 조작 | 동작 |
|---|---|
| Enter / 게임 시작 | 타이머 시작, 마우스 시점 조작 |
| WASD / Space / Shift | 이동 / 점프 / 질주 |
| 마우스 / 휠 | 시점 / 줌 |
| F 길게 누르기 | 현재 활성 해체 장치 근처에서 작업 |
| Tab | 다음 팀원 선택(총12명) |
| T | 반대 팀의 같은 번호 선택 |
| 1 | 선택 팀원을 자기 팀 타이머 발판에 시험 배치 |
| 2 | 선택 팀원을 현재 해체 장치에 시험 배치하고 자동 작업 지정 |
| 3 | 선택 팀원을 대기 위치로 배치하고 자동 역할 해제 |
| R | 선택 팀원 출발 지점 복귀(재정비 중에는 불가) |
| F3 | 라운드 초기화, Inspector 설정 다시 읽기 |
| Esc | 마우스 해제/복귀. 타이머는 계속 흐름 |

1/2/3은 **시험용 순간 배치**다. 자동 작업 담당은 단계 완료 시 다음 장치로 순간 이동한다. 선택한 팀원을 WASD로 움직이면 자동 역할이 해제된다. 일반 진행에서는 계단을 걸어 올라가 발판을 누르고, 아래 장치에서 F를 누를 수 있다. 초기 팀별 배분은 발판2명·자동 해체1명·대기3명이며 1번 팀원부터 조작한다.

## 규칙

- 팀별 45초. 각 팀 발판에 실제 접지한 고유 캐릭터 수를 비교한다. 같은 캐릭터의 여러 래그돌 콜라이더를 중복 계산하지 않는다. 캐릭터 질량과 무관하게 1인1표이며 공중/넘어진 캐릭터는 제외한다.
- 다수 팀의 시간이 정지한다. 동수는 양쪽 시간이 감소한다. 새로운 다수 상태가 0.35초 유지되어야 정지하며 전환 중에는 양쪽 시간이 흐른다.
- 눌린 발판은 0.2m 내려가고 풀리면 복귀한다. kinematic Rigidbody/기존 이동 표면 계약으로 운반한다. 온라인 장애물 시계와 별개인 오프라인 상태형 장치다.
- 아래의 PAWN → KNIGHT → ROOK 장치를 순서대로 해체한다. 현재 장치 근처에서 F를 누르거나 자동 담당으로 배치된 캐릭터가 작업한다. 단계당 기본10 인·초, 최대3명까지 속도를 합산한다. 위치를 떠나도 현재 작업량은 유지한다. 지금은 인원 배분 검증용 누르기 작업이며 별도 문양/배선 퍼즐은 미구현이다.
- 0초면 해당 팀6명에게 밀침·상향 속도·3초 넉다운을 적용한다. 완료 단계는 유지하고 현재 작업량만0으로 만든다. 시간을45초로 다시 채우고 총6초(넉다운3+여유3) 재정비 후 재개한다. 재정비 중 작업/타이머 감소/시험 재배치로 페널티를 건너뛸 수 없다. 종료 시 지정된 역할 위치로 재배치한다.
- 마지막 단계 완료 시 자기 팀 문이 열리고 그 팀의 시간이 영구 정지한다. 문 뒤 통과 인원을 HUD에 표시한다. 다음 씬으로 이동하지는 않는다.
- 한 팀 완료 후 남은 팀은 발판2명 이상으로 시간을 멈출 수 있다. 완료한 팀 인원은 경쟁에서 제외한다.
- 제한시간 만료와 작업 완료가 같은 물리 단계에 발생하면 폭발을 우선한다.

## Inspector

루트 `ChessTimerMinigame`의 Time Limit, Seconds Per Stage, Switch Delay, Stun Seconds, Retry Grace, Blast Speed, Solo Required Riders, Interact Distance. 라운드 규칙 값을 변경한 뒤 **F3**로 새 라운드에 적용한다. 초기45초는 조작 확인용 여유값이다. 폭발·역할 배분 압박은 Time Limit을10~15로 낮춰 시험할 수 있다. 최종 난이도 수치는 아직 정하지 않았다.

## 확인 순서

1. 기본 설정으로 시작 → 양쪽 발판2명이므로 두 시간 감소. Tab으로 청팀 대기자를 선택하고1 → 청팀3:홍팀2, 잠시 뒤 청팀만 정지.
2. T로 홍팀 대응 인원을 발판에 배치 → 동수에서 양쪽 감소. 직접 점프/발판에서 내려오면 인원 갱신.
3. 3으로 한 명을 발판에서 빼고2로 자동 해체 배치 → HUD 작업 인원과 진행 속도 비교. 직접 담당은 이동해서 역할 해제 후 활성 장치 앞에서 F.
4. Time Limit을10으로 바꾸고 F3/Enter → 팀 폭발, 래그돌 날아감/기절, 완료 단계 보존/진행 단계 초기화, 재정비 확인.
5. 기본값 복구 후 한 팀 먼저 해체 → 자기 문만 열림·시간 정지. 남은 팀 발판2명이 시간을 정지시키는지 확인.
6. 열린 문 뒤로 이동 → 통과 인원 증가. F3로 모든 문/시간/역할/통과 표시 초기화.

## 코드와 검사

- `Core/ChessTimerRules.cs`: Unity 없는 시간·발판 우세·작업·폭발·완료 규칙.
- `RagdollLab/Scripts/ChessTimerMinigame.cs`: 경기장 생성·래그돌/물리·입력·시험 배치·UI.
- `RagdollLab/Editor/ChessTimerMinigameTools.cs`: 기존 씬 변경 저장 확인 후 시험 씬 열기.
- `NetworkCoreTests`: 동수/다수 전환, 단계 보존 폭발/재정비, 완료/단독 발판, 동시 만료/잘못된 시간 입력 4개.
- `test_chess_timer_scene.py`: 씬 스크립트·기존 프리팹 참조와 fileID·메뉴 경로 2개.

자동 결과: 구조24·Core87·모의 세션39·7개 런타임 어셈블리 컴파일. Unity 2021 참조 DLL에 대한 호환 컴파일이며 실제 Unity 6 실행은 아니다. Editor/Input 코드는 제외한다. **Unity import/화면/계단 이동/발판 접지/폭발·문 통과 실기는 미확인**이다. 두 PC 동기화·정식 미니게임 퍼즐·최종 아트/음향·실제 다음 스테이지 연결은 후속 작업이다.
