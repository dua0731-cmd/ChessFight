# 체스 타이머 폭탄 미니게임 프로토타입

R99 · 2026-10-18. **단일 체스 타이머 위 난투 + 거대한 8×8 판에서 도구로 전선을 자르는 쉬운 퍼즐 1개**. 6 대 6 독립 오프라인 시험장이다. 기존 래그돌/스폰/타이머 위치를 유지하고 뒤쪽 해체 구역만 확장했다. 자동 해체는 제거했다. 온라인·실제 다음 코스 전환은 미연결이다.

팀 표시는 **왼쪽 백팀(기존 파란 팀), 오른쪽 흑팀(기존 빨간 팀)**으로 통일했다. 캐릭터·버튼 표시·진입로·출구·HUD/LCD·승리 문구에 적용한다. 퍼즐 전선의 빨강/파랑/노랑은 정답 식별용으로 유지한다.

## 실행·첫 시험 순서

Unity 메뉴 **ChessFight → Minigames → Open Chess Timer Prototype**, 또는 `Assets/Scenes/ChessTimerMinigame.unity` → **Stop 후 Play → Enter**. 경기장은 실행할 때 생성되므로 Play를 다시 시작해야 새 지형이 나온다.

1. 선택 캐릭터는 기존 입구에 있다. 타이머 옆으로 돌아 **자기 팀 뒤쪽 해체 구역**으로 걸어간다. 양쪽 바깥 경사로는 기존 상단 난투용이다.
2. 정사각형 해체 구역 입구의 절단기 공급대 앞에서 **F를 한 번 눌러 절단기를 장착**한다. 손에 도구가 보이고 HUD에 절단기 보유 여부가 나온다.
3. 8×8 판 안으로 직접 들어가 룩2개·비숍1개와 세 전선의 위치를 읽는다. **H**는 자기 판의 전체 기물 공격 범위 힌트 표시/숨김이다.
4. 안전한 칸에 놓인 전선 장치 가까이에서 **F를 1.5초 연속 유지**한다. 절단기가 전선 위에서 닫히고 중앙 선이 끊어지면 해체 성공이다.
5. 오답은 **전체 제한시간의1/9 차감(90초 설정이면10초) + 장치2초 잠금**. 이미 자른 전선을 다시 잘라 중복 페널티를 받지 않는다. 시간 정지 중에도 오답 차감은 적용된다.
6. 해체 성공/폭발·입구 복귀·출구를 확인한다. HUD의 경과 시간과 해체 완료 시간을 기록한다. **이동시간 측정에는 숫자키 시험 배치를 사용하지 않는다.** B로 대련 봇을 끄면 퍼즐만 보기 쉽다.

도구 없이/기절/공중/거리 밖에서는 절단하지 못한다. 키를 놓거나 범위를 벗어나거나 캐릭터/대상 전선을 바꾸면 절단 진행을 초기화한다. 공급대는 각 팀원의 도구를 보충할 수 있다. 폭발·리스폰·시험용 순간 배치 시 도구를 잃고 다시 얻어야 한다. 도구는 장착형 시각 모델이며 자유 물리 집기/던지기 방식은 아니다.

오답 차감은 남은 시간이 아니라 라운드 시작 시 설정한 Time Limit 기준이다. 90초에서80초가 남았어도 오답은10초 차감한다.0초 이하면 만료 폭발/양문 개방으로 이어진다. 고정 초 설정은 제거했다.

## 이번 문제와 공정성

두 팀에 같은 고정1단계 문제를 준다. 파일 A~H, 랭크1~8. **룩 C3·F6 두 개와 비숍 C6 한 개**를 배치한다. 기물은 기존 축소값60%를 유지하고 비숍도 같은 비율로 만든다. Rook Scale은 현재 퍼즐 기물 전체에 적용한다.

| 전선 | 좌표 | 판정 |
|---|---|---|
| 빨강1 | F2 | F6 룩의 세로 공격 → 오답 |
| 파랑2 | E4 | C6 비숍의 대각선 공격 → 오답 |
| 노랑3 | C7 | 모든 기물의 공격 밖 → 정답 |

**C6 비숍이 C3 룩과 C7 사이를 가린다.** 룩은 다른 기물을 넘어 공격하지 못하므로 C7이 안전하다. 기물들을 같은 진영의 고정 장애물로 간주하며 룩은 상하좌우, 비숍은 대각선으로 다른 기물을 만날 때까지 공격한다. 플레이어/전선 받침대는 체스 규칙의 차단 기물이 아니다. H 힌트와 실제 정답 판정은 동일한 공격 계산을 사용한다.

전선은 책상 위 축소 퍼즐이 아니라 캐릭터가 직접 걷는 체스판의 해당 칸에 놓인 절단 장치다. 각 장치는 케이블 양끝/중앙 절단 구간/접속선을 갖고, 정답은 체스 공격 규칙으로 결정한다. 이번에는 정답 하나인 고정 문제로 검증한다. 무작위 문제 은행·추가 조합·나이트·이동 후 판정은 후속이다.

## 기물 이동 설명 액자

각 팀의 룩2개·비숍1개에 대응하는 액자 하나씩, 총6개를 **체스판 밖 외벽의 안쪽 면**에 걸었다. 좌우 외벽에서 판 안을 향해 읽는 단면 벽걸이이며, 각 액자 안에 도식과 설명이 함께 들어간다. 액자 중심은 X=±41.64, Y=2.5, Z=18/30/42m. 외벽은 액자를 받치도록 높이를3m에서5m로 높였다. 룩은 십자 방향, 비숍은 대각선 방향의5×5 도식에서 금색 칸으로 이동 방향을 보여준다. “막힐 때까지 여러 칸 / 다른 기물은 넘지 못함”을 함께 안내한다. 현재 문제의 정답 좌표가 아닌 기본 이동 규칙을 설명한다. 액자는 보행/전선 접근을 막지 않는 비충돌 안내물이다.

## 공간과 이동거리

- **스폰 유지:** 팀 중심 X=-15/+15, Z=-24~-25 부근. 기존 타이머/경사로도 이동하지 않았다.
- **해체 구역:** 팀별42×42m. 백팀 X=-42~0, 흑팀 X=0~42, Z=9~51. 중앙벽으로 분리하며 상단 난투를 막지 않는다.
- **체스판:** 한 칸4m, 8×8=32×32m. 중심 X=-21/+21, Z=30. 양쪽 구역 안에5m 여유 동선이 있다.
- **도구대:** X=-21/+21, Z=11.5. **출구:** X=-21/+21, Z=51. 통과 판정은Z>52.
- **전체 외곽 범위:** X±42, Z=-27~58. 앞쪽 스폰 바닥/폭은 기존54m이며 뒤쪽만84m로 넓어진 형태다.
- **타이머:** 몸체22×10m, Coupled white rocker Scale=(1,0.7,1), 실크기20.4×1.4×8.5m, 중심Y=5·수평 윗면5.7. 양쪽 접근 경사/연결판 유지.

타일은 평평한 바닥 위 시각 표면이며 타일마다 충돌 턱을 만들지 않는다. 실제 걷는 바닥은 하나의 기초 Collider다. 기물/전선 받침대/벽은 물리 충돌을 가진다.

## 약90초 목표와 이번 범위

**90초는 완성형 코스의 목표 체류시간이며 첫 문제를 90초 동안 강제로 붙잡는 시간이 아니다.** 타이머는 시험용으로90초부터 시작하고 발판으로 정지할 수 있어, 실제 경과시간과 별도로 표시한다. 한 문제를 익힌 플레이어는 더 빨리 끝낼 수 있고, 시간을 계속 보호하면90초를 넘길 수도 있다.

현재 래그돌 기본 이동속도5.5m/s 기준, 기존 입구→도구대→전선→출구는 경로 선택에 따라 약80~110m로 **이동만 약15~20초**의 계산값이다. 질주9.6m/s·충돌·우회·관찰에 따라 달라진다. 이번 쉬운 문제는 도구 획득/관찰/절단을 합해 **초견 약30~50초를 가설**로 측정한다. Unity 실측값이 아니다.

완성형은 이동/도구15~20초 + 쉬움10~15초 + 보통20~25초 + 어려움25~30초 + 마무리5초로 **75~95초**를 초기 예산으로 잡는다. 다음 문제의 전선 위치를 바꿔 이동과 관찰을 섞되 왕복만 강요하지 않는다. 먼저 현재1문제의 경과/해체 시간을 확인한 뒤 2·3단계를 추가한다. 이번에는 중급/고급 문제나 인위적인 대기시간을 넣지 않았다.

## 타이머 인원·난투

실제 윗면 접촉 사람을 팀 소속과 무관하게 위치한 쪽에 한 명씩 센다. 넘어진 몸도 포함하고 팔다리 중복/공중 접촉은 제외한다. 중앙선은 골반 위치로 한쪽만 센다. 많은 쪽 버튼 하강·시간 정지, 적은 쪽 상승·시간 감소. 동수면 수평·양쪽 감소. 기본 안정시간0.35초, 기울기최대±3°.

백측4:흑측2에서 백팀1명이 흑측으로 공격하면3:3으로 자기 시간도 흐른다. 두 명이 넘어가면2:4로 상대 시간이 멈춘다. 상단은 열린 공간이라 밀치기/잡기로 떨어뜨릴 수 있다. 아래 중앙벽은 좌우 직접 이동을 막지만 완전한 팀 출입 제한은 아니며 등반/상단 낙하 우회는 실기 점검 대상이다.

## 문·폭발·결과

- 한 팀 해체 성공: 그 팀 문 열림·처음 성공한 팀 승리·맵 안 상대 팀 폭발. 나중에 상대가 해체해도 최초 승자에게 보복 폭발하지 않는다.
- 동시 해체: 같은 물리 업데이트에서 완료하면 남은 시간이 많은 팀 승리·적은 팀 폭발. 시간 차이0.001초 이하면 양 팀 폭발. 양쪽 문 열림. 로컬 시험은 한 캐릭터만 직접 조작하므로 동시 제출은 Core 자동 검사로 검증하며 온라인 다인 입력은 미연결이다.
- **한 팀 타이머 만료: 해당 팀 전원 폭발 + 양 팀 문 즉시 열림. R92 정정을 코드에 반영했다.** 문 개방과 해체 종료 상태를 분리하여, 상대 퍼즐/타이머는 계속 진행할 수 있다. 만료 팀은 재충전하지 않는다.
- 오답 차감/시간 만료와 해체 성공이 같은 단계면 만료 우선.
- 폭발 효과·강한 비행·기본2.4초(0.5~2.8초 제한) 뒤 기존 입구 복귀. 성공팀은 직접 영향을 받지 않지만 폭발 적을 잡고 있으면 함께 날아간다. 잡은 아군은 별도 강제 리스폰 대상이 아니다.
- 성공 폭발 범위는 확장한 맵 외곽 X±42, Z=-27~58, Y=-5~30. 만료 폭발은 해당 팀 전원.
- 문이 열린 뒤에도 테스트는 종료하지 않는다. 다음 씬 전환은 미구현이다.

## 조작·설정

| 키 | 기능 |
|---|---|
| Enter / Esc | 시작 / 메뉴·마우스 해제(타이머는 흐름) |
| WASD / Space / Shift | 기존 이동 / 점프 / 질주 |
| 좌클릭 / 우클릭 | 밀치기 / 잡기 |
| F | 공급대에서 도구 획득, 전선 앞에서 길게 절단 |
| H | 자기 판 전체 기물 공격 범위 힌트 |
| Tab / T | 다음 캐릭터 / 반대 팀 같은 번호 |
| 1 / 4 | 자기 / 상대 버튼 시험 배치 |
| 2 / 3 | 도구대 앞 / 입구 시험 배치. 자동 풀이 없음 |
| B / R / F3 | 대련 봇 / 입구 복귀 / 전체 초기화 |

Inspector: Rook Scale=0.6(Stop→Play로 적용), Time Limit=90, Cut Seconds=1.5, Wrong Wire Lock=2, Interact Distance=1.8. Time Limit/절단/잠금은 F3로 새 라운드 적용. 기존 Switch Delay, Solo Required Riders, Rocker Tilt/Speed, Success Blast Speed/Respawn Seconds 유지. Seconds Per Stage는 시험 씬에서 제거했다. Core의 이전 시간 작업 Step은 회귀 호환용이며 씬은 StepPuzzle만 호출한다.
