# 체스 타이머 폭탄 미니게임 프로토타입

R104 · 2026-10-19. **단일 체스 타이머 위 난투 + 거대한 8×8 판에서 도구로 전선을 자르는 무작위 퍼즐 2단계**. 6 대 6 독립 오프라인 시험장이다. 기존 래그돌/스폰/타이머 위치를 유지하고 뒤쪽 해체 구역만 확장했다. 자동 해체는 제거했다. 온라인·실제 다음 코스 전환은 미연결이다.

팀 표시는 **왼쪽 백팀(기존 파란 팀), 오른쪽 흑팀(기존 빨간 팀)**으로 통일했다. 캐릭터·버튼 표시·진입로·출구·HUD/LCD·승리 문구에 적용한다. 퍼즐 전선의 빨강/파랑/노랑은 정답 식별용으로 유지한다.

## 실행·첫 시험 순서

Unity 메뉴 **ChessFight → Minigames → Open Chess Timer Prototype**, 또는 `Assets/Scenes/ChessTimerMinigame.unity` → **Stop 후 Play → Enter**. 경기장은 실행할 때 생성되므로 Play를 다시 시작해야 새 지형이 나온다.

1. 선택 캐릭터는 기존 입구에 있다. 타이머 옆으로 돌아 **자기 팀 뒤쪽 해체 구역**으로 걸어간다. 양쪽 바깥 경사로는 기존 상단 난투용이다.
2. 정사각형 해체 구역 입구의 절단기 공급대 앞에서 **F를 한 번 눌러 절단기를 장착**한다. 손에 도구가 보이고 HUD에 절단기 보유 여부가 나온다.
3. 8×8 판 안으로 직접 들어가 룩2개·비숍2개와 세 전선의 위치를 읽는다. **H**는 자기 판의 전체 기물 공격 범위 힌트 표시/숨김이다.
4. 안전한 칸에 놓인 전선 장치 가까이에서 **F를 7초 연속 유지**한다. 1단계 정답이면 해당 팀만2단계로 전환한다. 2단계 정답까지 잘라야 최종 해체 성공이다.
5. 오답은 **전체 제한시간의1/9 차감(45초 설정이면5초) + 장치2초 잠금**. 이미 자른 전선을 다시 잘라 중복 페널티를 받지 않는다. 시간 정지 중에도 오답 차감은 적용된다.
6. 해체 성공/폭발·입구 복귀·출구를 확인한다. HUD의 경과 시간과 해체 완료 시간을 기록한다. **이동시간 측정에는 숫자키 시험 배치를 사용하지 않는다.** B로 대련 봇을 끄면 퍼즐만 보기 쉽다.

도구 없이/기절/공중/거리 밖에서는 절단하지 못한다. 키를 놓거나 범위를 벗어나거나 캐릭터/대상 전선을 바꾸면 절단 진행을 초기화한다. 공급대는 각 팀원의 도구를 보충할 수 있다. 폭발·리스폰·시험용 순간 배치 시 도구를 잃고 다시 얻어야 한다. 도구는 장착형 시각 모델이며 자유 물리 집기/던지기 방식은 아니다.

오답 차감은 남은 시간이 아니라 라운드 시작 시 설정한 Time Limit 기준이다. 45초에서35초가 남았어도 오답은5초 차감한다.0초 이하면 만료 폭발/양문 개방으로 이어진다. 고정 초 설정은 제거했다.

## 이번 문제와 공정성

**1단계는 룩2개+비숍2개(총4개)**, **2단계는 그4개의 위치를 유지하고 나이트1개+폰6개를 추가(총11개)**한다. Play/F3 새 판마다 두 단계 모두 새로 생성한다. R 복귀·폭발 리스폰·Enter 시작으로는 문제를 바꾸지 않는다.

- 양 팀의 단계 진행은 독립적이다. 1단계 정답은 문/승패/성공 폭발을 발생시키지 않으며 해당 팀만2단계로 넘어간다. 상대 팀의 진행/기물/전선은 유지한다. 2단계 정답을 최종 해체 성공으로 제출하므로 기존 동시 해체·시간 비교·폭발 규칙이 유지된다.
- 1단계는 서로 다른4칸에 무작위 배치한다. 일반 생성에서는 이전 판의 기물 칸을 피한다. 2단계는 기존4개 외 나이트/폰7개의 칸과 전선 위치·정답 색을 새로 뽑는다. 폰6개는8개 열 중 무작위6개 열을 선택해 열마다1개씩 놓는다(R104). 같은 열에 폰이 중복되지 않으며 행은 무작위다. 일반/보장 생성 모두 같은 분산 조건을 지킨다. 각 단계마다 **기물이 없는 안전한 전선1개+공격받는 전선2개**를 보장한다.
- 룩/비숍은 다른 기물에 막히며, 나이트는 L자 공격으로 기물을 뛰어넘는다. 폰은 **앞 대각선 한 칸만 공격**하고 직진/뒤쪽은 공격하지 않는다. 기물은 고정 퍼즐 장애물로 직접 움직이지 않는다.
- **백팀 판은 흑 기물, 흑팀 판은 백 기물**이다. 흑 폰은 랭크 감소, 백 폰은 랭크 증가 방향으로 공격한다. 백 기물 문제는 랭크를 반전하고 오른쪽 판의 좌표 방향도 반전해 실제 배치·도구대부터 이동거리·정답 색이 동등하다. 두 판 모두 폰은 물리적으로 입구 쪽을 공격한다. 폰 밑의 금색 표시와 외벽 설명이 방향을 안내한다.
- 무작위 생성은 단계별 최대128회 시도한다. 1단계는 검증된 기본/반전 배치, 2단계는 기존 안전 칸을 보호하고 나이트의 위험 칸2개를 비워두는 보장 생성으로 대체한다. 대체 생성에서도 정답 하나·기물 조합·1단계4개 유지 조건을 지킨다. 1단계 대체 생성은 배치 전체 변화만 보장하며 이전 칸 일부가 겹칠 수 있다.
- 단계 전환 시 해당 판 안의 플레이어는 **절단기 보유를 유지한 채 판 입구(Z=10.1m)**로 옮겨 새 기물/전선 충돌에 끼이지 않게 한다. 타이머 위 플레이어는 이동하지 않는다. 타이머는 충전하지 않고 이어진다. 기존 판의 충돌·힌트·메시·글자 등록은 정리한 뒤 해당 팀 판만 재생성한다.

제한시간45초·각 전선 연속 절단7초·오답 초기시간1/9(5초)은 유지한다. Rook Scale은 모든 기물에 적용한다. 자동 검사는2,000판×두 단계의 구성/정답/공격과 색 반전 동등성, 보장 생성500개, 폰 방향/나이트 점프, 팀별 단계 독립성과 최종 해체 조건을 다룬다. Unity 플레이 난이도·이동시간은 별도 확인이 필요하다.

## 기물 이동 설명 액자

외벽에는 **기물 종류별 액자 하나**를 표시한다. 1단계는 룩/비숍2개, 2단계는 나이트/폰까지4개다. 같은 종류를 여러 번 설명하는 액자 대신 종류별 도식/설명을 보여준다. 중심 X=±41.64, Y=2.5, Z=18/26/34/42m이며 판 안을 향한다. 금색 칸은 공격 방향, 중앙 R/B/N/P는 해당 기물이다. 나이트는 L자/뛰어넘기, 폰은 앞 대각선과 직진 공격 불가를 안내한다. 기존 액자 크기·글자 자동 맞춤을 유지한다.

글자 크기는 TextMesh의 폰트 해상도48과 월드 크기를 분리해 보정한다(R100). 액자 제목2.7×0.4m, 설명2.7×0.65m, 범례2.7×0.23m, 중앙 기호0.26×0.26m로 제한한다. LCD 인원은2.6×1.1m, 상태는 별도8.8×0.65m 프레임 안8.2×0.45m로 제한한다. 문구 변경 시 실제 렌더러 경계를 측정해 비율을 유지하며 축소한다. 실제 Unity 가독성은 재확인 대기다.

## 공간과 이동거리

- **스폰 유지:** 팀 중심 X=-15/+15, Z=-24~-25 부근. 기존 타이머/경사로도 이동하지 않았다.
- **해체 구역:** 팀별42×42m. 백팀 X=-42~0, 흑팀 X=0~42, Z=9~51. 중앙벽으로 분리하며 상단 난투를 막지 않는다.
- **체스판:** 한 칸4m, 8×8=32×32m. 중심 X=-21/+21, Z=30. 양쪽 구역 안에5m 여유 동선이 있다.
- **도구대:** X=-21/+21, Z=11.5. **출구:** X=-21/+21, Z=51. 통과 판정은Z>52.
- **전체 외곽 범위:** X±42, Z=-27~58. 앞쪽 스폰 바닥/폭은 기존54m이며 뒤쪽만84m로 넓어진 형태다.
- **타이머:** 몸체22×10m, Coupled white rocker Scale=(1,0.7,1), 실크기20.4×1.4×8.5m, 중심Y=5·수평 윗면5.7. 양쪽 접근 경사/연결판 유지.

타일은 평평한 바닥 위 시각 표면이며 타일마다 충돌 턱을 만들지 않는다. 실제 걷는 바닥은 하나의 기초 Collider다. 기물/전선 받침대/벽은 물리 충돌을 가진다.

## 현재 제한시간과 전체 코스 목표

**90초는 완성형 코스의 목표 체류시간이며 첫 문제를 90초 동안 강제로 붙잡는 시간이 아니다.** 현재 프로토타입은 R101 요청에 따라 제한시간45초·연속 절단7초로 설정했다. 타이머는45초부터 시작하고 발판으로 정지할 수 있어, 실제 경과시간과 별도로 표시한다. 한 문제를 익힌 플레이어는 더 빨리 끝낼 수 있고, 시간을 계속 보호하면90초를 넘길 수도 있다.

현재 래그돌 기본 이동속도5.5m/s 기준, 기존 입구→도구대→전선→출구는 경로 선택에 따라 약80~110m로 **이동만 약15~20초**의 계산값이다. 질주9.6m/s·충돌·우회·관찰에 따라 달라진다. 기존 초견30~50초 가설은 절단1.5초 기준이었다. 절단7초로 변경했으므로 이동/관찰을 포함한 체류시간은 다시 측정해야 한다. Unity 실측값은 없다.

완성형은 이동/도구15~20초 + 쉬움10~15초 + 보통20~25초 + 어려움25~30초 + 마무리5초로 **75~95초**를 초기 예산으로 잡는다. 다음 문제의 전선 위치를 바꿔 이동과 관찰을 섞되 왕복만 강요하지 않는다. 현재는2단계를 구현했다. 두 번의7초 절단과 단계 전환/이동/관찰 시간을 측정한 뒤 난이도와 제한시간을 조정한다. 3단계는 미구현이다.

## 타이머 인원·난투

실제 윗면 접촉 사람을 팀 소속과 무관하게 위치한 쪽에 한 명씩 센다. 넘어진 몸도 포함하고 팔다리 중복/공중 접촉은 제외한다. 중앙선은 골반 위치로 한쪽만 센다. 많은 쪽 버튼 하강·시간 정지, 적은 쪽 상승·시간 감소. 동수면 수평·양쪽 감소. 기본 안정시간0.35초, 기울기최대±3°.

백측4:흑측2에서 백팀1명이 흑측으로 공격하면3:3으로 자기 시간도 흐른다. 두 명이 넘어가면2:4로 상대 시간이 멈춘다. 상단은 열린 공간이라 밀치기/잡기로 떨어뜨릴 수 있다. 아래 중앙벽은 좌우 직접 이동을 막지만 완전한 팀 출입 제한은 아니며 등반/상단 낙하 우회는 실기 점검 대상이다.

## 문·폭발·결과

- 한 팀 2단계까지 해체 성공: 그 팀 문 열림·처음 성공한 팀 승리·맵 안 상대 팀 폭발. 나중에 상대가 해체해도 최초 승자에게 보복 폭발하지 않는다.
- 동시 해체: 같은 물리 업데이트에서 완료하면 남은 시간이 많은 팀 승리·적은 팀 폭발. 시간 차이0.001초 이하면 양 팀 폭발. 양쪽 문 열림. 로컬 시험은 한 캐릭터만 직접 조작하므로 동시 제출은 Core 자동 검사로 검증하며 온라인 다인 입력은 미연결이다.
- **한 팀 타이머 만료: 해당 팀 전원 폭발 + 양 팀 문 즉시 열림. R92 정정을 코드에 반영했다.** 문 개방과 해체 종료 상태를 분리하여, 상대 퍼즐/타이머는 계속 진행할 수 있다. 만료 팀은 재충전하지 않는다.
- 오답 차감/시간 만료와 해체 성공이 같은 단계면 만료 우선.
- 폭발 효과·강한 비행·기본2.4초(0.5~2.8초 제한) 뒤 기존 입구 복귀. 성공팀은 직접 영향을 받지 않지만 폭발 적을 잡고 있으면 함께 날아간다. 잡은 아군은 별도 강제 리스폰 대상이 아니다.
- 성공 폭발 범위는 확장한 맵 외곽 X±42, Z=-27~58, Y=-5~30. 만료 폭발은 해당 팀 전원.
- 문이 열린 뒤에도 테스트는 종료하지 않는다. 다음 씬 전환은 미구현이다.

## 조작·설정

| 키 | 기능 |
|---|---|
| Enter / Esc | 시작 / 메뉴·마우스 해제(타이머는 흐름) |
| WASD / Space / Shift | 기존 이동 / 점프 / 질주 |
| 좌클릭 / 우클릭 | 밀치기 / 잡기 |
| F | 공급대에서 도구 획득, 전선 앞에서 길게 절단 |
| H | 자기 판 전체 기물 공격 범위 힌트 |
| Tab / T | 다음 캐릭터 / 반대 팀 같은 번호 |
| 1 / 4 | 자기 / 상대 버튼 시험 배치 |
| 2 / 3 | 도구대 앞 / 입구 시험 배치. 자동 풀이 없음 |
| B / R / F3 | 대련 봇 / 입구 복귀 / 전체 초기화 |

Inspector: Rook Scale=0.6(Stop→Play로 적용), Time Limit=90, Cut Seconds=1.5, Wrong Wire Lock=2, Interact Distance=1.8. Time Limit/절단/잠금은 F3로 새 라운드 적용. 기존 Switch Delay, Solo Required Riders, Rocker Tilt/Speed, Success Blast Speed/Respawn Seconds 유지. Seconds Per Stage는 시험 씬에서 제거했다. Core의 이전 시간 작업 Step은 회귀 호환용이며 씬은 StepPuzzle만 호출한다.

- ChessTimerMinigame.Puzzle.cs: 실물 판·룩2/비숍1·케이블·도구/절단 시각·입력·시간 측정.
- Core/ChessWirePuzzle.cs: 룩/비숍 공격·기물 차단·유일 정답·연속 절단·중단·오답 잠금.
- Core/ChessTimerRules.cs: 물리 퍼즐 결과/오답 차감·동시 해체·만료 양 문 개방.

구조26·Core102·모의 세션39·런타임7 호환 컴파일 통과. 새 검사:8×8 유일 정답, 도구/거리 적격성·연속 유지·작업자 교대, 오답 잠금/중복 방지, 실제 퍼즐 결과의 동시 비교, 정지 타이머 오답 차감, 만료 양쪽 문, 시간만으로 자동 완료하지 않음. 기존 면적5배 검사는 이번 변경에 맞춰 두 정사각형/판 여유/외곽/경사 조건으로 수정했다.

**Unity/PhysX·실제 걸어서 진입·도구 표시·카메라·90초 체류시간은 미검증**. 현재 환경은 Unity Editor 없이 Unity2021 참조 DLL로 호환 컴파일한다. Editor/Input 코드는 검사 제외다. 게임 코드와 최종 시각/손맛 검증을 구분한다.
