# 체스 타이머 폭탄 미니게임 프로토타입

R110 · 2026-10-21. **단일 체스 타이머 위 난투 + 거대한 8×8 판에서 도구로 전선을 자르는 무작위 퍼즐 3단계**. 6 대 6 독립 오프라인 시험장이다. 기존 래그돌/스폰/타이머 위치를 유지하고 뒤쪽 해체 구역만 확장했다. 자동 해체는 제거했다. 온라인·실제 다음 코스 전환은 미연결이다.

팀 표시는 **왼쪽 백팀(기존 파란 팀), 오른쪽 흑팀(기존 빨간 팀)**으로 통일했다. 캐릭터·버튼 표시·진입로·출구·HUD/LCD·승리 문구에 적용한다. 전선은 번호와 빨강/파랑/노랑/초록/보라/주황으로 구분하며 색 자체가 정답을 뜻하지 않는다.

## 실행·첫 시험 순서

Unity 메뉴 **ChessFight → Minigames → Open Chess Timer Prototype**, 또는 `Assets/Scenes/ChessTimerMinigame.unity` → **Stop 후 Play → Enter**. 경기장은 실행할 때 생성되므로 Play를 다시 시작해야 새 지형이 나온다.

1. 선택 캐릭터는 기존 입구에 있다. 타이머 옆으로 돌아 **자기 팀 뒤쪽 해체 구역**으로 걸어간다. 양쪽 바깥 경사로는 기존 상단 난투용이다.
2. 정사각형 해체 구역 입구의 절단기 공급대 앞에서 **F를 한 번 눌러 절단기를 장착**한다. 손에 도구가 보이고 HUD에 절단기 보유 여부가 나온다.
3. 8×8 판 안으로 직접 들어가 룩2개·비숍2개와 네 전선의 위치를 읽는다. **H**는 자기 판의 전체 기물 공격 범위 힌트 표시/숨김이다.
4. 안전한 칸에 놓인 전선 장치 가까이에서 **F를 7초 연속 유지**한다. 현재 단계의 안전 전선을 모두 자르면 해당 팀만 다음 단계로 전환한다. 3단계 안전 전선4개까지 모두 잘라야 최종 해체 성공이다.
5. 오답은 **고정5초 차감 + 장치2초 잠금**. 이미 자른 전선을 다시 잘라 중복 페널티를 받지 않는다. 시간 정지 중에도 오답 차감은 적용된다.
6. 해체 성공/폭발·입구 복귀·출구를 확인한다. HUD의 경과 시간과 해체 완료 시간을 기록한다. **이동시간 측정에는 숫자키 시험 배치를 사용하지 않는다.** B로 대련 봇을 끄면 퍼즐만 보기 쉽다.

도구 없이/기절/공중/거리 밖에서는 절단하지 못한다. 키를 놓거나 범위를 벗어나거나 캐릭터/대상 전선을 바꾸면 절단 진행을 초기화한다. 공급대는 각 팀원의 도구를 보충할 수 있다. 폭발·리스폰·시험용 순간 배치 시 도구를 잃고 다시 얻어야 한다. 도구는 장착형 시각 모델이며 자유 물리 집기/던지기 방식은 아니다.

오답은 제한시간 설정이나 남은 시간과 관계없이 전선 하나당 고정5초 차감한다(R107). 같은 틱에 오답을 여러 개 자르면 개수만큼 차감한다.0초 이하면 만료 폭발/양문 개방으로 이어진다.

## 이번 문제와 공정성

모든 단계에서 **공격받지 않는 전선**을 자른다. 중간에 나온 “공격받는 전선” 요청은 사용자 정정으로 폐기했다. 안전한 전선은 아래 개수만큼 정확히 생성하고 모두 잘라야 완료된다. 각 단계의 나머지2개는 공격받는 오답이다.

| 단계 | 기물 | 전체 전선 | 잘라야 할 안전 전선 |
|---|---|---|---|
| 1 | 룩2·비숍2 (4개) | 4개 | 2개 |
| 2 | 룩2·비숍2·나이트1·폰6 (11개) | 5개 | 3개 |
| 3 | 룩2·비숍2·나이트2·폰8·퀸1 (15개) | 6개 | 4개 |

- Play/F3마다 세 단계의 기물/전선을 새로 생성한다. 2단계의 원래 룩/비숍4개는 그 판1단계 위치를 유지한다. 3단계는15개 전체 위치를 새로 뽑는다. 폰은2단계6개 열에1개씩, 3단계8개 열에1개씩 분산한다.
- 기물과 전선은 겹치지 않으며 안전2/3/4개·위험2개를 확인한 뒤 전선 순서(색)를 섞는다. 무작위 시도 한도 뒤에는 검증된3단계 배치/좌우 반전과 새 전선 선택을 사용해 불가능한 문제나 무한 재시도를 막는다. 일반1단계 생성은 이전 기물 칸을 피하며, 보장 생성은 배치 전체 변화를 보장한다.
- 정답 하나를 자르면 **정답 절단 개수**가 증가하고 잘린 전선은 유지된다. 마지막 정답을 자를 때만 단계가 완료된다. 오답은5초 차감/2초 잠금이며 정답 개수에는 포함되지 않는다. 이미 자른 전선의 중복 점수/중복 페널티는 없다. 작업 중단은 현재7초 절단 진행만 초기화하고 완료한 전선은 보존한다.
- 각 팀은 독립적으로 진행한다. 1·2단계 완료 시 문/성공 폭발 없이 다음 단계로, **3단계 완료 시 최종 해체 성공**으로 기존 승패/폭발 규칙에 제출한다. 시간 만료는 여전히 성공보다 우선한다.
- 룩/비숍/퀸은 다른 기물에 막힌다. 퀸은 직선+대각선, 나이트는 L자로 뛰어넘기, 폰은 앞 대각선 한 칸만 공격한다. 실제 기물은 이동하지 않는 고정 퍼즐이다.
- 백팀 판에는 흑 기물, 흑팀 판에는 백 기물이 나온다. 랭크 반전으로 두 팀의 실제 배치/거리/정답을 동등하게 맞춘다. 흑 폰 랭크 감소·백 폰 랭크 증가가 모두 **출구(입구 반대, 월드+Z)**를 향하며 금색 방향 표시/액자와 일치한다.
- 단계 전환 시 해당 판의 플레이어만 도구를 유지한 채 입구(Z=10.1m)로 옮겨 새 충돌에 끼이지 않게 한다. 타이머 위 사람과 상대 팀 진행은 유지한다. 타이머 재충전은 없다.

제한시간60초·전선 하나당 연속 절단7초·오답 고정5초로 설정한다(R107). 총9개 정답을 혼자 자르면63초지만 서로 다른 전선은 여러 명이 동시에 작업할 수 있다. 같은 전선에 여러 명이 붙어도 가속하지 않는다. Rook Scale은 퀸을 포함한 모든 기물에 적용한다. 자동 검사에서는2,000판×3단계의 구성/안전 개수/별도 공격 계산/반전 동등성, 보장 생성500판, 정답 누적/중단/중복 절단/오답/최종 완료를 확인한다. Unity 실제 난이도/이동시간/전환은 별도 확인 대상이다.

## 절단 지원 봇 (R107)

각 팀의4·5·6번 캐릭터, 기본3명이 Enter 시작 후 자동 지원한다. 기존2·3번은 발판에 남고1번은 기본 직접 조작 캐릭터다. Inspector의 **Cutting Helpers Per Team(0~3)**으로 지원 인원을 조절한다.

- 지원 봇은 타이머/경사로 바깥으로 걸어 도구대에 가서 절단기를 얻고, 기물과 다른 전선 받침대를 피하는 반 타일 격자 경로로 이동한다. 도구대 옆으로 돌아 판에 진입한다.
- 프로토타입용 봇은 공격 계산에서 안전한 전선을 직접 골라 정답만 작업한다. 실제 사람처럼 퍼즐을 추론하는 AI는 아니다. 진행 중인 다른 봇의 전선은 빼앗지 않고 각자 다른 전선을 맡는다. 남는 봇은 대기한다.
- 플레이어의 F 작업을 우선한다. 지원 캐릭터를 직접 선택하면 해당 캐릭터는 자동 조작을 멈추고 수동 입력을 받는다. 다른 캐릭터로 전환하면 다시 지원한다. 해당 봇을1/4키로 발판 역할에 배정하면 자동 지원에서 제외한다.
- 봇/플레이어 모두 도구·거리·접지·활동 상태를 만족한 채7초 연속 작업해야 한다. 전선별 진행과 절단 애니메이션을 따로 표시한다. 한 전선은 한 작업자만 인정하며 작업자가 바뀌면 그 전선의 진행이 초기화된다.
- 기절/거리 이탈/선택 변경으로 중단한 전선만 초기화한다. 오답 잠금2초는 팀 공통으로 적용하며 이미 완료한 전선은 유지한다. 단계 전환/F3에서 경로를 다시 계산하고, 폭발로 도구를 잃으면 다시 도구대를 찾는다.
- B는 상단 대련 봇만 켜고 끈다. 절단 지원 봇은 별도 설정이다. 메뉴/포커스 해제 중에는 지원 조작을 멈춘다(기존 타이머는 계속 흐름).

경로와 동시 절단 규칙은 자동 검사했지만 실제 래그돌 이동/팀원 충돌/전환 모습은 Unity 확인이 필요하다. 봇은 온라인에 연결하지 않은 독립 시험 씬 전용이다.

## 기물 이동 설명 액자

외벽에는 **기물 종류별 액자 하나**를 표시한다. 1단계는 룩/비숍2개, 2단계는 나이트/폰까지4개, 3단계는 퀸까지5개다. 같은 종류를 여러 번 설명하는 액자 대신 종류별 도식/설명을 보여준다. 중심 X=±41.64, Y=2.5, Z=18/24/30/36/42m이며 판 안을 향한다. 금색 칸은 공격 방향, 중앙 R/B/N/P/Q는 해당 기물이다. 나이트는 L자/뛰어넘기, 폰은 앞 대각선과 직진 공격 불가, 퀸은 직선/대각선과 기물 차단을 안내한다. 기존 액자 크기·글자 자동 맞춤을 유지한다.

글자 크기는 TextMesh의 폰트 해상도48과 월드 크기를 분리해 보정한다(R100). 액자 제목2.7×0.4m, 설명2.7×0.65m, 범례2.7×0.23m, 중앙 기호0.26×0.26m로 제한한다. LCD 인원은2.6×1.1m, 상태는 별도8.8×0.65m 프레임 안8.2×0.45m로 제한한다. 문구 변경 시 실제 렌더러 경계를 측정해 비율을 유지하며 축소한다. 실제 Unity 가독성은 재확인 대기다.

## 공간과 이동거리

- **스폰 유지:** 팀 중심 X=-15/+15, Z=-24~-25 부근. 기존 타이머/경사로도 이동하지 않았다.
- **해체 구역:** 팀별42×42m. 백팀 X=-42~0, 흑팀 X=0~42, Z=9~51. 중앙벽으로 분리하며 상단 난투를 막지 않는다.
- **체스판:** 한 칸4m, 8×8=32×32m. 중심 X=-21/+21, Z=30. 양쪽 구역 안에5m 여유 동선이 있다.
- **도구대:** X=-21/+21, Z=11.5. **출구:** X=-21/+21, Z=51. 통과 판정은Z>52.
- **전체 외곽 범위:** X±42, Z=-27~58. 앞쪽 스폰 바닥/폭은 기존54m이며 뒤쪽만84m로 넓어진 형태다.
- **타이머:** 몸체22×10m, Coupled white rocker Scale=(1,0.7,1), 실크기20.4×1.4×8.5m, 중심Y=5·수평 윗면5.7. 양쪽 접근 경사/연결판 유지.

타일은 평평한 바닥 위 시각 표면이며 타일마다 충돌 턱을 만들지 않는다. 실제 걷는 바닥은 하나의 기초 Collider다. 기물/전선 받침대/벽은 물리 충돌을 가진다.

## 현재 제한시간과 전체 코스 목표

**90초는 완성형 코스의 목표 체류시간이며 첫 문제를 90초 동안 강제로 붙잡는 시간이 아니다.** 현재 프로토타입은 R107 요청에 따라 제한시간60초·연속 절단7초로 설정했다. 타이머는60초부터 시작하고 발판으로 정지할 수 있어, 실제 경과시간과 별도로 표시한다. 한 문제를 익힌 플레이어는 더 빨리 끝낼 수 있고, 시간을 계속 보호하면90초를 넘길 수도 있다.

현재 래그돌 기본 이동속도5.5m/s 기준, 기존 입구→도구대→전선→출구는 경로 선택에 따라 약80~110m로 **이동만 약15~20초**의 계산값이다. 질주9.6m/s·충돌·우회·관찰에 따라 달라진다. 기존 초견30~50초 가설은 절단1.5초 기준이었다. 절단7초로 변경했으므로 이동/관찰을 포함한 체류시간은 다시 측정해야 한다. Unity 실측값은 없다.

완성형은 이동/도구15~20초 + 쉬움10~15초 + 보통20~25초 + 어려움25~30초 + 마무리5초로 **75~95초**를 초기 예산으로 잡는다. 다음 문제의 전선 위치를 바꿔 이동과 관찰을 섞되 왕복만 강요하지 않는다. 현재는3단계와 총9개 정답 절단을 구현했다. 혼자 작업하면 절단만63초이며, 봇3명이 서로 다른 전선을 병렬 작업하면 순수 절단 시간은 단계별7/7/14초가 이론상 최소다. 실제 이동/전환/충돌 시간을 포함한 체류시간을 측정해야 한다.

## 타이머 인원·난투

실제 윗면 접촉 사람을 팀 소속과 무관하게 위치한 쪽에 한 명씩 센다. 넘어진 몸도 포함하고 팔다리 중복/공중 접촉은 제외한다. 중앙선은 골반 위치로 한쪽만 센다. 많은 쪽 버튼 하강·시간 정지, 적은 쪽 상승·시간 감소. 동수면 수평·양쪽 감소. 기본 안정시간0.35초, 기울기최대±3°.

백측4:흑측2에서 백팀1명이 흑측으로 공격하면3:3으로 자기 시간도 흐른다. 두 명이 넘어가면2:4로 상대 시간이 멈춘다. 상단은 열린 공간이라 밀치기/잡기로 떨어뜨릴 수 있다. 아래 중앙벽은 좌우 직접 이동을 막지만 완전한 팀 출입 제한은 아니며 등반/상단 낙하 우회는 실기 점검 대상이다.

## 문·폭발·결과

- 한 팀 3단계까지 해체 성공: 그 팀 문 열림·처음 성공한 팀 승리·맵 안 상대 팀 폭발. 나중에 상대가 해체해도 최초 승자에게 보복 폭발하지 않는다.
- 동시 해체: 같은 물리 업데이트에서 완료하면 남은 시간이 많은 팀 승리·적은 팀 폭발. 시간 차이0.001초 이하면 양 팀 폭발. 양쪽 문 열림. 로컬 시험은 한 캐릭터만 직접 조작하므로 동시 제출은 Core 자동 검사로 검증하며 온라인 다인 입력은 미연결이다.
- **한 팀 타이머 만료: 해당 팀 전원 폭발 + 양 팀 문 즉시 열림. R92 정정을 코드에 반영했다.** 문 개방과 해체 종료 상태를 분리하여, 상대 퍼즐/타이머는 계속 진행할 수 있다. 만료 팀은 재충전하지 않는다.
- 오답 차감/시간 만료와 해체 성공이 같은 단계면 만료 우선.
- 폭발 효과·강한 비행·기본2.4초(0.5~2.8초 제한) 뒤 기존 입구 복귀. 성공팀은 직접 영향을 받지 않지만 폭발 적을 잡고 있으면 함께 날아간다. 잡은 아군은 별도 강제 리스폰 대상이 아니다.
- 성공 폭발 범위는 확장한 맵 외곽 X±42, Z=-27~58, Y=-5~30. 만료 폭발은 해당 팀 전원.
- 문이 열린 뒤에도 테스트는 종료하지 않는다. 다음 씬 전환은 미구현이다.

## 기물 모델 (R108)

퍼즐 판의 폰·룩·비숍·나이트·퀸을 전용 FBX 메시로 교체했다. 룩은 성벽형 탑, 비숍은 실제 홈이 파인 머리, 나이트는 말머리/귀/갈기, 퀸은 왕관으로 구분한다. 흑백 몸체와 금속 장식을 공유 재질로 적용하고 이름과 칸 좌표를 표시한다. [실제 메시의 Blender 렌더](CHESS_TIMER_PIECES.png)는 Unity 화면 캡처가 아니다.

원본 제작 스크립트: `Tools/Art/build_chess_timer_pieces.py` (Blender 4.3, `blender -b --threads 6 --python Tools/Art/build_chess_timer_pieces.py`). 결과: `Assets/Resources/ChessTimerPieces/{Pawn,Rook,Bishop,Knight,Queen}.fbx`. `ChessTimerMinigame.PieceArt.cs`에서 로드하며 누락 시 기존 단순 도형으로 대체한다. 모델 폭을2.8m로 정규화한 뒤 기존 `rookScale`(기본0.9, R109)을 적용한다. 기물당 하나의 단순 BoxCollider를 사용하여 장식에 봇이 걸리지 않게 한다. FBX 메시와 런타임 재질은 공유하며, 기존 판 재생성 경로에서 인스턴스를 정리한다. 공격/퍼즐 규칙은 그대로다.

구조26·Core108·모의 세션39 및 런타임7개 호환 컴파일 통과(Input/Editor 제외). 모델 재수입과 Blender 렌더를 확인했다. Unity에서 실제 재질·조명·카메라 시점·봇 이동은 아직 미확인이다. Stop 후 Play로 새 모델을 생성한다.

R109: 사용자가 Unity에서 기물 눕힘/작은 크기를 보고했다. 인스턴스의 `localRotation`을 identity로 덮어쓰던 부분을 제거하여 FBX의 축 보정 회전을 보존한다. 수직 자세에서 폭을 정규화하고 코드/씬 모두 원래 기준0.9배로 설정했다(직전0.6배 대비1.5배). Unity 재확인 대기.

## 출구 합류 통로 (R110)

각 팀 문(x=±21, z=51)에서 폭6m 진입로를 지나 z=62의 공용 합류 발판으로 나온다. 양쪽에서 중앙으로 이동하면 폭8m 통로(z=66~88)가 하나의 다음 스테이지 아치(z=86)로 이어진다. 바닥은 높이0으로 연결되고 가장자리는 난간으로 보호한다. 입구 뒤에는 테스트용 발판(z=88~96)이 있다. 기존 문 개방/팀 통과 판정은 유지하며 실제 다음 씬 전환은 미연결이다. Stop→Play 후 양 팀 문이 열린 상태에서 직접 걸어 접합부를 확인한다.
