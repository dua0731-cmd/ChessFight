# 체스 타이머 폭탄 미니게임 프로토타입

R89 · 2026-10-17. **실제 체스 시계처럼 한 몸체에 두 시간창과 서로 연동되는 좌우 버튼**이 있다. 같은 타이머 위에서 싸우며, 공격하러 상대 쪽으로 이동하면 우리 시간 보호를 잃을 수 있다는 기획을 시험한다. R85의 두 타이머/사이 연결 다리 구성은 제거했다. 독립 오프라인 시험장이다.

## 실행

Unity 메뉴 **ChessFight → Minigames → Open Chess Timer Prototype**, 또는 `Assets/Scenes/ChessTimerMinigame.unity` → Play → Enter. 업데이트한 배치를 보려면 Play를 종료하고 다시 실행한다. 경기장/타이머/기존 래그돌12명은 실행 시 생성된다. 기존 캐릭터 프리팹·tuning·LabCamera·PhysicsProfile을 사용한다. 정식 경기·Steam 동기화·다음 맵 로딩은 연결하지 않았다.

## 핵심 의도와 판정

- 왼쪽은 청팀 시간 버튼, 오른쪽은 홍팀 시간 버튼이다. 실제 윗면 접촉이 있는 플레이어를 **소속과 무관하게, 몸이 위치한 쪽에** 한 명씩 센다. 넘어진 몸도 포함한다.
- 여러 팔다리가 닿아도 한 명이다. 중앙선을 걸친 사람은 골반 위치로 한쪽에만 배정한다. 공중/옆면/밑면 접촉은 제외한다. 기울어진 스위치의 로컬 윗면 기준으로 판정한다.
- 사람이 많은 쪽이 내려가고 반대쪽은 올라간다. 내려간 쪽 시간은 정지하고 올라간 쪽 시간은 감소한다. 동수면 수평으로 돌아가며 두 시간이 감소한다. 우세 변경에는0.35초 안정 시간이 있다.
- **청측4명·홍측2명에서 청팀1명이 홍측으로 공격하면3:3으로 청팀 시간도 흐른다. 두 명이 건너가면2:4로 홍팀 시간이 정지하고 청팀 시간이 흐른다.** 공격에 성공해 적을 떨어뜨리는 이득과 자기 시간 보호를 포기하는 위험을 선택한다. 상대를 밀치거나 잡아 떨어뜨릴 수 있다.
- 좌우 스위치는 독립 승강기가 아니다. 하나의 Rigidbody 상단 스위치를 중앙 축에서±3도 기울여 양쪽이 반대 방향으로 움직인다. 이동 표면은 실제 회전 변위/각속도를 기존 래그돌에 전달한다.

## 공간과 외형

54×54m(2916㎡) 바닥은 유지한다. 최초24×24m 대비 면적5.0625배이며 가로·세로 각각5배는 아니다. 중앙에 **검정 둥근 타이머 몸체 하나**, 크림색 상단 양쪽 버튼, 전면 LCD 두 칸, 가운데 작은 조작 버튼을 둔다. 좌우에 청색/코랄색으로 진영을 표시하며 LCD에는 해당 시간과 그쪽 전체 인원이 표시된다.

몸체22×10m, 상단 스위치 원본 메시20.4×2×8.5m(X/Y/Z)에 Coupled white rocker의 Transform Scale=(1,0.7,1)을 적용했다. 실제 크기20.4×1.4×8.5m, 중심Y=5m, 수평 윗면Y=5.7m다. 장식·충돌·시험 배치·진입 연결판도 축소 크기를 따른다. 상단 두 진영 사이에는 벽이나 별도 다리가 없다. 같은 연속 상판에서 중앙선을 건너가 싸운다. 앞뒤 가장자리에 난간이 없어 지상으로 떨어질 수 있다.

양쪽 바깥 진입 경사로는 폭5m·수평길이21.3m·높이5.7m(약15도)다. 기존 래그돌 미끄럼 기준20도보다 낮다. 진입 연결판은 스위치 끝 높이를 따라 회전/길이를 조절하여 어느 쪽 버튼이 올라가도 단차 없이 연결하도록 했다. 실제 방향키 진입/운반은 Unity에서 재확인해야 한다. 공통 래그돌 물리 설정은 수정하지 않았다.

하부 해체 구역에는 중앙 X=0에 두께0.5m·높이4.5m 벽을 배치했다. Z=7.75~23.25로 타이머 뒤 몸체와 출구 중앙벽에 맞닿아 지상에서 좌우 해체 장치 사이를 바로 건너지 못하게 한다. 상단 스위치 뒤끝(Z=7.25)과 분리하여 상단 난투 동선을 유지한다. 별도의 팀 출입 제한은 없으며 등반/상단 낙하로 우회할 수 있는지는 실기 확인 대상이다.

## 조작

| 키 | 기능 |
|---|---|
| Enter | 라운드 시작 |
| WASD / Space / Shift | 이동 / 점프 / 질주 |
| 좌클릭 / 우클릭 | 기존 밀치기 / 잡기 |
| F 길게 | 타이머 뒤 지상의 활성 해체 장치에서 작업 |
| Tab / T | 다음 팀원 / 상대 팀 같은 번호 선택 |
| 1 / 4 | 선택 팀원을 자기 쪽 / 상대 쪽 버튼 위에 시험 배치 |
| 2 / 3 | 자동 해체 담당 배치 / 대기 위치 배치 |
| B | 선택하지 않은 버튼 담당의 간단한 대련 켜기/끄기(기본 켜짐) |
| R | 출발 지점 복귀(재정비 중 불가) |
| F3 | 라운드 초기화·설정 다시 읽기 |
| Esc | 마우스 해제/복귀. 타이머는 계속 흐름 |

숫자키는 혼자 시험하기 위한 **순간 배치**다. 자동 해체 담당은 다음 단계 장치로 순간 이동한다. 직접 WASD로 움직이면 선택 캐릭터의 자동 역할을 해제한다. 초기 배분은 팀별 버튼2명·자동 해체1명·대기3명이다. B 대련은 완성형 전투AI가 아니라 상대에게 접근하고 밀치기를 반복하는 시험 도우미다. 떨어진 도우미는 지상에서 기다린다. 정확한 인원/시간 비교 시 B로 끈다.

## 해체·폭발·출구

기본 제한시간45초. PAWN → KNIGHT → ROOK를 순서대로 F 길게 누르기로 해체한다. 단계당10 인·초, 최대3명까지 속도 합산. 장치를 떠나도 현재 작업량 유지. 인원 배분 검증용 단순 작업이며 별도 배선/문양 퍼즐은 아직 없다.

0초면 그 팀6명에게 날아가는 속도와3초 넉다운을 적용한다. 완료 단계는 보존하고 현재 단계 작업량만0으로 만든다. 시간을 다시45초로 채우고 넉다운3초+여유3초 후 재개한다. 재정비 중 해당 팀 작업과 시간 감소는 정지하지만 상단에 남은 몸은 양쪽 인원 비교에 계속 포함한다. 재정비 후 시험 담당 위치로 돌아간다. 시간 만료와 해체 완료가 같은 물리 단계면 폭발 우선이다.

해체 완료 시 그 팀 문이 열리고 그 팀 시간이 영구 정지한다. 완료한 순간 한 번만 맵 안 적팀에게 강한 발사(기본 수평/수직22m/s)·기절과 12개 발광 불덩이가 퍼지는0.9초 폭발 효과를 적용한다. 적팀은 기본2.4초 후 최초 입구 대기 위치로 돌아와 정상 상태로 복귀한다. Success Respawn Seconds는0.5~2.8초로 제한한다. 비행 중 시험 배치/자동 해체/낙사 복귀를 막아 예약된 리스폰이 실행되게 한다. 팀 소속 기준이므로 상대/자기 발판 어디에 있어도 적만 맞는다. 범위는 골반 위치 X/Z=±27m, Y=-5~30m이며 범위 밖과 아군은 제외한다. 성공 폭발은 적의 시간/해체 진행도를 초기화하지 않는다. 입구 복귀 후 직접 다시 진입한다. 성공팀은 직접 효과를 받지 않는다. 단, 폭발 직전 적을 실제 손으로 잡고 있던 사람은 잡기 연결이 해제되더라도 같은 발사 속도를 한 번 전달받는다. 잡은 사람에게는 성공 폭발 효과·강제 기절·예약 리스폰을 적용하지 않는다(충돌/낙사는 기존 물리 처리). 동시 완료면 양 팀 모두 폭발을 받지만 양쪽 문은 열린 채 유지된다. 문 뒤 통과 인원을 표시하며 실제 다음 씬으로 이동하지는 않는다. 양 팀 완료 후에도 이동·싸움·시험 배치(완료된 해체 역할 제외)를 계속할 수 있고 자동 종료하지 않는다. 기절 중 시험 배치/R 복귀로 기절을 취소할 수 없으며 F3는 전체 초기화다. 한 팀 완료 후 남은 팀은 자기 버튼 위2명 이상이면 시간을 멈출 수 있다. 이때도 적아군 구분 없이 남은 쪽 인원을 센다.

## 설정·확인

루트 Inspector: Time Limit, Seconds Per Stage, Switch Delay, Stun Seconds, Retry Grace, Blast Speed, Solo Required Riders, Interact Distance, Sparring Bots. 성공 폭발은 Success Blast Speed와 Success Respawn Seconds로 조절한다. 규칙 변경은 F3로 적용한다. Rocker Tilt(0~3°), Rocker Speed(°/초)는 상단 기울기/전환 속도다. 45초는 조작 확인용 여유값이며 압박/폭발 테스트는10~15초로 줄일 수 있다.

1. B를 끄고 각 버튼에 같은 인원 배치 → 수평·두 시간 감소.
2. 한쪽에1명 추가 → 해당 버튼 하강·반대 상승·각 시간 상태 확인.
3. 양쪽 경사로에서 **점프 없이** 진입 → 낮은/높은 버튼 모두 접근 연결판을 통해 통과.
4. 청측4:홍측2를 만들고 청팀을1명·2명씩4로 상대 쪽에 보냄 →3:3/2:4 및 청팀 시간 손실 확인.
5. 중앙선 걸침·넘어진 몸·팔다리 중복·점프/밀쳐져 추락 → 총 인원 중복/잔존 없음.
6. B 대련·직접 밀치기/잡기·해체·폭발·문·F3 확인.

## 코드와 자동 검사

- `Core/ChessTimerRules.cs`: 인원 우세·시간·해체·폭발 규칙.
- `ChessTimerMinigame.cs`: 입력·캐릭터·시험 배치·UI.
- `ChessTimerMinigame.Arena.cs`: 단일 타이머/상단 연동 회전·높이를 따르는 진입 연결판·LCD 메시.
- `ChessTimerPlate.cs`: 공유 상판 접촉 인원을 고유 캐릭터로 합친 뒤 좌우 분류.

구조26·Core91(완료 이벤트 1회·상대 진행 지속·동시 완료 회귀 포함)·모의 세션39·7개 런타임 어셈블리 컴파일 통과. 검사 도구는Unity2021 참조 DLL로 호환 컴파일하며 Editor/Input은 제외한다. **실제 Unity6 화면·접촉·경사로 통과·난투·온라인은 미검증**이다. 두 타이머가 하나로 합쳐졌는지와 양쪽이 반드시 반대로 움직이는지는 Unity에서 확인한다.
