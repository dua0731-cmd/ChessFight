# 작전실 → 총지휘부 통합 프리팹 (R118)

2026-11-02. `Assets/Scenes/GiantChessCourse.unity` → **Play → Enter**로 실행한다. 씬에는 `Assets/Maps/RoyalPalace/WarRoomComplete.prefab` 인스턴스 하나가 들어 있다. 같은 12명으로 작전실을 통과한 뒤 총지휘부의 거인 체스판에 진입한다. 오프라인 프로토타입이며 자동 랜덤 조립·멀티플레이는 미연결이다.

## 저장된 공간

- **작전실:** 기존 6개 진행 구간을 외벽·천장·부서별 칸막이로 둘러쌌다. 벽면 전쟁 지도와 왕실 군기, 문서 보관대, 전술 교본, 인장·잉크병, 포획 병력 전시대를 배치했다. 움직이는 밀기 장치에는 벽 안쪽 공간을 확보했다.
- **총지휘부 앞:** 두 번 꺾이는 전실과 근접 자동문으로 외부에서 체스판·거인을 바로 보지 못하도록 구성했다. 지도와 보관장으로 가림벽을 꾸몄다. 문 주변에 몸이 있으면 열린 상태를 유지한다.
- **총지휘부:** 거대한 작전 탁자, 지휘관 의자 두 개, 지도·군기·지휘봉·문서 소품, 높은 벽과 격자 천장. 현재 체스판은 128×128m(한 칸16m)다.

벽·천장·소품·미리보기 체스판은 프리팹에 저장되어 Play 전에도 편집할 수 있다. 실제 체스 기물·거인·판정 타일·래그돌은 Play 때 생성되며 미리보기 판은 비활성화된다. 옛 `GiantChessWarRoom` 환경 생성 컴포넌트는 통합 프리팹에 붙이지 않아 중복 생성을 방지했다.

## 추가한 장애물

| 구간 | 추가 장치 | 플레이 의도 / Inspector |
|---|---|---|
| 1 | 좌우 교대 명령서 압인기 | 경고를 보고 빈 쪽으로 이동. CommandStampPress의 Warning/Slam/Hold/Rest Seconds, Raised Height, Push Force |
| 2 | 좌우 지휘봉 | 휘두르는 타이밍에 통과. CommandPointerSweep의 Swing Angle, Period, Phase Offset, Push Force |
| 3 | 기사 사이 지도실 돌풍 | 안전 지점에서 기다렸다가 전진. 기존 AirVent 설정 사용 |
| 4 | 상층 시간차 관문 | 좁은 회랑에서 개방 시점 선택. 기존 ClockworkGate 설정 사용 |
| 5 | 추가 지휘봉 | 슬라이딩 벽에 들어가기 전에 간격 확보 |
| 6 | 전폭 압인기 | 마지막 다리 뒤에서 무작정 전진하지 않고 경고를 읽도록 구성 |

압인기 머리에는 고체 충돌체를 두지 않았다. 착지 판정 영역 안의 캐릭터를 주기당 한 번 밀치며 래그돌이 바닥과 머리 사이에 끼는 구조를 피했다. 공통 Obstacle/ObstacleMotion 구조를 사용하고 개별 수치는 해당 클래스에 직렬화했다. 자동문은 이 오프라인 씬의 근접 상태 기반 장치다.

## 편집과 재생성

통합 편집은 **WarRoomComplete 루트**를 선택한다. 원본 `Courses/3-1_RoyalWarRoom.prefab`과 나머지 4개는 제작용 원본으로 보존되며 현재 씬에 별도 인스턴스로 배치되지 않는다. 통합본은 원본의 확장 복사이므로 원본 편집이 자동 전파되지 않는다.

`python3 Tools/RoyalPalace/build_war_room.py --check`는 저장 결과를 읽기 전용으로 비교한다. `--overwrite`는 **통합 프리팹과 GiantChessCourse 씬을 재생성**하므로 Unity에서 직접 수정한 내용을 먼저 생성기에 반영해야 한다. 기존 5개 원본은 `build_courses.py`가 관리한다.

프리팹은 **Scale (1,1,1), Y축 회전** 기준이다. 루트 이동/Y축 회전을 따라 체스 좌표·스폰·밀치기·봇 방향이 변환되도록 수정했다. 비균일 크기/기울어진 루트는 지원 범위가 아니다. 저장 벽은 16m 타일 기준이므로 Tile Size 변경 시 환경도 함께 편집해야 한다.

체스 설정은 기존 사용자 값 Replay Speed5 / Knockback12 / Upward9 유지. 메타데이터 Target Seconds360은 편집용 목표값이며 플레이 제한시간·실측 완주시간이 아니다. 3체크포인트, 개별 복귀, F3 초기화, 첫 총지휘부 진입 후 기보 시작을 유지한다. 봇은 단순 경로 추종이므로 새 장애물의 완주를 보장하지 않는다.

## 검사와 남은 확인

구조37·Core113·모의 세션40 통과, 런타임7개 Roslyn 컴파일 통과(Input/Editor 제외). 저장 프리팹 참조, 전실 보행 바닥/벽 간격, 총지휘부 시야 차단, 문 점유 높이, 압인기 비압착 구조, 스폰 간격을 검사했다. 두 생성기의 --check도 통과했다.

**Unity 실행·PhysX·실내 카메라·성능·밸런스는 미확인.** Unity에서 6구간 주행, 지휘봉 피격, 문 근처 넘어짐/다인 통과, 총지휘부 공개 시점, 실내 카메라, R/F3 및 루트 이동/Y축 회전 후 재실행을 확인해야 한다. 저장된 단순 소품은 최종 아트가 아니다.
