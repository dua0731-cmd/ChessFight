# 작전실 → 총지휘부 통합 프리팹 (R120)

2026-11-02. `Assets/Scenes/GiantChessCourse.unity` → **Play → Enter**로 실행한다. 씬에는 `Assets/Maps/RoyalPalace/WarRoomComplete.prefab` 인스턴스 하나가 들어 있다. 같은 12명으로 작전실을 통과한 뒤 총지휘부의 거인 체스판에 진입한다. 오프라인 프로토타입이며 자동 랜덤 조립·멀티플레이는 미연결이다.

## R120 정사각형 작전실 / 2~3분 목표

작전실 외벽 중심선 기준 **160×160m 정사각형**으로 정리했다. 앞쪽 문서 보관실도 같은 외곽 안에 포함된다. 총지휘부와 그 앞의 가림 전실은 별도 연결 공간이며 전체 프리팹은 계속 하나다.

주 동선은 기존 1→2→3→6구간으로 단축했다. 상층 승강/시간차 관문과 기병/슬라이딩 벽 구간은 통합본에서 비활성화하고 북쪽 횡단 통로로 연결한다. 해당 공간은 지휘관용 보조 브리핑 구역으로 꾸몄다. 전술 포격판·반대 위상 폰 대열·압인기·지휘봉·승인문은 유지한다. 체크포인트2도 새 횡단 통로로 옮겼다. 아래 R118/R119 목록은 당시 추가 이력이다.

**2~3분의 범위는 작전실 입구부터 총지휘부 문 안까지**다. 거인 체스판 통과는 포함하지 않는다. 일반 우회로의 경유점 길이는 약639m: 기본 이동5.5m/s로 순수 이동116초 + 장애물 대기/회피25~60초 ≈141~176초를 목표로 한다. 질주·협동 지름길은 더 짧고, 낙사·재시도는 더 길어진다. 실측 완주시간이나 3분 강제 종료가 아니다.

화면에 캐릭터별 작전실 경과 시간을 표시한다. Enter부터 측정, Esc/창 비활성화 중 정지, 총지휘부 진입 시 기록 확정. R 복귀는 누적 유지, F3은 기록 초기화 후 Enter로 재시작. 기본 코스 메타데이터150초, 전체 통합본240초는 편집용 목표다.

검사: 구조/로직46·Core113·모의 세션40·런타임7 컴파일 통과. 정사각 외곽·4개 활성 구간·새 횡단 통로의 바닥/벽 간격·체크포인트와 거리 예산 검사 포함. **Unity 실제 2~3분 달성 여부는 미확인**이며 화면 기록으로 정상 주행/실패 주행을 나눠 측정해야 한다.

## 저장된 공간

- **작전실:** 기존 6개 진행 구간을 외벽·천장·부서별 칸막이로 둘러쌌다. 벽면 전쟁 지도와 왕실 군기, 문서 보관대, 전술 교본, 인장·잉크병, 포획 병력 전시대를 배치했다. 움직이는 밀기 장치에는 벽 안쪽 공간을 확보했다.
- **총지휘부 앞:** 두 번 꺾이는 전실과 근접 자동문으로 외부에서 체스판·거인을 바로 보지 못하도록 구성했다. 지도와 보관장으로 가림벽을 꾸몄다. 문 주변에 몸이 있으면 열린 상태를 유지한다.
- **총지휘부:** 거대한 작전 탁자, 지휘관 의자 두 개, 지도·군기·지휘봉·문서 소품, 높은 벽과 격자 천장. 현재 체스판은 128×128m(한 칸16m)다.

벽·천장·소품·미리보기 체스판은 프리팹에 저장되어 Play 전에도 편집할 수 있다. 실제 체스 기물·거인·판정 타일·래그돌은 Play 때 생성되며 미리보기 판은 비활성화된다. 옛 `GiantChessWarRoom` 환경 생성 컴포넌트는 통합 프리팹에 붙이지 않아 중복 생성을 방지했다.

## R119 작전실 전용 장애물 추가

기존의 대기→직진 위주 진행에 **안전 경로 선택, 연속 횡이동, 협동 지름길**을 추가했다. 기존 작전실/총지휘부 한 프리팹에 저장했고 새 씬을 만들지 않았다.

| 장치 / 위치 | 동작과 의도 | Inspector 설정 |
|---|---|---|
| **전술 지도 포격판** / 3구간 진입 | 3×3 지도 칸에서 각 행마다 안전한 초록 칸 하나가 매 주기 옆으로 바뀐다. 나머지는 붉게 예고된 뒤 밀쳐진다. 가로 이동과 진입 시점 선택이 필요하다. | TacticalMapBarrage: Warning Seconds2.2, Strike Seconds0.35, Rest Seconds0.8, Push Force9, Upward Force2 |
| **병력 재배치 장벽** / 3구간 후반 | 폰 대열 두 줄의 3.5m 틈이 반대 위상으로 움직인다. 첫 줄을 통과한 뒤 다음 틈으로 이동한다. 줄 사이 이동 공간을 남겼고, 계속 안전한 직선 통로는 없다. | TroopFormationSlide: Travel Distance2.5(중심에서 좌우), Period6, Phase Offset0 / 0.5, Push Force7, Upward Force1 |
| **이중 승인문** / 마지막 문서 보관실 | 서로 다른 두 캐릭터가 두 인장 발판을 1.25초 유지하면 중앙 지름길이 8초 열린다. 혼자라면 왼쪽 금색 바닥선을 따라 상시 열린 서류 통로를 이용한다. | DualApprovalGate: Approval Seconds1.25, Open Seconds8, Open Distance4.5, Move Speed3 |

두 인장 발판은 팀 제한이 없다. 아군과 역할을 나누거나 상대를 발판에서 밀어내는 상황을 만들 수 있다. 문을 지나는 몸이 있으면 닫히지 않는다. 자동 봇은 우회로를 따라가며 발판 협동을 자동 수행하지 않는다. 혼자 승인문을 시험하려면 **B로 봇을 끄고 → 한 캐릭터를 첫 인장에 세운 뒤 → Tab으로 다른 캐릭터를 선택해 두 번째 인장에 세운다.**

포격은 주기마다 캐릭터당 한 번만 적용한다. 안전 칸에서 뻗은 팔만 위험 칸에 닿으면 맞지 않지만, 누운 몸은 실제 위험 칸에 겹치면 맞는다. 점프로 항상 피하는 것을 막기 위해 판정 높이는6m다. 초록 칸은 고정 휴식처가 아니므로 다음 경고를 확인해야 한다. 압인기/지휘봉 등 기존 장애물과 겹치지 않는 위치에 배치했다.

폰 대열의 이동 범위에 있던 장식 기둥·보관함을 통합본에서 정리하고, 두 번째 대열은 회전 구간 난간 앞에 배치했다. 승인 지름길의 중앙 바닥을 연결하고, 일반 우회로는 바닥 모서리를 자르지 않게 경유점을 추가했다. 화면 안내에 새 세 장치의 통과 방법을 표시한다.

세 클래스는 공통 Obstacle 계열이며 개별 SerializeField로 조절한다. 승인문은 **오프라인 상태형 장치**로 온라인 상태 복제는 미연결이다. 원본5개 코스 프리팹은 변경하지 않았다.

## 편집과 재생성

통합 편집은 **WarRoomComplete 루트**를 선택한다. 원본 `Courses/3-1_RoyalWarRoom.prefab`과 나머지 4개는 제작용 원본으로 보존되며 현재 씬에 별도 인스턴스로 배치되지 않는다. 통합본은 원본의 확장 복사이므로 원본 편집이 자동 전파되지 않는다.

`python3 Tools/RoyalPalace/build_war_room.py --check`는 저장 결과를 읽기 전용으로 비교한다. `--overwrite`는 **통합 프리팹과 GiantChessCourse 씬을 재생성**하므로 Unity에서 직접 수정한 내용을 먼저 생성기에 반영해야 한다. 기존 5개 원본은 `build_courses.py`가 관리한다.

프리팹은 **Scale (1,1,1), Y축 회전** 기준이다. 루트 이동/Y축 회전을 따라 체스 좌표·스폰·밀치기·봇 방향이 변환되도록 수정했다. 비균일 크기/기울어진 루트는 지원 범위가 아니다. 저장 벽은 16m 타일 기준이므로 Tile Size 변경 시 환경도 함께 편집해야 한다.

체스 설정은 기존 사용자 값 Replay Speed5 / Knockback12 / Upward9 유지. R118 당시 메타데이터 Target Seconds360은 편집용 목표값이며 플레이 제한시간·실측 완주시간이 아니다. 3체크포인트, 개별 복귀, F3 초기화, 첫 총지휘부 진입 후 기보 시작을 유지한다. 봇은 단순 경로 추종이므로 새 장애물의 완주를 보장하지 않는다.

## 검사와 남은 확인

구조/로직44·Core113·모의 세션40 통과, 런타임7개 Roslyn 컴파일 통과(Input/Editor 제외). 저장 프리팹 참조, 전실 보행 바닥/벽 간격, 총지휘부 시야 차단, 문 점유 높이, 압인기 비압착 구조, 스폰 간격을 검사했다. 두 생성기의 --check도 통과했다. R119 추가 검사는 실제 포격 클래스의 Mono 스텁 실행(639 assertion), 이동 대열의 전체 왕복 범위/상시 직선 우회 방지, 포격 격자/표시 참조, 승인문 우회로 보행 발자국/중앙 연결 바닥을 확인한다. 스텁 검사는 PhysX 실행이 아니다.

**Unity 실행·PhysX·실내 카메라·성능·밸런스는 미확인.** Unity에서 포격 타이밍·대열 사이 방향 전환·2인 승인/1인 우회·문에 넘어진 몸과 HUD 가독성, 6구간 주행, 지휘봉 피격, 문 근처 넘어짐/다인 통과, 총지휘부 공개 시점, 실내 카메라, R/F3 및 루트 이동/Y축 회전 후 재실행을 확인해야 한다. 저장된 단순 소품은 최종 아트가 아니다.
