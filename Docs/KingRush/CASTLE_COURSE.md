# R55 · 승격 집결 + 성벽 갈림길 / 판 뒤집기

2026-09-27, `JY-kingrush`. **사용자 추가 지시가 DESIGN §4.2의 선착순 미션 진입보다 우선한다.** 승격 구역은 빨강 장애물 코스의 끝이며 다음 파랑 미션과 벽으로 분리한다.

## 집결 진행 (사용자 확정)

1. 첫 코스는 승격 발판2개, 다음 코스는3개. 기존 1.5초 독점/쟁탈 규칙으로 자리를 결정한다. 양 팀을 합친 총 자리 수이며 팀별 정원은 아니다.
2. 해당 구간의 모든 승격 자리가 정해지면 **10초 카운트다운**. 벽은 계속 닫히고 다음 미션/능력은 시작되지 않는다.
3. 10초가 끝나는 **그 순간**, 아직 도착하지 못한 양 팀 인원을 승격 구역의 서로 떨어진 자리로 이동시킨다. 이미 도착한 사람은 이동시키지 않는다. 현재 구간 승격자는 기물 유지, 미승격자는 폰, 고정 킹은 킹이다.
4. 집결을 모두 처리한 다음 벽 충돌을 해제하고 벽이 위로 올라간다(0.8초 시각 연출). 각자가 파랑 입구를 지나면 능력이 켜지고 첫 입장부터 미션 시간이 흐른다.

물에 빠진 사람, 이전 미션의 선반에 잡힌 사람, 아직 이전 구간에 있는 사람도 집결 대상이다. 이때 오래된 물 복귀/포획 예약과 잡기 관절을 정리한다. 이전 미션의 승격은 다음 빨강 집결 전에 폰으로 되돌린다. 집결은 구간당 한 번이며, 나중에 R을 누르거나 물에 빠져도 다시 전원을 소환하지 않는다. 순간이동은 충돌 콜백 밖 Update에서 한다. 앞선 구간으로 이미 넘어간 사람을 뒤로 소환하지 않는다.

## 실행 / 혼자 시험

기존 메뉴 **ChessFight → King Rush → Open Opening Course → Play**. `KingRushOpening.unity`를 이어 확장했다. 로비의 KingRush/온라인 연결은 아직 이전 캡슐 버전이다.

- **F7:** 현재 빨강 구간의 승격 발판 위에 정지 더미를 배치한다. 즉시 문을 여는 치트가 아니라 **실제1.5초 승격→10초→미도착 양 팀 집결**을 시험한다.
- **F5:** 성벽 갈림길 시작으로 배치한다.
- **Shift+F5:** 시소 미션+반대편 무게추 더미. 혼자 올라가 출구까지 시험할 수 있다. AI는 아니다.
- **F4:** 기존 상자 미션. **F6:** 다음 개인 체크포인트(개발용, 갈림길 양쪽 체크포인트도 순서대로 이동).
- Tab 다른 말, R 체크포인트/해당 파랑 입구, F3 전체 초기화, 나머지 기본 조작 그대로.

F4/F5/Shift+F5는 개발용 구간 배치라 앞쪽 집결 벽을 생략한다. F7은 정상 집결을 시험한다. 단축키는 경기 전체를 초기화한다.

## 두 번째 코스: 성벽 갈림길

최종 아트가 아닌 **통과 가능성/선택/몸싸움용 블록아웃**. z220~392(전진172m), 양 갈래 간격20m. 기획의 약250m/1.5~2분을 확정 측정값으로 간주하지 않는다.

| 순서 | 위쪽 성벽길 | 아래쪽 해자길 |
|---|---|---|
| 갈림목 | 3.5m 벽을 기존 우클릭 등반으로 오름 | 움직이는 금색 발판으로 물 틈 건넘 |
| 중간 | 폭3m 임시 다리 → 흔들리는 철퇴 | 좌우로 미는 벽 → 주기적으로 들어 올리는 도개교 |
| 합류 | 경사로 내려온 뒤 폭4m X 교차 다리에서 만남 | 같은 높이에서 정면 교차 |
| 마지막 | 함께 시간제 성문 → 룩/비숍/나이트 승격3자리 →10초 집결 | 동일 |

**밧줄 그네는 기준 브랜치에 없어 임시 좁은 다리로 표시했다.** 공통 물리/등반/갈고리나 다른 채팅의 미완성 밧줄을 가져오지 않았다. 체크포인트는 각자 밟은 구간만 기록한다. 해자는 기존5초 부유 후 개인 복귀다. 레벨 길이·낙하 비용·최종 아트/음악은 사용자 플레이 후 조정한다.

## 두 번째 미션: 판 뒤집기

- 물 위24×24m, 8×8 체스판. 남북 축을 중심으로 좌우 기울기. 중앙1m는 무게0.
- 판 위에 서 있거나 누워 지지된 몸을 사람당 한 번 세며 판 좌표 동쪽 거리+, 서쪽−. 물/잡혀 들림/대포 비행/공중은 제외. 고정 석상 위에 서 있어도 센다. **벽 등반으로 손에만 매달린 몸의 무게 전달**, 미구현 기물 탑승/매달림은 후속이며 완료로 주장하지 않는다.
- 목표=무게 합÷60×25°, 최대±25°, 최대초당8°. 움직이는 판의 접점 속도를 기존 캐릭터에 제공한다. 반복 장애물과 달리 플레이어가 만드는 **방장 소유 미션 상태**이며 온라인에 연결할 때 각도/진행 복제가 필요하다.
- 백팀 왼쪽/흑팀 오른쪽 북쪽3m 턱. 자기 끝이15° 올라가면 자기 팀 통행,12° 미만이면 닫힘. 120초부터10°/7°로 완화(3° 간격 유지).
- 판의 높은 쪽은20°부터 미끄러짐 보조 힘. 고정 석상을 잡고 버틸 수 있다. 공통 마찰/캐릭터 튜닝은 바꾸지 않는다.
- 자기 팀 **서로 다른4명**이 높은 출구를 지나면 다음 빨강 문 개방. 앞서 도착한 사람은 턱 위 대기 공간에서 나머지를 기다린다. 같은 몸 반복 통과는 득점하지 않으며 킹도1명이다. 높은 턱으로 직접 날아오는 대포 착지도 허용한다.
- 최초 완료20초 뒤 또는 미션150초에 두 구제 경사 다리를 제공한다. 최초 완료20초 뒤 상대의 다음 빨강 문도 개방. 150초 다리만 제공됐을 때는4명 완료 조건을 유지한다.
- 다음 빨강 문을 통과하면 비킹은 폰. **왕의 계단/결승은 아직 없으며 두 번째 통과를 경기 승리로 처리하지 않는다.**

## 자산/검사

첫 코스11프리팹을 재생성하지 않고 `11_RallyWall`~`17_CastleWater`7개를 추가했다. `09_Exit`의 끝 벽 비활성화/문구는 씬 인스턴스의 명시적 변경만 적용했다. 씬 확장은 중복 생성하지 않는다. Core의 집결/시소 규칙, Gameplay의 벽/판/출구, 랩의 모드 연결은 기존 어셈블리 경계를 따른다. Steam 프로토콜/패킷 변경 없음.

### 자동 검사 기록 (2026-09-27)

- Core **56개**, 모의 세션 **20개** 통과. 실제 Unity 6000.3.11f1 DLL로 전 어셈블리 컴파일 통과. Steam 실접속 검사가 아니다.
- 최종 Windows 빌드9, 1280×720의 전체 코스 검사 **68 통과 / 0 실패**, 이어 실행한 기존 기능 시험장도 **80 통과 / 0 실패**. `-kingRushOpeningTest -kingRushTest`. 아래 집중 검사와 순서를 달리해 기존 코스를 먼저 거친 경우까지 재시험했다.
- Windows 빌드8, 1600×900의 새 구간 집중 검사 **34 통과 / 0 실패**, 이어 실행한 기존 기능 시험장 **80 통과 / 0 실패**. `-kingRushOpeningTest -kingRushCastleOnly -kingRushTest`.
- 첫/둘째 승격 모두 실제 발판 점유부터10초까지 기다린다. 종료 직전 물에 빠진 킹과 이전 미션 포획자를 포함해 모으고, 승격/도착자 위치 유지·뒤늦은 재소환 없음까지 검사한다.
- 실제 이동/잡기/점프 입력으로 왕복 발판 탑승→이동→하차, 미는 벽/도개교/X다리/성문, 위쪽 등반/좁은 다리/철퇴, 시소 중앙 진입/높은 턱/구제 다리를 통과했다. 공중 몸 무게 제외와 지지된 래그돌 포함도 검사한다. 4명 완료 조건은 별도 위치 배치로 보완하며 12인 사람이 동시 플레이한 결과가 아니다.
- 중간 실패를 통해 발판 길이/접근 높이, 통로를 막던 안내판, 구제 경사의 연결 위치를 수정했다. 시험 입력도 발판을 기다려 탑승한 뒤 미리 앞으로 이동하고, 독립 코스 시험 사이에는 물 복귀 예약까지 초기화하도록 고쳤다. 공통 물리 튜닝은 변경하지 않았다.
- 빌드8 전체 순서 검사에서는 **67 통과 / 1 실패**: 시소 출구의 수평 위치에 도달했지만 아직 높이6.45m로 공중에 있어 계수를 너무 빨리 검사했다. 빌드9의 시험은 최대4초 안에 **실제 착지·물에 빠지지 않음·1명 통과**를 모두 요구한다. 판정 범위를 넓히거나 점프 높이를 낮추지 않았다.
- 기존11개 프리팹·공통 Pawn/Camera/튜닝·소드파이트·네트워크/패키지 설정 변경 없음, 참조 경계/메타 동반 검사 통과. 자동 렌더는 `Logs/R55`에 남긴다(로그/빌드는 Git 제외).
