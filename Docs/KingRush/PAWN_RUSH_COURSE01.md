# 폰 러시 코스 01 — 구현 (v0.4, R86)

2026-10-08. 기획: [레벨 디자인 v0.4](PAWN_RUSH_COURSE01_DESIGN_v0.4.md)(성한 님, 사용자 첨부 원문)와 폰 러시 미니게임 기획서 v0.1(PDF, 사용자 첨부; v0.4 5절이 그 v0.2 안). 같은 씬이 v0.1(R68, 일자 코스) → v0.2(R69, 탑을 감는 3층 고리) → **v0.4**로 바뀌었다. 예전 원문은 [v0.1](PAWN_RUSH_COURSE01_DESIGN_v0.1.md), [v0.2](PAWN_RUSH_COURSE01_DESIGN_v0.2.md), 예전 코드는 커밋 `c4015ff`(v0.1), `cc6373f`(v0.2).
**상태: Linux 컴파일·자동 검사와 파이썬 좌표 점검만. Unity에서 사람이 본 적 없음.** 확인 목록은 [VALIDATION](../Network/VALIDATION.md) 최상단.

## 1. 여는 법

1. Unity 메뉴 **ChessFight → Pawn Rush → Open Course01** (또는 `Assets/Scenes/PawnRush/PawnRush_Course01.unity`).
2. 그대로 **Play** → 씬에 코스가 없으면 코드가 기획서 월드 좌표대로 코스를 만들고, **이번 판 미니게임 두 개를 뽑아** 광장 ①·②의 두 팀 스테이션에 넣는다(Console에 "이번 판 미니게임: …"). 래그돌 폰(백팀)이 출발 광장에 서고 3초 뒤 출발 막대가 내려간다.
3. 코스를 씬에 실제 오브젝트로 두려면 Play를 멈추고 **ChessFight → Pawn Rush → Build Course01 v4**. `Course01v4_Root`를 지우고 다시 만든 뒤 씬을 저장하고 검증기를 돌린다(두 번 눌러도 같다). 씬에는 미리 보기로 광장 ①에 A, 광장 ②에 E가 들어 있고, Play 때 새로 뽑는다. **루트 안을 손으로 고치면 다음 Build 때 사라진다.**

| 키 | 동작 |
|---|---|
| WASD·Space·Shift·좌클릭·우클릭·마우스 | 래그돌 기본 조작(오비트 카메라) |
| **F5** | 백팀 ↔ 흑팀(그 팀 출발 자리에서 다시, 미니게임은 처음으로) |
| **F6** | 지금 있는 광장(광장 밖이면 다음 광장)의 **우리 팀 미니게임 완료** → 팀 문이 열림 |
| **F7** | C·D의 **상대 반대 입력** 켜기/끄기(기본 켜짐, 기획서: 테스트 빌드에서 켜고 끔) |
| **F8** | 새 판: 미니게임 두 개를 다시 뽑고 문을 모두 닫음 |
| **F9 / F10** | 광장 ① / ② 게임을 다음 것으로(다른 광장과 같은 게임은 건너뜀) |
| R / Backspace | 마지막 체크포인트로 / 처음부터(카운트다운 다시, 새 판) |
| V | 자유 카메라 |

오른쪽 위에 구간(S+A, M1, B, M2, C, T)·진행 m·이번 판 게임 두 개·단축키. 광장에 들어서면 3초 동안 그 광장 게임 이름과 한 줄 설명(그림 카드), 광장 안에서는 화면 아래에 **우리 팀·상대 팀 진척 막대**. 구간 입장·퇴장은 `Logs/PawnRush/course01_날짜.csv`(열: 구간, enter/exit, 초, 팀).

## 4. 미니게임과 뽑기

판마다 A~E 중 두 개를 뽑아 광장 ①·②에 하나씩 놓는다(`PawnRushMissions.Choose`, Core). 두 광장은 다른 게임, **직전 판에 나온 두 게임은 빼고** 뽑으며(남은 게 모자라면 "다른 게임" 규칙만), 두 팀은 같은 게임을 받는다. 오프라인은 시계로 씨앗을 정하고, 온라인은 방장이 뽑아 보내면 된다(같은 씨앗 = 같은 결과).

모든 게임: 진척 0~1, 완료하면 그 팀 문만 열리고 다시 닫히지 않는다. **자기 팀 폰만 진척을 올리고, 한 번에 4명까지만 센다**(`WorkerCap`). 상대는 스테이션에 걸어 들어와 밀고 막을 수 있다(벽 없음).

| 게임 | 하는 법(구현) | 상대 방해(구현) | 기획서와 다른 점 |
|---|---|---|---|
| A 체스판 칠하기 | 8×8 칸(2.25 m, u 2~20) 위에 1.5초 서 있으면 금색. 칸을 떠나면 그 칸 시간 0. 팀당 동시에 칠하는 칸 4개까지 | 상대가 서 있는 칸은 안 칠해짐. 밀려 나가면 그 칸 시간 0. 칠한 칸은 그대로 | 다이빙으로 미끄러질 때 0.5초씩 쌓기는 없음 |
| B 판자 다리 놓기 | 판자 더미(u 3, v ±8, 5장씩)에 1초 서 있으면 판자를 머리 위에 듦. 다리 끝(지금 놓을 줄 앞)에 1.5초 서 있으면 놓임. 가까운 줄부터, 2열×5줄. 동시에 드는 사람 4명까지 | 든 사람이 넘어지거나(골반 속도가 한 번에 7 m/s 넘게 바뀜) 떨어지거나 스테이션을 나가면 판자를 떨어뜨리고 5초 뒤 더미로 돌아감. 놓은 판자는 그대로 | 손으로 잡지 않고 서 있기로 들고 놓음(손의 잡기는 코스 코드에서 안 보임). 운반 중 이동 −50% 없음. 떨어진 판자를 던지기 없음(바로 사라졌다 5초 뒤 더미) |
| C 도개교 줄당기기 | 가운데 줄 길(v ±1.6, u 1~11)에서 **해자 반대쪽(남쪽)으로 걸으면** 1명당 초당 0.85%만큼 도개교가 내려옴. 다 내려오면 해자(u 12~16, 떨어지면 체크포인트로) 위 다리 + 문 열림 | 상대가 줄 길에서 앞(북쪽)으로 걸으면 1명분씩 다시 올라감. 25%마다 걸쇠(F7로 끔) | 손잡이를 잡지 않고 줄 길 안에서 걷는 방향으로 판정 |
| D 캡스턴 성문 | 가운데 캡스턴(u 10) 둘레(반지름 1~4.2 m)를 **바닥 화살표 방향**(백: 위에서 시계, 흑: 거울)으로 돌면 돌아감. 1명 최대 초당 0.13바퀴, 16바퀴면 문 열림. 진척에 따라 쇠살문(팀 문)이 최대 0.4 m 들림 | 반대로 돌면 1명분씩 되돌아감. 4바퀴(25%)마다 걸쇠(F7로 끔) | 막대를 밀지 않고 둘레를 도는 방향으로 판정. 쇠살문은 다 돌 때까지 0.4 m만(사람이 기어 나가지 못하게) |
| E 종탑 여섯 개 | 6·6·7.5·7.5·9·9 m 탑(돌 블록, 오름), 3 m마다 남쪽 면이 0.8 m 물러나는 쉬는 턱. 꼭대기(2.4×2.4)에 서면 종이 금색으로 울림 | 상대가 같은 꼭대기에 서 있으면 안 울림. 울린 종은 그대로 | 쉬는 턱은 남쪽(오르는 쪽) 면에만 |

## 6. 검증기 (Validate Course01)

1. **장애물마다 길 폭 전체를 덮는지**: `ObstacleSpan`이 붙은 장애물 자리에서 길을 가로질러 0.1 m마다 광선을 쏴 실제로 걸을 수 있는 바닥(벽·난간·막음 벽 제외), 탑은 오를 수 있는 면을 재고, 그 전체가 장애물이 닿는 범위 안인지 본다. 대상: 회전 막대 2, 미닫이 벽 2, 진자 3(B2), 시계 문, 룩 벽 2, 해머 4(경사로), 탑 진자 2(한 묶음). 원판·회전판·떨어지는 말은 옆이 낭떠러지라 대상 아님.
2. 백·흑 진행 경로 길이 차 ≤ 0.1 m.
3. 필수 경로 틈 ≤ 1.5 m(R89, 그 전 2.5 m). 경로 선 위에서 1.5 m를 넘으면 두 바닥 사이 가장 짧은 거리로 다시 잰다(A3 원판은 경로 선 양옆에 있어 선 위로는 1.58 m, 원판 사이는 1.49 m).
4. 체크포인트 9개의 부활 자리 아래 바닥.
5. 스테이션 4곳(문·같은 팀 장벽·게임), **다섯 게임을 네 스테이션에 하나씩 다 넣어 보고** 스테이션 20×20 m 밖으로 나가는 것이 없는지(검사 뒤 미리 보기 게임으로 되돌림).
6. 대리석 재질 = `NoClimbSurface`, 돌 블록 재질 ≠ `NoClimbSurface`. 광장 북쪽 덩어리·바깥 벽, 시계 문 막음 벽, 탑 몸체·어깨, 팀 문은 반드시 오를 수 없음.
7. 낙사 영역 있음.

## 8. 사람이 결정·확인할 것

- 기획서 "결정할 것": 판 목표 시간, C·D 반대 입력을 넣을지(F7로 시험), E 탑 6개/5개, 결승 왕관 원.
- 미니게임 시간: 혼자 약 2분, 4명 약 30초가 나오는지(작업량 상수는 각 `Mg*.cs` 맨 위).
- 하지 않은 것: 온라인(뽑기 결과·스테이션 진척 전송 — 문·도개교·캡스턴은 `StateDrivenMover`, 오프라인 전용), 프로모션·결승·과반 판정 규칙, 부활 2초 면역, 장애물 힘의 방장 판정, B의 판자 던지기와 운반 감속, A의 다이빙 칠하기.

## 9. 자동으로 확인한 것과 못 한 것

- `Tools/run-tests-linux.sh`: Core 91(뽑기 3개 포함)·세션 40, 경계·장애물 시계 검사 통과(문·도개교·출발 막대는 상태형으로 표시). PawnRush 런타임·에디터 코드 Roslyn 컴파일 통과(에디터는 `UnityEditor.dll` 2021.1).
- **주의:** 이 브랜치에 같이 올라온 다른 작업(R76~R85)의 Game 코드가 Unity 6 전용 API(`FillGradient`, `Painter2D.ArcTo`, `Resolution.refreshRateRatio`)를 써서, `--compile`은 2021.3 참조 DLL로 Game을 만들다 멈춘다. 그래서 PawnRush는 그 전 Game(`cc6373f`)으로 만든 DLL에 대고 따로 컴파일했다. 실제 Unity 6에서는 문제없을 것으로 보이지만 Linux 검사를 다시 쓰려면 그 API들을 `unity6_to_2021`에서 건너뛰게 해야 한다.
- 파이썬으로 빌더 좌표를 다시 적어 점검: 두 팀 경로 398.15 m로 같음, 필수 경로 틈은 A3 원판(경로 선 위 2.6 m, 원판 사이 2.44 m. R89에 1.58 m·1.49 m로) 말고는 없음, 체크포인트 부활 자리 54곳 아래 바닥, 종탑 6개가 스테이션 안.
- **못 한 것: Unity 실행.** 래그돌 완주, 미니게임 다섯 개의 실제 시간·판정, 팀 문·장벽, 검증기 결과, 셰이더는 사람이 Unity에서 봐야 한다.
