## 1. 기획 요약 (원문에서 결정된 것만)

| 항목 | 내용 |
|---|---|
| 한 줄 | 전원 폰으로 출발해 폴가이즈식 **입체 장애물 코스**를 달리고, **팀원 과반이 먼저 결승**을 통과하면 이기는 2~6인 팀 대 팀 레이스 |
| 한 판 | 로비 → 출발(5초) → 레이스(선두 약 6분) → 결승 판정(첫 통과 뒤 최대 90초, 전체 8분) → 결과(30초) → 로비. 라운드제 아님 |
| 승리 | 필요 인원 = ⌊N/2⌋+1 (2→2, 3→2, 4→3, 5→3, 6→4). 채우는 순간 즉시 종료. 같은 틱이면 마지막 필요 인원의 통과 시각을 틱 사이 보간으로 비교. 시간 초과 시 통과 인원 → 상위 필요 인원의 **경로 진행도** 합 → 마지막 체크포인트 도달 시각 |
| 결승 뒤 | 코스로 못 돌아감. 팀원 시점 관전 + 응원 이모트만 |
| 코스 | 출발 섬 → 공용 A 폰 머리 롤러 다리(60초) → **전직①+미션① 상자 계단**(45초, 팀별 섬) → 공용 B 체스 시계 대바퀴 + 나이트 말굽 풍차 + 나이트 도약대 지름길(80초) → **전직②+미션② 크랭크 승강기**(40초) → **전직③+공용 C 룩 탑 나선**(비숍 지팡이 회전봉, 킹 왕관 진자, 90초) → 룩 탑 꼭대기 결승 |
| 코스 규칙 | 아래는 물(빠지면 5초 뒤 마지막 체크포인트, 체크포인트는 구간 입구·개인별). 겹쳐 지나가는 길(위에서 떨어지면 반드시 지나온 길로). 공용 구간은 높은 길·낮은 길 두 갈래. 길 폭 2.4 m 이상 |
| 전직(=승격) | 지점마다 **팀별로** 가장 먼저 온 폰 1명. 지점 뒤 바닥에 발판 5개(퀸·룩·비숍·나이트·폰 유지), 밟으면 선택, **3초** 안에 안 밟으면 폰 유지 → 기회는 그 팀 다음 폰. 재전직 없음, 퀸은 마지막 활성 지점에서만, 같은 팀 같은 기물 1개, 1초 변신 동안 밀기·잡기 면역, 부활해도 유지 |
| 활성 지점 | 2인: ② / 3인: ①② / 4~6인: ①②③. 폰이 최소 1명은 남는다 |
| 스킬 | **미정.** 방향: 뒤처진 팀원을 돕는 스킬. 입력은 E·Q. 기본 능력치는 `Core/ChessPieces` 시작값(쓸지 미정) |
| 팀 미션 | 작업량 고정·인원 병렬·진척 공유(되돌아가지 않음)·혼자 50초 이하·동시 작업 상한 3명·**기물 무게 반영**·상대 방해 불가(투명 벽). 예: 박스 10개 나르기, 크랭크 20바퀴, 무게 발판 문, 체스판 뒤집기 |
| 몸싸움 | 다이빙(좌클릭), 잡기(우클릭, 잡힌 쪽 클릭 게이지 탈출, 풀리면 1초 무적), 등반(55° 초과, 스테미나 8초) |
| 공정성 | **아군 방해 불가**(아군 밀기·잡기 없음, 몸 충돌 약하게), 넘어짐 보호(0.65초/1.1초/3초 안 재넘어짐은 휘청), **부활 후 2초 면역**(공격하면 해제), **결승 직전 8 m 잡기 금지**, **분리 구간 입구 5 m 상대 진입 금지** |
| 테스트 | 오프라인 1인 → 팀 5명+봇 7명 비공개(매주) → 사람 3대3(격주) → 사람 6대6(마일스톤). 호스트가 전직·미션 완료·물 빠짐·결승 시각을 **CSV**로 기록. 지표: 첫 전직 팀 승률 60% 초과면 스노우볼 |
