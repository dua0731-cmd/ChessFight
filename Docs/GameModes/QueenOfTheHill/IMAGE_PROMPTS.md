# 퀸 오브 더 힐 — 레벨 디자인 예시 이미지 프롬프트 5장 (2차)

[DESIGN.md §3](DESIGN.md)의 "센터 탑"을 보여 주는 **레벨 디자인 예시** 이미지용이다(2026-09-26, R27). 아트 컨셉이 아니다.

**1차 프롬프트(섬 위 피라미드)는 폐기했다.** 사용자 평가: 맵이 쓸데없이 넓고, 그리스 여행지 같고 유치하며, 체스와 관계가 없다. 그래서 2차는 이렇게 바꿨다.
- 섬·바다·폭포·나무·현수막·표지판 글자를 **금지**한다(프롬프트에 명시).
- 체스판, 거대 기물, 체스 시계 부품으로만 만든다.
- 차분한 고급 테이블 디오라마 톤으로 간다.
- 재료 색을 게임 신호로 쓴다: 초록 펠트 = 휴식처, 황동 = 움직이는 장애물, 흑백 체크무늬 = 노출된 개활지.

**쓰는 법:** 모든 프롬프트 끝에 같은 STYLE이 붙어 있다. 가로 16:9를 권한다. 1번을 먼저 만들고, 나머지는 같은 대화에서 "same tower and art style as the previous image"를 덧붙이면 모양이 덜 흔들린다.
