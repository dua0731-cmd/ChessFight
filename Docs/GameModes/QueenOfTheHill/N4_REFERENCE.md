## 1. 이번 세션에서 사용자가 정한 것

1. 목표는 **재미 검증용 간단한 프로토타입을 하루 안에 대충** 만드는 것이다. 몇 주짜리 개발 계획은 원하지 않는다.
2. **프로모션 쟁탈전부터** 만든다. 킹을 지켜라와 소드파이트는 아직 기획이 덜 됐다.
3. 테스트는 **대부분 혼자** 한다. 그래서 **아군과 적군을 전부 AI**로 채울 수 있어야 한다.
4. **모든 말(기물)을 직접 플레이**해볼 수 있어야 한다.
5. 이 모드의 구성은 **폰 4~8명 + 나머지 기물 각 1~2개**다. 여러 폰이 주인공이고, 가운데 구조물 꼭대기까지 올라가 승격하는 게 목표다. (Claude는 "팀당"으로 해석했다. 두 팀 합계일 수도 있다. **미확인**)
6. 가운데 **구조물의 레벨 디자인과 등반 액션은 최소한 제대로** 되어 있어야 한다.
7. 기물 능력은 9/19 핸드오프 3-3절 그대로다: 나이트 2단 점프 + 밟기 찌그러뜨림 / 룩 선딜 후 중력 무시 고정 방향 긴 돌진 / 비숍 6초 호버 + 돌조각 투사체 / 폰 능력 없음 + 뒤에서 치면 "앙파상" / 퀸은 승격한 폰 딱 1명.

## 4. 중앙 구조물 "The Keep" (`Assets/ChessFight/Settings/PromotionHill.json`)

맵: 40m(x) × 60m(z) 바닥, 바깥은 낭떠러지. 파랑 스폰 z=-25, 빨강 z=+25. 구조물은 중심 기준 180도 회전 대칭.

| 층 | 윗면 높이 | 구성 |
|---|---|---|
| 1층 성벽 기단 | 2.6m | 18×14m. 모든 면 벽 오르기(2.6m). 팀마다 앞 모서리에 점프 계단(1.3m) |
| 2층 본성 | 5.2m | 10×8m. 정면 가운데는 4.8m 높이 성벽이 막음 → 정면 양 모서리(각 2m)와 옆면으로만 오름 |
| 성탑 4개 | 4.6m | 1층 위. 성탑에 올라 2m 틈을 뛰어 2층으로 가는 지름길 |
| 3층 발코니 | 7.8m | 동·서 발코니(4×4m, 두께 0.5m 슬래브, 밑 공간 2.1m). 2층에서 모서리 잡고 오르거나 디딤돌(6.5m)로 점프. 기둥 둘레에 폭 0.9m 통로 |
| 정상 기둥 | 10.4m | 2.6m 사각. 3층에서만 오를 수 있음. 윗면 금색 판 = 승격 구역 |

AI용 경로 3개(파랑 기준, 빨강은 자동 대칭): 정면 모서리(벽 4번) / 서쪽 계단+디딤돌 / 동쪽 성탑 점프. 파랑의 서쪽 길과 빨강의 정면 길이 같은 발코니에서 만난다(반대쪽도 같음).

레벨을 바꿀 때 지켜야 할 물리 수치: 캡슐 높이 1.8m·반지름 0.45m, 몸 중심은 바닥 +0.95m, 머리 위 여유 2.0m 이상, 점프 상승 1.96m, 올라설 수 있는 상자 1.3m 이하, 편한 틈 3.5m 이하, **한 번에 잡고 오르는 벽 2.0~3.2m**, 올라선 뒤 바닥 깊이 0.8m 이상. JSON을 고치면 `scripts/Build-N4.ps1`로 다시 빌드한다.

## 7. 알려진 문제와 미검증

- **사람이 직접 조작한 테스트 없음.** 등반 조작감, 카메라, 난이도는 모른다.
- 마지막 코드 검토(등반·혼자 모드·AI 경로)는 사용량 문제로 **중간에 멈췄다**. 그 전 검토에서 나온 문제는 모두 고쳤다.
- AI 폰이 방해 없이 15초 안팎에 정상에 오른다. 방어가 너무 어려울 수 있다(`BotHesitationMin/Max`로 조절).
- 퀸 AI는 사냥이 서툴다(맵 밖으로 떨어지거나 늦게 끝남).
- 범용 등반은 난투전(소드파이트) 아레나에도 적용된다(상자를 오를 수 있음).
- 예전 N3 자동 점검(`Test-N3.ps1`)은 옛 규칙을 검사하므로 실패한다.
- 킹 없음, 소리는 합성음 자리표시, 비주얼은 회색 박스, 판정 크기는 모든 기물 동일.
- 다른 PC·인터넷에서 여럿이 플레이한 적 없음.
- git: 프로젝트가 속한 저장소의 소유 계정이 달라서 git 명령이 거부된다. 팀 공유 전에 별도 저장소로 분리 권장.
- 씬과 프리팹은 빌드 때 코드로 다시 생성된다. 에디터에서 손으로 고친 것은 덮어써진다. 레벨은 JSON으로 고칠 것.
