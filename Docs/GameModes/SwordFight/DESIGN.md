## 3. 재미의 중심

**접근 → 휘두름 → 상대가 넘어짐 → 추격·연속 타격·협공 → 장외 +1 → 복귀.**

1. **휘두르는 건 명확하게, 맞고 넘어지는 건 물리답게.** 의도한 공격 방향이 읽혀야 하고 몸의 뒤틀림·엉킴에서 웃음이 나와야 한다.
2. **중앙은 몸싸움, 외곽은 득점 위기.** 중앙에서 아무 한 대나 맞았다고 바로 장외가 되기보다 바깥으로 모는 위치 싸움이 생긴다.
3. **잘 몰아붙이면 계속 때릴 수 있다.** 쓰러진 적을 추격하거나 아군과 포위하는 장면을 재미로 인정한다. 문제는 그 상황의 존재가 아니라 아무 준비 없이 누구나 반복할 수 있는 쉬운 필승법이 되는 것이다.

### 3.1 연속 타격 — 금지 대신 성립 조건을 조절

사용자 정정(R46)에 따라, 초기에 GPT가 제안한 **자동 재넉다운 방지·무조건 기상 무적·연속 타격 강제 종료**는 기본 규칙으로 채택하지 않는다. 필요하더라도 실제 플레이 근거를 본 뒤 별도 논의한다.

우선 시험할 조절 손잡이(아직 수치 미정):

| 손잡이 | 노리는 효과 |
|---|---|
| 타격으로 밀리는 거리·방향 | 공격자가 다음 타격을 맞히려면 추격·조준·위치 선정을 해야 함. 연속타를 무조건 끊을 만큼 멀리 보내자는 뜻은 아님 |
| 칼의 회수 시간·헛스윙 빈틈 | 제자리 연타가 항상 정답이 되지 않게. 다른 적에게 공격받을 여지도 생김 |
| 기상 소요 시간과 다음 공격의 도달 시각 | 성공적인 연속 타격과 빠져나갈 여지가 섞이는 지점을 찾음. 피격 중 반드시 일어날 권리를 보장하는 규칙은 아님 |
| 지형과 협공 | 벽·가장자리·포위·아군의 구원이 중요해짐. 협공이 강한 것과 혼자 누구든 무한히 붙잡는 것은 따로 평가 |

측정은 **평균만 보지 않는다**: 첫 명중 이후 연속타 성립 비율, 연속 피격의 횟수·지속 시간, 1대1과 다대1의 차이, 벽·중앙·외곽별 차이, 공격자의 이동·재조준 필요성, 아군 개입으로 끊긴 비율을 함께 기록한다. 연속타를 없애는 것이 아니라 **재미있는 성공 장면과 너무 쉬운 반복 사이**를 찾는다. 목표 수치와 강제 상한은 지금 정하지 않는다.

## 4. 첫 플레이 버전의 규칙 제안

| 항목 | 시험용 시작안 | 이유 / 미정 사항 |
|---|---|---|
| 인원 | 6 대 6, 개발 중 1 대 1·봇 | 현재 매칭 구조 활용. 래그돌 전투 봇은 별도 구현 필요 |
| 승리 | 먼저 20점 또는 4분 종료 시 높은 점수 | 실제 판 길이를 보고 조절. 동점은 일단 무승부 |
| 체력 | **없음** | 칼은 피해 숫자보다 자세·위치를 바꾸는 수단. 영상 HP는 채택하지 않음 |
| 장외 | 경기장 아래의 판정 경계를 넘으면 낙사 확정 | 테두리를 살짝 벗어나거나 걸린 순간에는 확정하지 않음 |
| 점수 | 낙사 1회당 상대 팀 +1을 제안 | 자발적 낙사도 상대 +1인지는 미확정. 마지막 공격자 표시와 팀 득점을 분리 |
| 부활 | 3초 뒤, 자기 팀 후보 지점 중 적에게서 먼 곳 | 영구 탈락 없음 |
| 부활 보호 | 1.5초, 공격 시 조기 종료를 제안 | **기상 무적과 별개**인 부활 지점 보호. 채택 여부 미정 |
| 아군 | 몸은 부딪히되 칼의 아군 넉다운은 우선 끔 | 팀킬 스트레스와 난장판의 재미 중 선택 필요 |
| 기물 차이 | 첫 버전은 같은 칼·같은 전투 성능 | 기본 싸움부터 판단. 종류별 인원 제한·선택 방식은 미정 |

장외 점수는 방장 한 곳에서 생명당 한 번만 판정한다. R47 현재값·한계는 README를 따른다.

## 5. 칼싸움과 조작

| 입력 | 소드 파이트에서의 역할 제안 |
|---|---|
| WASD / 마우스 | 기존 이동 / 시점·공격 방향 |
| Shift / Space | 기존 질주 / 점프 유지 |
| 좌클릭 | **칼 휘두르기**. 이 모드에서는 기존 다이빙 태클 대신 칼 공격 |
| 우클릭 | **기물 특수 스킬 전용 예약**. 첫 버전에서는 미구현, 폰은 스킬 없음 |
| E·Q·F | 우선 새 기능 없음. 퀸 모드의 갈고리·종 기능은 여기서 작동시키지 않음 |

**잡기·등반과의 충돌:** 기존 우클릭은 잡기·등반이다. 소드 파이트에서는 스킬용으로 예약하므로 기존 동작을 그대로 켜 두지 않는다. 첫 버전은 잡기·등반 없이 칼 중심을 제안하고, 필요하면 별도 키·상황 규칙을 먼저 정한다. 공유 래그돌의 입력을 전역 변경하는 뜻은 아니다.

공격감 시작안:

- 작은 준비 동작 → 명확한 가로 베기 → 회수. 좌우 번갈아 베되 복잡한 콤보 입력은 없음.
- 클릭 즉시 자세·소리로 반응. 연타로 회수 동작을 건너뛰지 않으며 다음 공격 예약은 1회까지 제안.
- 누운 상대도 다음 공격에 맞을 수 있고 넘어짐을 이어갈 수 있다. 성공 난도는 §3.1에서 조절한다.
- 차지·패링·방패·콤보 보너스·누적 피해율·칼 줍기는 첫 범위에서 제외. 칼은 손에 붙어 있고 부활 시 복원.

기술 방향(구현 아님): 공격 의도와 제한은 안정적인 코드로, 팔·칼 궤적과 몸의 반응은 물리로 표현한다. 칼이 실제 지나간 공간을 검사하되 **공격 1회 × 대상 1명당 판정 1회**로 합친다. 이것은 래그돌 여러 부위가 동시에 닿아 생기는 중복 이벤트를 막는 것이며 **다음 휘두르기의 연속 타격을 금지하는 규칙이 아니다.** 가만히 닿은 칼은 공격이 아니다. `IHitReceiver`와 공통 계약을 활용하고 게임 모드 코드는 래그돌 구현 타입에 직접 의존하지 않는다.

## 6. 첫 경기장 — 체스판 난투장

단순하고 잘 읽히는 정사각형 경기장 한 개를 제안한다. 큰 탑·점프 코스·복잡한 기믹은 없음.

- 약 **24 × 24 m**, 8 × 8 타일을 첫 배치안으로 두고 실제 폰 크기·사거리로 시험한다.
- **중앙:** 평평한 난투 공간. 왕관 무늬는 장식이지 점령 목표가 아님.
- **외곽:** 난간 없는 장외 구간. 테두리와 밀려나는 방향이 쉽게 읽혀야 함.
- **장애물 4개:** 모서리 안쪽의 낮은 룩 형태. 돌아 피하거나 몰아붙이는 용도. 큰 벽은 아님.
- **부활:** 서로 반대편 두 줄 안쪽에 분산. 바로 뒤가 낭떠러지인 가장자리는 피함.
- **색:** 기물은 흑·백, 바닥은 청회색·모래색 체크, 테두리는 금색. 캐릭터 식별이 우선.
- **배경:** 흐린 하늘 위 떠 있는 체스판을 1차 아트안으로 사용.
- **게임 카메라:** 영상처럼 캐릭터를 따라가는 3인칭을 우선 검토. 아래 그림은 전체 배치를 보여주는 시점이지 고정 게임 카메라 제안이 아님.

## 7. 승인 후 구현 순서 제안

1. **칼 시험대:** 두 캐릭터가 베고 넘어짐. 칼 궤적·중복 피격·추격 연속타부터 확인.
2. **오프라인 한 판:** 단순 경기장 → 장외 점수 → 부활 → 시간·승패·재시작. 혼자 시험할 최소 봇/더미.
3. **멀티 연결:** 랩의 호스트 권위 래그돌 기반을 경기 씬으로 연결하고 공격·낙사·부활·점수 동기화. 로비의 평면 캡슐 이동과 별개 작업이다.
4. **12인 난전:** 1대1·협공·지형별 연속타 성립과 지속, 장외 빈도, 부활 위치, 성능·지연 확인.
5. **기물별 우클릭 스킬:** 기본 칼싸움이 재미있어진 다음 별도 기획·구현.

다음에 정할 것: 시안의 분위기·배치, 기본 공격과 연속타의 감각, 경기 시간·점수·부활·아군 규칙, 기물 선택 방식. 우클릭 스킬 내용은 지금 정할 필요 없음.

퀸 오브 더 힐·미커밋 밧줄 작업·공통 물리 튜닝은 범위 밖이다. 새 브랜치는 마지막 커밋까지의 기반만 이어받았고 미완성 튜닝이 해결된 것은 아니다.
