## 3. 소드 파이트 프로토타입 — 지금 상태 (9-27 R51 기준)

**한 줄(당시 기획):** "귀여운 체스 말들이 칼을 휘두르며 우당탕 싸우고, 상대를 체스판 밖으로 떨어뜨려 점수를 따는 팀 난투전."

| 항목 | 현재 구현 |
|---|---|
| 득점 | **이미 HP가 없고, 장외 낙사 1회 = 상대 팀 +1점**(스스로 떨어져도 상대 +1) |
| 승리 | 20점 먼저, 또는 4분 뒤 점수 높은 팀. 동점 무승부 |
| 부활 | 3초 뒤 팀 자리, 부활 보호 1.25초(칼을 꺼내면 해제) |
| 칼 | 모든 폰이 허리에 칼. **두 조작 방식을 F6으로 전환하며 비교 중** |
| ① 물리 드래그(기본) | 좌클릭을 누르는 동안 칼을 꺼내 들고, 마우스를 끌어 실제 물리 칼(0.88 m, 0.18 kg)을 휘두른다. 시점이 무게감 있게 늦게 따라온다. **충분히 넓고 빠르게 베야만 넘어뜨림**(약한 접촉은 물리 밀림만) |
| ② 클릭 베기 | 한 번 클릭 = 정해진 궤도로 한 번 베기(준비 0.16 + 타격 0.2 + 회복 0.34초) |
| 타격 효과 | 넘어뜨리고 수평 2.8~4.5 + 위 0.7 m/s로 밀어냄. **누운 상대 추가타 허용**(연속타는 금지하지 않고 난도로 조절하기로 결정됨) |
| 아군 | 칼로는 아군을 넘어뜨리지 않음(몸 부딪힘은 있음) |
| 맵 | **14 m 평평한 시험 발판 하나.** 장애물·기믹 없음("맵은 마지막"으로 미뤘음) |
| 봇 | **움직이지 않는 더미**(맞고 떨어지고 부활만) |
| 우클릭 | 기물 스킬 자리로 비워 둠. 잡기·등반은 이 모드에서 꺼짐. 다른 기물 없음(폰만) |
| 온라인 | 동작(방장 계산, 칼 자세 전송). 두 PC 손맛은 미확인 |
| 사용자 확인 | 9-27: 더미로 혼자 시험 가능, 물리 칼 시스템 동작 확인. 이후 "검이 몸에 가림·무게감·약한 접촉" 피드백을 반영(R51)했으나 **R51 이후 재확인 안 됨** |

> **bold-johnson의 스킬 작업(R91~R110, 승규 님, 아직 `main`에 없음, 시험 씬·오프라인만):** 킹·퀸·룩·비숍·나이트마다 **F 스킬**(왕의 반격·꼬치 베기·열린 파일 포격·관통 핀·포크 강하)과 **E 가장자리 스킬**(가장자리 2 m 안에서: 왕의 귀환·체크메이트 일섬·성벽 붕괴·구원의 손·벼랑 끝 역전)이 있다. 모두 "얼마나 장외로 보내나/살아남나"로 설계되어 **사용자가 말한 "스킬로 떨어뜨리기"가 이미 부분적으로 구현돼 있다.** 기물 배정 방식·스킬 온라인·최종 키는 미정. 상세는 [STATUS §6](STATUS.md#6-기물과-스킬).

### 3-1. 왜 "데스매치"처럼 느껴지는가 (Claude Code 진단)

규칙은 이미 "떨어뜨리기 득점"인데 플레이 감각이 "칼로 처치"인 이유:

1. **맵이 평평한 14 m 발판뿐**이라 가장자리로 모는 위치 싸움·지형 함정이 없다. 남는 동사가 "베기"뿐이다.
2. 칼의 결과가 **"넘어뜨림"이 주이고 "날려 보냄"이 약하다**(밀림 2.8~4.5 m/s). 떨어뜨리려면 여러 번 베며 끌고 가야 해서 결과적으로 "때려 눕히기 게임"이 된다.
3. 칼 조작(물리 드래그) 자체가 학습·감각 비용이 커서 플레이어의 관심이 "어떻게 휘두르나"에 쏠린다.
4. 더미가 서 있기만 해서 혼자 시험하면 "때리기 연습장"이 된다.
5. 추가로, 밀림 수치는 **10-08 이동 튜닝 이전(달리기 4 m/s 시절)** 값이다. 지금 달리기가 2.5 m/s라 상대적으로 강해졌을 수 있어 재조정이 필요하다.

## 4. 사용자의 생각 (10-10, 원문 요지)

> 지금 모드는 칼로 적 말을 처치하는 '데스매치' 느낌이다. 데스매치는 살려도 되지만, 핵심 컨셉을 **"적 말을 직접 타격하거나 스킬을 활용해서 낭떠러지로 떨어뜨리는 게임"**으로 가면 어떨까? 즉흥적인 생각이니, 폰 러쉬 다음 추가 콘텐츠로 괜찮은지 판단하고 더 좋은 방향이 있으면 제안해도 좋다.

1. **HP를 넣으면** 폰 러쉬에 없던 메카닉이 생겨 어색할 것 같아서 "떨어뜨린다"로 말한 것이다.
2. 이 모드는 **참고 영상**(§5)에서 출발했다.
3. **영상의 느낌을 잘 살리는 방식**은 무엇일까?
4. **3~6인 게임**으로 만드는 것까지 고려해야 한다.
5. **체스판 흑백 격자에 따른 말 이동 방식** 시스템을 넣으면 더 재밌을까? 넣는다면 어떻게?

## 6. Claude Code의 1차 판단

**결론: 좋은 방향이다. 다만 "새 컨셉"이라기보다 "원래 규칙의 강조점을 바로잡는 것"에 가깝다.** 지금도 득점은 낙사뿐이고 HP도 없다. 바꿔야 할 것은 규칙보다 **맵·타격 결과·동사 구성**이다.

| 판단 | 근거 |
|---|---|
| 폰 러쉬와 잘 맞는다 | HP 없음, "밀기·넘어뜨리기·떨어뜨리기"라는 같은 언어를 쓴다. 래그돌 넉다운·낙사 판정·기물 스킬·방장 계산 온라인을 그대로 재사용한다. 폰 러쉬에서 배운 조작이 그대로 통한다 |
| 콘텐츠 비용이 낮다 | 폰 러쉬는 긴 코스 + 미니게임 5종이 필요했지만, 이 모드는 **경기장 하나 + 규칙**이다. 경기장 여러 개로 늘리기도 쉽다 |
| 폰 러쉬와 겹치지 않는다 | 폰 러쉬 = 레이스·협동 작업, 소드 파이트 = 짧고 굵은 **아레나 난투**. 파티 게임에 둘 다 필요하다 |
| HP 대신 쓸 수 있는 장치 | 폴 가이즈·스매시브라더스식 **"맞을수록 더 멀리 날아감"(누적 밀림 배율)**은 HP 숫자 없이도 긴장감을 준다. 다만 폰 러쉬에 없는 숨은 수치라 넣을지는 결정 필요(질문 Q4) |

**위험 요소**

1. **물리 드래그 칼**은 손맛이 좋으면 강점이지만 배우기 어렵고, 참가자 PC는 입력이 방장까지 왕복한 뒤에야 칼이 움직인다(예측 없음). 인터넷 지연에서 검증되지 않았다.
2. 칼(좌클릭)이 폰 러쉬의 다이빙 태클 자리를 차지하고, 잡기(우클릭)는 꺼져 있다. **모드마다 같은 키가 다른 일을 하는 문제**.
3. 낙사 게임은 **가장자리 캠핑**·**부활 직후 다시 떨어뜨리기**·**잘하는 팀의 굴러가는 눈덩이**가 생기기 쉽다.
4. 3~6인은 지금 매칭(6 대 6 고정)과 다르다. 봇도 지금은 서 있기만 한다(폰 러쉬와 공통 과제).

## 7. 방향 후보 (상담 AI가 비교·보완해 줄 것)

### A. 장외 난투 — 점수제 (지금 규칙 + 맵)
- 정해진 시간 동안 떨어뜨린 수로 승부. 부활 있음.
- 핵심은 **가장자리가 많은 경기장**: 섬 여러 개, 좁은 다리, 난간 없는 테두리, 밀어내는 장치.
- 장점: 지금 코드 그대로, 언제 들어와도 즐겁다. 단점: 끝까지 긴장감이 평평할 수 있다.

### B. 무너지는 체스판 — 라운드 생존
- 떨어지면 그 라운드 탈락(관전), **마지막까지 남은 팀(또는 사람)이 라운드 승리**, 3판 2선승.
- 시간이 지나면 체스판 칸이 **바깥부터, 또는 체스 수의 모양으로** 떨어져 판이 좁아진다(§8의 1).
- 장점: 폴 가이즈 최종전 같은 클라이맥스, 3~6인에 잘 맞음. 단점: 일찍 떨어진 사람이 기다린다.

### C. 섞기 — 점수제 + 마지막 1분 서든데스
- 앞 3분은 A(부활 있음), 마지막 1분은 판이 무너지고 부활이 꺼진다.
- 장점: 초반 난투와 마지막 긴장을 둘 다. 단점: 규칙 설명이 길어진다.

### 공통으로 검토할 것: 칼의 역할
| 안 | 내용 |
|---|---|
| 칼 유지(주 무기) | 지금처럼. 단 "넘어뜨림"보다 **"날려 보냄"**을 키운다(강하게 벤 만큼 멀리, 타격 정지·카메라 흔들림·슬로 장외) |
| 칼 + 기물 스킬 | 칼은 기본기, 우클릭(또는 F)은 기물 스킬. 폰 러쉬처럼 승격 발판으로 기물이 바뀌거나, 경기 전에 기물을 고른다 |
| 칼 대신 폰 러쉬 동사 | 다이빙·잡기·밀기 + 기물 스킬만으로 떨어뜨리기. 모드 이름과 영상 출발점에서 멀어지므로 비추천이지만 비교용 |

## 8. 체스판 격자(흑백 칸) 시스템 — 후보 아이디어

**Claude Code 의견:** 캐릭터 이동 자체를 칸에 묶는 것(턴제·칸 단위 이동)은 래그돌·폴 가이즈식 자유 이동과 맞지 않아 비추천. 대신 **"판이 체스를 둔다"**와 **"스킬이 체스처럼 움직인다"** 쪽을 추천한다.

| # | 아이디어 | 설명 | 기대 효과 | 비용·주의 |
|---|---|---|---|---|
| 1 | **판이 체스를 둔다** | 몇 초마다 거대한 유령 기물(룩·비숍·퀸…)이 판 위에 **이동 경로를 빛으로 예고**한 뒤 그 줄의 칸을 꺼뜨리거나 쓸고 지나간다. 룩 = 가로/세로 한 줄, 비숍 = 대각선, 나이트 = L자 칸들 | 체스를 몰라도 "빛나는 줄에서 피하라"로 읽힌다. 체스를 알면 더 재밌다. 상대를 그 줄로 미는 플레이가 생김 | 칸이 떨어지는 장치는 폰 러쉬 장애물 재료로 만들 수 있다. 예고 시간 튜닝 필요 |
| 2 | **흑칸·백칸 효과** | 자기 팀 색 칸에서는 버팀(밀림 감소), 상대 색 칸에서는 미끄럽거나 더 멀리 날아감 | 팀 위치 싸움("우리 칸으로 끌어들여라") | 6 대 6 난전에서 읽기 어려울 수 있다. 칸 크기(1.5~3 m)에 따라 체감이 달라짐 |
| 3 | **스킬이 체스 이동** | 이미 구현된 룩 직선·비숍 대각선·나이트 L자·폰 두 걸음·퀸 범위를 그대로 가져와, 스킬 거리를 **칸 단위**로 맞춘다(1칸 = 1.5 m) | 새로 만들 것이 적고 폰 러쉬와 일관 | 소드 파이트에서 기물을 어떻게 정할지 결정 필요 |
| 4 | **승격 칸** | 판의 마지막 줄(상대 진영 끝 랭크)에 도달하면 승격해 강한 기물이 됨 | 체스 규칙과 직결, 공격적인 전진 보상 | 폰 러쉬의 승격 발판과 겹치니 차별화 필요 |
| 5 | **체크 칸** | 특정 칸에 서 있으면 상대 팀 "체크" 표시 → 그 칸의 적을 떨어뜨리면 2점 | 목표 지점이 생겨 동선이 정리됨 | 퀸 오브 더 힐(점령)과 겹칠 수 있음 |
| 6 | (비추천) 칸 단위 이동 | 캐릭터가 칸 중심으로만 움직이거나 박자에 맞춰 이동 | 체스다움 최대 | 래그돌 물리·공통 조작과 정면 충돌, 폰 러쉬와 이질적 |

## 9. 3~6인 고려 사항

- **먼저 정할 것:** "3~6인"이 **한 경기 전체 인원**인지(개인전 또는 2:2·3:3·2:2:2), **팀당 인원**인지.
- 지금 구조: 매칭은 6 대 6 고정, 빈자리는 봇으로 채움. 네트워크는 최대 12개 몸까지 되므로 **인원을 줄이는 것은 기술적으로 쉽다.** 3팀 이상이나 개인전은 팀 색·득점·매칭 코드를 손봐야 한다.
- 경기장 크기는 인원에 따라 달라져야 한다(지금 14 m 발판은 2:2 정도). 판이 좁아지는 B안은 인원과 상관없이 밀도를 맞추기 쉽다.
- 개인전이면 아군 오인 타격 문제는 사라지지만 흑·백 두 색만으로는 6명을 구분하기 어렵다(색·모자 등 필요).
- 봇이 움직이지 않으면 적은 인원 시험이 어렵다. **난투 봇**(가까운 적에게 다가가 베고, 가장자리를 피함)이 필요하다.

## 11. 원하는 답 형식

- 한국어, 각 질문마다 **추천 1개 + 이유 2~3줄 + 대안 1개**.
- 수치를 제안할 때는 위의 현재 값(§2·§3)과 비교해서(예: "밀림 4.5 → 7 m/s").
- 마지막에 **"첫 시험판 기획 요약"**(경기장 그림을 말로, 규칙 표, 조작 표, 시험할 것 5개)을 한 덩어리로.
- 구현 난도를 상·중·하로 표시. 이 프로젝트는 AI로 개발하므로 코드로 맵을 만드는 것(블록·칸 배치)은 쉽고, 새 3D 모델·애니메이션은 비싸다.
