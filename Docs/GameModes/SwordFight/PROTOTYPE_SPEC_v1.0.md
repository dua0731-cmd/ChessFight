# 소드 파이트 프로토타입 구현 명세 v1.0 — 떨어뜨리고 빼앗기

## 0. 이 문서를 읽는 법

이 문서는 Claude Code가 소드 파이트 프로토타입을 Unity 프로젝트에 구현하기 위한 명세다. 목표는 **핵심 규칙 5개로 4분 경기 한 판이 처음부터 끝까지 돌아가는 상태**를 만드는 것이다.

문서끼리 충돌하면 아래 순서로 판단한다.

1. 이 문서 (v1.0)
2. STATUS.md R113: F·E 스킬 10종의 수치와 동작
3. 기존 SwordFight README: 칼 판정값
4. DESIGN.md (9-27 초안)와 PLANNING\_BRIEF: 이 문서와 겹치는 부분은 모두 폐기

이 문서에 없는 결정이 필요하면 임의로 정하지 않는다. 가장 단순한 쪽으로 구현하고, 그 지점을 §13 미정 목록에 한 줄 추가해 보고한다.

참고 시연: 같은 규칙을 대본으로 재생한 브라우저 페이지가 있다(소드 파이트 핵심 규칙 시연). 장면의 느낌과 순서만 참고하고, 수치는 이 문서를 따른다.

## 2. 작업 전 저장소 확인

코드를 쓰기 전에 아래 항목을 확인하고, 결과를 작업 메모에 남긴다. 추측으로 진행하지 않는다.

1. **스킬 브랜치 상태.** F·E 스킬 10종은 `bold-johnson` 브랜치의 시험 씬에만 있다. main과의 차이, 특히 R92·R93과 프로토콜 v16을 확인한다. 구현은 **main으로 합친 뒤** 시작한다.
2. **기존 소드 파이트 모드.** 로비에서 소드 파이트를 고르면 들어가는 경기 씬, 장외 판정, 부활, 점수 코드가 어디 있는지 찾는다. 새로 만들지 않고 이 코드를 확장한다.
3. **칼 조작.** 클릭 베기와 물리 드래그(F6 전환)가 함께 있다. 이번 프로토타입은 **클릭 베기만** 쓴다. 드래그 코드는 지우지 말고 끄기만 한다.
4. **공유 래그돌 조작.** 다이빙, 잡기, 벽타기는 폰 러쉬가 쓰고 있다. 전역으로 지우지 말고, **모드별로 끄는 설정**으로만 막는다.
5. **폰 러쉬의 폰 스킬.** 첫 두 걸음 구현이 있으면 재사용한다. 소드 파이트용 차이는 §7.2에 있다.
6. **피격 공통 계약.** `IHitReceiver`처럼 이미 있는 계약을 쓴다. 게임 모드 코드가 래그돌 구현 타입에 직접 의존하지 않게 한다.

## 3. 핵심 규칙

1. **떨어뜨린 수가 점수.** 상대가 판 밖으로 떨어질 때마다 우리 팀이 1점을 얻는다. 스스로 떨어져도 상대 팀에 1점이 간다. 먼저 10점을 낸 팀이 이기고, 4분이 지나면 점수가 높은 팀이 이긴다.
2. **기물은 시작할 때 고른다.** 킹·퀸·룩·비숍·나이트 중에서 고르고, 같은 팀 안에서는 겹칠 수 없다. 상대 팀과는 겹쳐도 된다.
3. **떨어지면 폰, 폰이 잡으면 빼앗는다.** 떨어진 말은 3초 뒤 폰으로 부활한다. 장외의 공로자(§8.2)가 **그 순간 폰**이고 떨어진 말이 폰이 아니면, 공로자는 떨어진 말의 기물이 된다. 빼앗기로 생긴 팀 안의 기물 중복은 허용한다.
4. **폰도 스킬이 있다.** 폰의 F는 첫 두 걸음이다(§7.2). 폰에게 E는 없다.
5. **2분부터 판이 줄어든다.** 30초마다 유령 기물 하나가 칸을 지운다(§9).

## 4. 경기 상태 기계

방장만 상태를 바꾸고, 참가자에게는 상태와 시작 시각을 알린다.

| 상태 | 들어오는 조건 | 하는 일 | 나가는 조건 |
| --- | --- | --- | --- |
| `Pick` | 경기 씬 로드 | 기물 선택 UI. 15초 제한, 시간이 끝나면 남은 기물에서 무작위 | 전원 확정 또는 시간 끝 |
| `Countdown` | Pick 종료 | 출발 칸에 배치, 3·2·1 표시, 입력 잠금 | 3초 |
| `Playing` | Countdown 종료 | 경기 시계 진행, 점수·부활·빼앗기·판 축소 | 10점 도달 또는 4:00 |
| `SuddenDeath` | 4:00에 동점 | 다음 1점을 낸 팀 승리, 판 축소 계속 | 1점 발생 |
| `Result` | 승패 결정 | 슬로 1.5초 뒤 결과 화면(팀, 점수, 장외·빼앗기 기록) | 로비 복귀 입력 |

4:00에 동점이면 SuddenDeath로 간다. SuddenDeath가 60초 넘게 이어지면 무승부로 끝낸다.

## 5. 경기장

하늘에 뜬 평평한 체스판 하나만 둔다. 장애물, 난간, 서재 배경은 넣지 않는다.

| 항목 | 값 |
| --- | --- |
| 판 | 8×8칸, 칸 2 m (판 16 m), 칸마다 독립 오브젝트 (§9에서 떨어뜨림) |
| 장외 판정 | 골반이 판 윗면에서 3 m 아래 (기존 값 유지) |
| 떨어지기 시작 | 공중에서 판 바깥으로 수평으로 벗어난 순간, 또는 판 윗면에서 0.25 m 아래로 내려간 순간. E 스킬 발동 시점의 기준(§7.4) |
| 출발 칸 | 흰 팀은 1\~2랭크, 검은 팀은 7\~8랭크 가운데 칸에 한 명씩 |
| 부활 칸 | 우리 진영 2\~3랭크 칸 중에서, ① 지워지지 않았고 ② 다른 말과 1.2 m 이상 떨어져 있으며 ③ 가장 가까운 적과의 거리가 가장 먼 칸 |

칸 크기는 인원에 따라 바꿀 수 있게 한 값으로 둔다. 4 대 4 이상은 2.5 m로 시험한다.

### 7.1 칼 — 클릭 베기

기존 README의 클릭 베기 값을 그대로 쓴다. 아래는 확인용이며, README 값과 다르면 README가 맞다.

| 항목 | 값 |
| --- | --- |
| 준비 / 판정 / 회수 | 0.16초 / 0.2초 / 0.34초 |
| 판정 | 앞쪽 원뿔 ±45°, 거리 1.45 m 안의 가장 가까운 적 1명. 공격 1회당 대상 1명에게 1번만 |
| 밀림 | 수평 3.4 m/s + 위 1.05 m/s, 넘어짐 0.65초 |
| 아군 | 칼로는 넘어뜨리지 않음. 몸 충돌은 그대로 |

누운 상대를 다시 베는 연속 타격은 막지 않는다(R46).

### 7.2 폰 F — 첫 두 걸음

| 항목 | 값 |
| --- | --- |
| 걸음 | 1.5 m를 0.2초에 (7.5 m/s), 두 번. 사이 간격 0.22초 |
| 두 번째 걸음 | 방향을 바꿀 수 있음. 폰 러쉬처럼 근처 적에게 유도되는 버전이 이미 있으면 그것을 씀 |
| 대각선으로 부딪힘 (진행 방향과 25\~75°) | 상대를 넘어뜨림. 밀림 4.5 m/s + 위 1.2 m/s |
| 정면으로 부딪힘 (25° 미만) | 둘 다 2 m/s로 튕기고 폰은 0.3초 휘청. 남은 걸음은 취소 |
| 판정 거리 | 0.84 m (몸 겹침 방지 거리 0.76 m보다 커야 함) |
| 쿨 | 5초 |

걸음 도중 판 밖으로 나가는 것은 막지 않는다. 폰 스스로 판단할 몫이다.

### 7.3 기물 F·E

STATUS R113의 스킬 10종을 동작과 수치 그대로 쓴다. 이번 작업에서 바꾸는 것은 아래뿐이다.

| 항목 | 변경 |
| --- | --- |
| 쿨타임 | 시험 씬의 2초 대신 기획 쿨 사용: 킹 F 8 / 퀸 F 8 / 룩 F 7 / 비숍 F 8 / 나이트 F 7초, 킹 E 20 / 퀸 E 15 / 룩 E 18 / 비숍 E 18 / 나이트 E 16초. 한 곳에서 바꿀 수 있는 설정값으로 둠 |
| 쿨 시작 | 경기 시작 시 F·E 모두 준비. 빼앗아서 얻은 기물은 F 준비, E는 쿨 절반 남음. 부활한 폰은 F 준비 |
| 기물 무게 | 킹 밀림 40% (STATUS 값) |
| 반격 | 킹 F는 칼만 받아낸다. 스킬은 그대로 맞는다 |

### 7.4 같은 순간에 겹칠 때 판정 순서

방장은 같은 물리 틱 안에서 아래 순서를 따른다.

1. 떨어지는 몸 하나에는 E가 하나만 걸린다. 떨어지는 동안 쓸 수 있는 것은 자기 E(킹 귀환, 나이트 역전)뿐이다. (R236: 비숍 E가 아군을 끌어올리는 "구원의 손"에서 가장자리를 빠져나가는 "대각선 미끄럼"으로 바뀌어, 아군 비숍이 이어받는 순서는 없어졌다.)
2. E의 발동 기준 시각은 §5의 "떨어지기 시작"이다. 위로 높이 튕겨 판 밖 허공을 나는 몸도 판 가장자리를 벗어난 순간부터 센다.
3. 퀸 일섬과 킹 반격 자세가 만나면 반격이 이긴다.
4. 룩 성벽 붕괴 위의 몸은 무너지지 않은 옆 칸 가장자리를 기준으로 E를 쓴다.
5. 유령 기물이 지운 칸은 되살아나지 않는다. 룩 붕괴가 무너뜨린 덩어리가 유령 예고와 겹치면 다시 솟지 않는다.

## 8. 낙사·점수·빼앗기·부활

### 8.1 장외 처리 순서

장외(골반 3 m 아래)가 확정되면 방장이 한 번만 아래를 처리한다.

1. 상대 팀 점수 +1
2. 공로자 결정 (§8.2)
3. 빼앗기 판정 (§8.3)
4. 떨어진 말을 3초 부활 대기에 넣음
5. 킬 피드 기록: "흑 2 ← 백 1의 폰 걸음", "백 2 — 스스로"

한 번 장외된 말은 부활할 때까지 다시 장외 처리하지 않는다. **부활할 때 장외 플래그를 반드시 초기화한다.** 시연을 만들 때 이 초기화가 빠져서 두 번째 장외부터 점수가 안 올라간 적이 있다.

### 8.2 공로자

떨어진 말을 **마지막으로 친 적**이 3초 안에 있으면 그 적이 공로자다. 칼, 스킬, 스킬로 날아온 몸, 나이트 뒷발차기가 모두 "친 것"에 들어간다. 룩 성벽 붕괴로 떨어진 **상대** 말은 그 룩이 공로자다. 아래 경우는 공로자 없이 "스스로"로 기록한다: 3초 안에 친 적이 없음, 마지막으로 친 쪽이 아군, 유령 칸이 떨어짐, 자기가 쓴 성벽 붕괴로 룩 자신이 떨어짐.

### 8.3 빼앗기

- 조건: 공로자가 장외 확정 순간에 폰이고, 떨어진 말이 폰이 아님
- 결과: 공로자의 기물이 떨어진 말의 기물로 바뀜. 모습, 스킬, 무게가 즉시 바뀌고 머리 위에 "빼앗음" 표시
- 쿨: F 준비, E는 해당 E 쿨의 절반이 남은 상태
- 공로자가 이미 폰이 아니면 아무것도 바뀌지 않음
- 떨어진 말은 폰으로 부활

### 8.4 부활

장외 확정 3초 뒤 §5의 부활 칸에 폰으로 놓는다. 1.25초 동안 보호(칼과 스킬 무시, 반투명)한다. 보호 중에 공격하면 보호가 바로 끝난다. 부활 연출(손이 내려놓기)은 §11의 최소안을 따른다.

## 9. 판 축소 — 유령 기물

2:00부터 30초마다 한 번, 미리 정한 목록에서 하나를 고른다.

| 시각 | 유령 | 지우는 칸 |
| --- | --- | --- |
| 2:00 | 룩 | 한 줄 6칸 (양 끝 칸은 남김) |
| 2:30 | 비숍 | 짧은 대각선 4칸 |
| 3:00 | 나이트 | L자 3칸 |
| 3:30 | 퀸 | 가장자리 한 바퀴 전부 |

- 예고: 칸이 1.5초 동안 깜빡이며 빛나고, 유령 기물이 경로를 따라 미끄러지듯 지나간다. 예고가 끝나면 칸이 떨어진다.
- 위치: 2:00·2:30·3:00의 줄·대각선·L자 위치는 경기마다 무작위다. 단, 아래 두 조건을 지켜야 하고, 어기면 다시 뽑는다(최대 20번, 실패하면 그 회차는 건너뜀). ① 남은 칸이 한 덩어리로 이어져 있음(4방향 연결 기준) ② 각 팀 부활 칸이 최소 2개 남음.
- 3:30 퀸은 고정이다. 그 뒤에는 부활 칸 후보를 남은 판 안쪽 칸으로 바꾼다.
- 이동 AI가 없으므로 피하는 건 사람이 한다. 예고 칸 위에 서 있으면 그대로 떨어진다.
- 일정은 방장이 정한 경기 시작 시각 + 고정 시각으로 계산한다. 참가자는 씨앗값과 시작 시각만 받아 같은 결과를 계산한다. 칸 상태를 매 틱 보내지 않는다.

| 경기 상태, 시계 | 상태 전환, 시작 시각 | 상태 값, 시작 시각 (시계는 각자 계산) |
| 점수, 공로자, 빼앗기 | 장외 확정 순간에 한 번 | 점수 두 개, 장외·빼앗기 순간 신호 1회 |
| 기물 종류 | 선택·빼앗기·부활 때 바뀜 | 말마다 기물 종류 상태 값 |
| 칼·스킬 적중 | 방장 물리 기준 | 결과는 래그돌 동기화로 보임. 적중 연출은 순간 신호 |
| 순간이동·끌어올리기 E | 방장 위치가 기준 | 참가자 화면은 위치 보간. 예측하지 않음 |
| 판 축소 | 씨앗값, 시작 시각으로 결정 | 씨앗값 1회 |
| E 준비 상태 | 쿨 계산 | 말마다 E 준비 여부 상태 값 (적에게도 보임) |

참가자 입력은 기존처럼 방장에게 보낸다. 칼 클릭은 누른 순간 자기 화면에서 준비 동작을 먼저 보여 주고, 판정은 방장이 한다.

## 11. HUD와 연출 (최소안)

프로토타입에서는 규칙이 읽히는 것까지만 만든다. 미술 다듬기는 다음 단계다.

| 요소 | 최소안 |
| --- | --- |
| 위 가운데 | 점수 "3 : 2", 남은 시간, 양 팀 말의 현재 기물 아이콘 (떨어져 있으면 흐리게) |
| 머리 위 | 이름과 기물 아이콘. E가 준비되면 금색 "E" 표시가 붙고, 적에게도 보임 |
| 장외 | 화면 가운데 짧은 도장 "장외! +1"과 킬 피드 한 줄 |
| 빼앗기 | 공로자 머리 위 "빼앗음! 나이트"와 금색 빛기둥 0.8초 |
| 부활 | 칸 위에 빛 고리 0.8초 뒤 폰 등장, 보호 중 반투명. "손이 내려놓기"는 나중에 미술 작업 때 |
| 판 축소 | 예고 칸 빛남과 반투명 유령 기물 이동 (§9) |
| 마지막 30초 | 시계가 빨개지고, 남은 10초는 초를 소리로 |
| 결과 | 승패, 점수, 팀별 장외·빼앗기 횟수 |

E 슬로 0.3초와 화면 당김은 STATUS 방식대로 쓴 사람과 맞은 사람 화면에서만 한다. 경기 결과가 정해진 뒤의 1.5초 슬로만 모두에게 보인다.

싸우는 봇이 없으므로, 혼자서도 규칙을 검증할 수 있는 키를 만든다. 개발 빌드에서만 켠다.

| 키 | 동작 |
| --- | --- |

| F9 | 경기 시계를 1:55로 (판 축소 바로 앞) |
| F10 | 모든 쿨 초기화 |
| F11 | 정지 더미 소환 (상대 팀, 기물 선택 가능) |
| F12 | 판정 표시 켜기·끄기 (칼 원뿔, 스킬 범위, 떨어지기 시작 시점, 장외 선) |

## 13. 구현 단계와 완료 기준

각 단계가 끝나면 완료 기준을 직접 시험하고 결과를 보고한 뒤 다음 단계로 간다.

| 단계 | 내용 | 완료 기준 |
| --- | --- | --- |
| 1. 합치기 | 스킬 브랜치를 main으로, 모드별 조작 끄기 | 폰 러쉬와 소드 파이트 둘 다 기존처럼 실행됨. 폰 러쉬에서 벽타기 정상 |
| 2. 경기 루프 | §4 상태 기계, §5 판, 점수, 부활(폰으로), 4:00·10점 종료, 서든데스 | F7로 10점을 내면 Result로 감. 부활은 늘 폰이고 장외가 매번 1점씩 올라감 |
| 3. 기물 | 선택 UI, 기물별 F·E 연결, 기획 쿨, 빼앗기, 폰 F | F8로 폰이 된 뒤 F7로 적 나이트를 떨어뜨리면 나이트가 됨. 폰이 아니면 안 바뀜 |
| 4. 판 축소 | §9 일정, 예고, 연결 검사, 부활 칸 갱신 | F9 뒤 2:00에 룩 줄이 사라짐. 20경기 무작위 시드에서 섬이 생기지 않음 |
| 5. 온라인 | §10 동기화 | 2명 접속에서 점수, 기물, 판 축소, E 표시가 양쪽 화면에서 같음 |
| 6. HUD | §11 최소안 | 처음 보는 사람이 점수와 빼앗기를 설명 없이 이해함 (팀원 1명 확인) |

첫 플레이테스트(팀 5명 + 더미 1)에서는 아래를 기록한다: 경기당 장외 수와 시간대 분포, 빼앗기 횟수, 기물별 E가 장외를 막은 횟수, 나이트 E 발동 횟수, 룩 붕괴 1회당 점수 득실.
