## 체크메이트 — 흰 팀 승리

3분 라운드를 약 45초로 압축했습니다. 유령 기물은 실제 기획(90초부터)보다 일찍 나옵니다.

| 승리 | 상대 킹이 판 밖으로 떨어지면 체크메이트, 라운드 승리. 3판 2선승 |
| --- | --- |
| 기물 | 팀마다 킹 1명, 나머지는 폰으로 출발. 상대 끝 줄에 1.5초 서 있으면 미리 고른 기물로 승격. 퀸은 팀에 한 명 |
| 부활 | 킹이 아닌 말은 떨어지면 3초 뒤 폰으로 돌아온다. 손이 부활 칸에 내려놓고, 1.25초 보호 |
| F 스킬 | 킹 왕의 반격, 퀸 꼬치 베기, 룩 열린 파일 포격, 비숍 관통 핀, 나이트 포크 강하 (STATUS R113 수치) |
| E 스킬 | 킹 왕의 귀환, 퀸 체크메이트 일섬, 룩 성벽 붕괴, 비숍 구원의 손, 나이트 벼랑 끝 역전. 준비되면 이름표에 E |
| 판 | 8×8칸(칸 2 m), 룩 모양 받침 4개, 양옆 낮은 난간. 엔드게임에 유령 기물이 칸을 지운다 |
| 새 제안 | 비숍에게 묶인 킹은 무게로 버티지 못한다. 시연의 마지막 장면이 이 규칙에 기댄다 |

움직임은 단순화한 물리로 계산하고 래그돌다운 흔들림은 연출로 덧붙였습니다. 실제 손맛과 네트워크 지연은 반영하지 않았습니다.
