**거울 방식(사용자 11-08 "거울은 3d ai로 생성하면 막혀서 거울 같은 느낌이 없잖아" → 선택 "방만 비침"):** 거울 면은 Tripo로 만들지 않는다. 시트 02를 속이 뚫린 빈 틀로 다시 만듦(`AssetRefs/PROMPT_02_frames.md`, 이전 판 `F_assets_02_mirrors_lights_v1_filled.png` 보관, Tripo 권장 면 수 시트 전체 약 45,000: 팀 문짝 틀 6,000·벽 거울 틀 3,000·스포트라이트 2,500). 팀 문짝은 게임 문짝처럼 직사각형으로 바꿈. Tripo가 구멍을 막아 내보내면 Blender에서 안쪽을 잘라 낸다. 거울 면은 Blender가 빈 자리에 평평한 판(`MIRROR_Surface`)을 넣고, Unity에서 거울 재질(금속 1·매끈함 약 0.95, `PR_Mid_SoftMirror`는 견본용으로만) + 방마다 상자 투영 반사 프로브(벽·샹들리에·창 같은 방 모습만 비침, 움직이는 폰·무용수는 안 비침, 게임 물체가 두 벌로 보이지 않음)로 만든다. 실시간 거울 반사(플래너 반사)는 쓰지 않는다.
