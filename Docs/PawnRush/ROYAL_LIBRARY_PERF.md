## 3. 문제가 큰 곳 (우선순위)

1. **원경 소품 10개가 그리기 호출 610개** — FBX 하나에 오브젝트가 55 ~ 68개씩 따로 들어 있음(잉크병 · 시계 · 돋보기 부품이 안 합쳐짐). 재질 칸별로 합치면 소품당 3 ~ 9개, 전체 약 60개로 줄어듦. **가장 큰 이득, 모양 변화 없음.** (R7 세션 몫)
   - **결과(11-18, R7 세션)**: `rl_r7_desk_props_model.py` export에 재질 칸별 합치기(`merge_by_slot`)를 넣어 10곳 다시 냄 — 오브젝트 610 → 77(자리당 6 ~ 9, 유리 · 홍차도 각자 한 덩어리), 삼각형 85,192 그대로, 모양 · 위치 · 재질 · UV 그대로(블록아웃 확인 스틸 전과 같음). Unity 확인 전.
2. **책장 13개 = 188,604 삼각형 · 호출 130** — 책장 하나 14,508 삼각형 · 재질 10칸(가죽 5색 · 양피지 · 놋쇠 …). 책 하나하나를 가볍게(목표 책장당 5,000 ~ 7,000) + 멀리용 LOD. (R4 몫, 체스 방도 같은 모델을 씀)
3. **체스 기물 32개 = 약 140,000** — 폰 4,000 × 16. 판이 넓어 대부분 멀리 보임 → 폰 1,500 · 나머지 3,000 정도 + LOD. 점유 표시 864 × 32는 사각 테두리라 100 이하로 충분. (R6 몫)
4. **가구가 무거움** — 지휘관 의자 2개 34,128 · 발받침 20,536 · 체스 방 벽 46,678 · 힌트판 5개 27,900(하나 5,580) · 차원문 26,364 · 타자기 26,644. 버튼 장식 · 징 · 둥근 모서리 세그먼트를 줄일 여지. (R5 · R3 · R1)
5. **거인 2명 = 64,428(스킨드, 오브젝트 13개씩)** — 스킨드 메시는 매 프레임 CPU/GPU 스키닝: 오브젝트를 합쳐 스킨드 메시 1 ~ 2개로. (거인 세션)
6. **LOD 없음 · 가림 컬링 없음** — 모델이 Play 때 코드로 걸려서 정적 배칭 · 미리 구운 오클루전이 안 됨. 큰 한 덩어리 모델(체스 방 벽 46k, 앞 서재 벽 35k)은 화면에 조금만 보여도 통째로 그림 → 10 m 칸처럼 잘라 두면 컬링이 먹음(마차뜰 R681 방식).
7. **그림자** — 해 그림자가 껍데기(벽 · 천장) 말고는 다 그림자를 드리움 → 그림자 패스 호출이 거의 그만큼 더 듦. 작은 소품 · 책 · 기물 표시 · 바닥 판의 그림자 끄기, 그림자 거리 확인.

텍스처 38.5 MB는 PC에서는 괜찮음(마차뜰 약 33 MB와 비슷). 저사양 단계에서 반으로 줄이려면 텍스처 밉맵 제한 그룹을 쓰면 됨(전역 Quality 설정이라 승규 확인 필요).

## 4. 아직 안 한 것 (실측)

- Unity Play에서 Stats 창 · Frame Debugger · Profiler로 실제 SetPass/그리기 호출 · 삼각형 · 프레임 시간(체스 방 한가운데, 앞 서재 입구, F2 둘러보기로 위에서 전체).
- 목표 제안: 그리기 호출 500 이하, 화면에 그려지는 삼각형 60만 이하, 60 fps(PC 기준) — 승규가 정할 것.

## 5. 결정 (승규 11-18)

- "삼각형 110만이면 안해도 되지 않나?" → 네: PC에서 삼각형은 문제 아님. 면 수 깎기 · LOD · 조각 나누기는 Unity 실측에서 프레임이 떨어질 때만.
- 할 만한 것 하나: 원경 소품 10개 부품 합치기(그리기 호출 610 → 약 60, 모양 그대로 — R7 세션 몫).
- **GPU Resident Drawer + GPU 가림 컬링은 자이언트 체스 코스가 마무리된 뒤 다른 Claude 계정에서 진행**(승규). 이어받는 쪽 메모:
  - 물리(PhysX · 래그돌)는 GPU로 못 옮김. 이 기능은 CPU의 그리기 명령 부담을 GPU로 넘김 → CPU 병목이면 프레임이 오르고, GPU 병목이면 거의 그대로. 그래픽 모습은 바뀌지 않음(아낀 성능을 그림자 · 디테일에 쓸 수 있음).
  - 먼저 실측: GiantChessCourse Play → 체스 방 한가운데, Game 창 Stats(CPU main · render thread ms, Batches)와 Profiler(CPU vs GPU 시간). 켜기 전 수치를 남겨 둘 것.
  - 조건: URP 렌더링 경로 Forward+, URP 에셋의 GPU Resident Drawer(Instanced Drawing) · GPU Occlusion Culling — **프로젝트 전체 설정**이라 모든 장면(왕의 서재, 마차뜰, 미니게임 방, 칼싸움)을 다시 확인. 자체 셰이더(마차뜰 `RcyTintLit` 등) · property block으로 색을 바꾸는 렌더러(팀 색, 경고 빨강) · 스킨드 메시(래그돌, 거인)는 예전 방식으로 그려짐(깨지지 않음). 셰이더 변형 · 빌드 크기 조금 늘어남. 문제 있으면 설정만 되돌리면 됨.
