## 방법

1. 빈 씬 Play에서 프리팹 하나씩 `Instantiate` → `PlaceEntryOn` · `Configure(슬롯, 씨앗, 6, 0)` (한 팀 6명 = 가장 큰 규모) → 활성화 → 5프레임 + 1초 기다려 코드가 만드는 것까지 세운 뒤 집계 → 지움.
2. MeshRenderer(MeshFilter) · SkinnedMeshRenderer의 sharedMesh 각 submesh `GetIndexCount / 3`. 같은 메시도 놓인 수만큼 셈.
3. **활성**: activeInHierarchy · enabled · forceRenderingOff 아님, LODGroup은 LOD 0만. **하위 LOD**는 따로. **전체**는 숨긴 것 · 하위 LOD 포함.
4. 카메라 시야 · 가림, 그림자 · 추가 패스, 플레이어, 구간 사이 복도, 실행 중 생기는 효과는 빠졌다. 한 프레임 실제 렌더 수와 다르다.
5. 조사용 스크립트는 사본에만 넣었다가 지웠다(저장소 변경 없음).
