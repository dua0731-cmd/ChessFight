## 집계 방법과 한계

1. 원본 씬·프리팹을 저장하거나 바꾸지 않고 Unity 임시 Preview Scene에 세 구간 프리팹을 각각 복제했다.
2. 구간 컴포넌트의 Awake를 호출했다. 정원·작전 회의실은 코드로 Content를 만들며, 대계단은 현재 레이아웃과 실제 아트를 입힌다. 빈 프리팹의 메시 0개나 대계단의 그레이박스만 세지 않았다.
3. MeshRenderer/MeshFilter 및 SkinnedMeshRenderer의 sharedMesh에 대해 각 submesh의 GetIndexCount / 3을 합했다. 동일 메시도 배치한 수만큼 포함했다. 세 구간 모두 삼각형 토폴로지였으며 LODGroup은 0개였다.
4. 활성 합계에는 activeInHierarchy, Renderer.enabled가 참이고 forceRenderingOff가 거짓인 메시만 포함했다. 비활성·숨긴 메시도 별도로 합했다.
5. 카메라 시야·가림 처리 전의 구간 전체 기본 구성이다. 그림자·반사·셰이더 추가 패스, 플레이어, 구간 연결 복도, 다른 구간, 실행 중 생성되는 효과·장애물 변화는 포함하지 않았다. 실제 한 프레임의 렌더 삼각형 수와 다르다.
6. 복제 구간과 Preview Scene을 finally에서 정리했다. 조사 도중 사용자가 연 Lobby 씬을 바꾸거나 저장하지 않았다.
