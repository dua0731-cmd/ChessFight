## 5. 파일과 검사

- 실제 Three.js 객체·모의 DOM으로 **10종 장면·카메라70건**, 백/흑/양팀의 문 소유권, 앞 장소50조합, 게임 소품10종·초반 장식3종 표시, A/C/D 고유 구조·C 다리4m 진입 검사 통과.

## 6. R312 실제 프리팹으로 이어 보기

`Assets/Prefabs/PawnRushSections/`에 저장한10개 `*_MG_*.prefab`이 현재 구현이다. Unity **ChessFight → Pawn Rush → Open Mini-game Prefab Test**에서 `PawnRush_MiniGames.unity`를 열고 숫자1~0으로 고른다. **Pawn Rush → Build → All Mini-game Prefabs**는 코드에서10개를 다시 굽고 목록을 갱신한다. 재생성·키 설명은 [구간 프리팹 안내](PAWN_RUSH_MINIGAME_SECTIONS.md#1-파일과-여는-법)를 따른다.

정적 건축·메시·재질은 자산으로 저장한다. Play 시작에는 `Game socket`의 기능 게임을 다시 설치하고 장식·글꼴을 재연결하므로, 소켓 안의 수동 편집은 Play 때 유지되지 않는다. 외형 수정은 `MiniGamePalaceArt`의 빌더에 반영해 다시 굽는다. R312의 F 목장식은0.68m, G 도착 장식은 실제 Garage 위치와 Road→Garage 방향에 맞춘다. 기존 규칙·충돌은 장식이 소유하지 않는다.

AI의 실제 Unity 로드·팀별 문 연결·초기화 검사는 통과했다. 자동 완료 이벤트를 쓴 연결 검사이며 **10종 퍼즐의 직접 입력·완주, 사용자 Unity·Steam 확인,12명 성능은 아직 전**이다. HTML 동작 예시와 R311 컨셉 이미지는 실제 게임 확인을 대신하지 않는다.
