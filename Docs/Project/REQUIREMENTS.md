# 사용자 요구사항 기록

사용자(메인 기획자)가 AI에게 요청한 것을 **시간순으로 전부** 적는다. 새 도구나 새 채팅은 이 표를 보고 "사용자가 무엇을 원했고, 어떻게 풀었고, 무엇이 남았는지"를 파악한다.

- **새 요청을 처리하면 맨 아래에 한 줄 추가한다.** 질문에만 답한 경우도 적는다(결과: 답변).
- 상태: `완료`(사용자 확인까지 끝) · `구현됨`(코드·테스트는 끝, Unity 확인 대기) · `답변` · `진행 중` · `보류`
- 요청 원문은 요지만 옮기되, 사용자가 강조한 조건은 빠뜨리지 않는다.

## 2. 요구사항에서 뽑은 지켜야 할 조건

여러 요청에 반복해서 나온 사용자 기준이다. 새 작업도 이 기준을 따른다.

| 조건 | 나온 요청 |
|---|---|
| 모든 PC에서 Pull만 하면 똑같이 동작해야 한다 (로컬 설정, 수동 설치에 기대지 않음) | R5, R6 |
| 변경점이 저절로 생기면 안 된다 | R6 |
| 폴더는 꼭 필요한 최소로, 한눈에 보이게 | R3 |
| UI는 한국어, 화면 전체, 폴가이즈풍, 우측 하단 시작 버튼 | R7, R19 |
| ~~게임 시작 버튼이 곧바로 매칭을 시작하면 안 된다 (단계를 거친다)~~ → R19 참고 영상대로 **게임 시작 = 파티 전체 매칭**, 대신 바로 위 모드 카드가 무엇을 시작할지 보여 준다 | R7 → R19 |
| 로비는 참고 영상처럼: 파티가 가운데 줄지어 섬, 모드 카드 + 게임 시작, 매칭 패널 | R19 |
| 게임 모드 하나 = 미니게임 하나, 모드마다 따로 매칭 | R19 |
| 캐릭터 조작·물리(래그돌)는 로비·게임모드 브랜치에서 바꾸지 않는다 | R18 |
| Steam 오버레이 대신 게임 안 UI를 쓴다 | R10 |
| 플레이어는 프리팹, UI는 UXML, 입력은 Input System 방향 (단, 클릭 문제로 현재 백엔드는 Old) | R2, R8 |
