# 사용자 요구사항 기록

사용자(메인 기획자)가 AI에게 요청한 것을 **시간순으로 전부** 적는다. 새 도구나 새 채팅은 이 표를 보고 "사용자가 무엇을 원했고, 어떻게 풀었고, 무엇이 남았는지"를 파악한다.

- **새 요청을 처리하면 맨 아래에 한 줄 추가한다.** 질문에만 답한 경우도 적는다(결과: 답변).
- 상태: `완료`(사용자 확인까지 끝) · `구현됨`(코드·테스트는 끝, Unity 확인 대기) · `답변` · `진행 중` · `보류`
- 요청 원문은 요지만 옮기되, 사용자가 강조한 조건은 빠뜨리지 않는다.
