**G30 (R56, 2026-09-27): 직접 테스트를 미루고 맵 우선 순서대로 왕의 계단/결승까지 연결한다.** 기획 §7.3/§8.3의 수치를 오프라인 1차 규칙으로 적용한다. 마지막4승격도 G29의10초/양 팀 집결을 따른다. 결승 T0는 두 킹 도착 또는 첫 킹+25초, 누적8초/적 단상 점유 시 정지,50·100·140초 붕괴/3초 예고,140초 전5초 탑 재진입, 이후2배/킹 추락 패배,180초 게이지 비교. 원문 미정인 동시 킹 추락/동률은 시험용 무승부로 두며 확정 밸런스로 표기하지 않는다. 기본 물리·카메라·로비·온라인은 보존한다. 세밀한 앉기/외형·음향·시각 슬로모션은 후속이다.

**G29 (R55, 2026-09-27): 빨강 끝에서 승격 결정→10초→양 팀 미도착 인원 집결→벽 개방.** 사용자 확정으로 기존 비동기 파랑 선착순 진입 기획을 대체한다. 첫2/다음3승격은 양 팀 합산 자리 수이며, 집결은한번. 도착자는 제자리·해당 승격 유지, 뒤처진 이전 기물은 다음 빨강 규칙에 맞춰 폰(고정 킹 유지). 물/포획/잡기 예약을 정리하고 Update에서 이동한 후 개방한다. 다음 연결 코스는 성벽/시소이며 밧줄 자리는 임시 다리. 시소120초 완화는10°/7°로3° 간격 유지,150초 구제 다리는4명 완료를 대신하지 않는다. 새 능력/공통 물리/온라인은 별도 후속.

**G28 (R54, 2026-09-27): 기물 능력 추가보다 맵·미션을 먼저 만든다.** 사용자가 G27의 능력 우선 순서를 변경했다. 첫 연결 코스(장난감 상자→승격→잡은 말 상자→출구)를 별도 오프라인 씬/구간 프리팹으로 만든 뒤 직접 플레이하며 조정한다. 능력 시험장·공통 조작·다른 채팅은 보존. 미션1차 안의 수치는 확정 밸런스가 아니다. **G27 (R52, 2026-09-27): 킹 러쉬는 `JY-gpt_gamemode@852eb2b`에서 별도 `JY-kingrush`로 개발한다.** 사용자가 `JY-ragdoll_v2` 출발 제안을 정정했다. 소드파이트/로비 기반은 유지하되 다른 채팅의 미커밋 변경을 가져오거나 원본을 수정하지 않는다. 기획의 기물 동일 몸·6v6 고정 킹·승격·파랑에서만 E를 따른다. 먼저 독립 오프라인 기능 시험장, 능력 재미 확인 후 미션. 기존 KingRush 로비 연결을 새 오프라인 구현으로 덮어 멀티가 되는 것처럼 보이게 하지 않는다. 새로운 킹 선정/미션 승패 규칙은 확정하지 않았다.

**G26 (R51, 2026-09-27): 검 가시성·무게감 있는 선 보정형 드래그·강한 베기만 넉다운.** 사용자 실기에서 R50의 정확한 시선 정렬이 검을 몸 뒤로 숨겼다. 조준에 약간의 오른쪽/위쪽 각도를 두고, 발도 중 시점은 단순 감도 곱셈이 아닌 지연 추종/따라잡기로 바꾼다. 무게·각속도·목표 오차를 반영하고 전환/메뉴/수납 시 복원. 약한 접촉은 물리 접촉만, 충분한 실제 회전 에너지와 드래그 폭을 가진 칼만 공격 넉다운. 클릭 방식·F6 전환·빠른 발도·누운 적 강한 추가타 유지. 공통 Pawn/카메라 소스·튜닝 보존. 타격 규칙 차이로 Steam v10, CFS3/CFR4 레이아웃 유지. 손맛은 사용자 재확인.

**G25 (R50, 2026-09-27, 회전 반응·검 방향은 G26으로 대체): 클릭 베기와 물리 드래그를 둘 다 유지하고 경기 중 비교한다.** F6/Esc 메뉴에서 개인별 전환, 새 버튼 입력부터 공격. 카메라와 검 방향을 가깝게 하고 발도 반응을 빠르게 한다. 당시 사용자가 감속 요청을 철회해 45% 감도·150°/초 제한을 폐기했다. 공유 물리/카메라 소스 보존. CFS3/Steam v9; CFR4 ability2는 이 모드 채널에서만 선택 절대값.

**G24 (R49, 2026-09-27, 시점 감속은 G25로 대체): 소드파이트만 물리 칼 드래그 조작을 시험한다.** 사용자 요청은 허리 수납·좌클릭 발도·시점과 함께 드래그 베기·발도 중 느린 시점. 구현 해석은 누르는 동안 발도/놓으면 수납이며 최종 조작 확정은 아니다. 공유 래그돌/카메라 코드·튜닝은 보존한다. 호스트만 칼 물리/타격을 판정하고 참가자는 기존 CFR4 held/aim 입력만 보낸다. 칼 상태는 CFS2, Steam v8. 정지 접촉 중복 방지는 누운 상대의 다음 추가타 금지가 아니다.

**G23 (R48, 2026-09-27): 소드파이트 개발 테스트는 아군·적군별 정지 더미 인원을 정해 혼자 시작한다.** 지금은 AI 추격/공격을 만들지 않는다. 몸을 고정하지 않아 피격·장외·부활은 가능하다. 팀당 최대 6명 안에서 비공개 방장만 추가·제거하고 사람과 기존 파티 예약을 보존한다. 공개 12명 매칭은 변경하지 않는다.
