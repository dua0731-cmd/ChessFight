## R109 수정 (2026-10-10, 승규 님)

승규 님: "비숍 E 스킬 사용할 때 아군이 올라오면 **나 때문에 다시 떨어져**, 이거 수정해줘."

- 원인: 아군을 내려놓는 자리(아군 쪽 가장자리에서 1.2 m 안쪽)가 비숍이 서 있는 자리와 자주 겹쳐서, 끌려 올라온 아군의 몸이 비숍의 몸·칼과 부딪혀 다시 밖으로 튕겨 나감.
- 끌어올리는 동안과 내려놓은 뒤 **0.8초**(그 뒤에도 둘이 0.9 m 넘게 떨어질 때까지)는 **비숍과 그 아군이 서로 부딪히지 않음**(몸·칼 모두, 다른 기물과는 그대로). 손을 놓치면 0.3초 뒤 원래대로.
- **내려놓을 자리가 비숍과 1 m 안이면** 가장자리를 따라 옆으로(비숍에게서 먼 쪽부터 0.5 m씩, 2 m까지) 비켜 내려놓음.
- 자동 시험 `edge-bishop-close`(아군이 떨어진 뒤 비숍을 그 아군이 내려질 자리에 세우고 E): 아군이 비숍 옆 1.06 m에 서서 살아 있음. `edge-bishop`(구해짐)·`edge-bishop-hit`(비숍이 맞으면 아군 장외)도 그대로.

## R103 가장자리 스킬 (2026-10-10, 승규 님)

승규 님이 붙여 준 기획 「가장자리 스킬」(공통 규칙 + 기물별 5개) 그대로: "새로운 스킬이야 unity로 만들어줘. 기존 스킬보다 **연출이 살짝만 더** 있었으면 좋겠어, 아무래도 극적이니까. **조작은 모두 E키로 통일**한다. 현재는 테스트 단계이니 **스킬 쿨타임은 2초**로 한다."

- **키: E 한 번**(설정 창의 "스킬" 키, 기본 E). 조준·좌클릭 없음. 기존 F 스킬은 그대로 F(기획 "키는 지금 스킬과 따로").
- **가장자리 구역** = 발판 끝에서 2 m 안. 조건이 맞으면 오른쪽 아래 **E 표시가 기물 색으로 깜빡**이고, 쓸 가장자리 선이 **기물 색으로 빛나고**, 대상 발밑에 고리가 생긴다. 지금은 오프라인이라 내 기물 것만 보인다(기획: 상대 화면에도).
- **쿨타임**: 시험용 **2초**(Inspector `edge.testCooldown`, 0이면 기획 15~20초). **예고 중에 조건이 깨져 취소되면 반만** 돈다. 맞아서 끊기면 다 돈다.
- **극적인 순간 한 번씩**: 슬로 모션 0.3초(게임 시간, 빠르기 0.35) + 화면을 당겨 붙잡음 + 가장자리 선 번쩍 + 멈춤·흔들림. **시험장에서는 게임 전체가 느려지는 대역**이다(실제로는 쓴 사람·맞은 사람 화면만, 게임 시간은 안 멈춤 — 히트스톱과 같음). 왼쪽 창 "슬로 켜짐/꺼짐"으로 끔. 효과음 없음.
- 떨어지는 중: 발판 밖 허공 위에 있고 발이 안 닿으면 "떨어지는 중"으로 센다(구멍 위 포함). 골반이 발판보다 2 m 아래면 늦음, 3 m 아래는 장외.

## 조작 (임시)

**F = 조준 시작 → 좌클릭 = 발동 → 우클릭(또는 F 한 번 더) = 취소**(다른 스킬 시험 씬과 같은 방식, 10-09 승규 님 요청). 취소하면 쿨타임 없음. 킹은 조준 없이 F를 누르는 순간 자세.
기물: **1 킹 · 2 퀸 · 3 룩 · 4 비숍 · 5 나이트 · 6 폰** (또는 Z ◀ ▶ X). **F7** = 지금 기물 시험 배치(동쪽 가장자리 x = 7 쪽으로 더미를 세움), **F8** = 가장 가까운 적이 맵 어디서든 옆으로 와서 나를 벰(킹 시험, R102) / 감속·묶인 적이 있으면 아군이 그 적을 벰(비숍 시험) / 가장자리에 매달린 킹이면 적이 박힌 칼을 벰(R103), **F9** = 더미 원위치, **F10** = 왼쪽 창 숨김. 창 버튼은 Esc로 마우스를 푼 뒤.

**가장자리 스킬(R103): E 한 번.** **Shift+F7** = 지금 기물의 가장자리 시험 배치(동쪽 가장자리, 카메라도 돌려 줌), **Shift+F8** = 도우미: 킹 → 적이 나를 가장자리 밖으로 밀어냄(그다음 0.6초 안에 E) · 퀸 → 대상 적이 안쪽으로 걸어 들어옴(금색 선 동안이면 취소) · 비숍 → 적이 아군을 밀어 떨어뜨림(1초 안에 E) · 나이트 → 적이 뒤로 물러남. 룩은 도우미 없음(동쪽 가장자리를 보고 E, 0.8초 안에 걸어 나오기). 왼쪽 창 아래 "가장자리 스킬 (E)" 칸에 설명·지금 상태(왜 안 되는지)·쿨타임, 화면 오른쪽 아래 E 표시.

## 이펙트 (A)

경고 → 기다림 → 팍! → 남음 → 사라짐. 바닥 경고는 체스판 칸·고리이고 **보는 사람 기준 색**(내 것 크림 테, 우리 편 청록, 적 빨강 + 흐르는 줄무늬), 특별한 기물은 자기 색(킹 에메랄드, 퀸 금, 룩 주황, 비숍 보라, 나이트 하늘)으로 채운다. 준비 동안 차오르고 마지막 6장면에 꽉 참 → 2장면 하얗게 → 6장면에 사라짐(큰 원판은 하얗게 번쩍이지 않음: 화면을 덮어서). **조준(F 뒤 좌클릭 전)은 본인 화면에만 흐리게**. R99부터 그 위에 발동·기 모으기·잔상·화면 당김(위 R99 표).

- 킹: 앞에 에메랄드 아치(받아내기) + 반격 범위 고리 → 막으면 에메랄드 충격 고리·몸 번쩍 → 에메랄드 고리가 2.5 m로 퍼짐 + 먼지. 빈틈이면 발밑에 회색 줄무늬 고리. R99: 막는 순간 한 바퀴 베기 고리 + 머리 위 왕관 + 큰 잔상.
- 퀸(R99): 줄을 따라 금 테두리 칸 + 설 자리 금 고리 → 돌진: 금 잔상 2장면마다, 금 리본, 바닥 벤 자국 → 맞은 적마다 대각선 베기 + 금 반원·물방울, 넘어지면 금 잡힌 칸 → 서면 지나온 칸이 한꺼번에 하얗게 + 먼지.
- 룩(R99): 통로 칸(주황) + 가운데가 지그재그로 갈라짐 → 내려치는 순간 주황 충격 고리·돌 물방울 → **칸마다 돌탑(주황 띠·성가퀴)이 솟았다 가라앉음**, 그 칸이 하얗게 번쩍 + 먼지 → 장애물이면 충격 고리·돌 물방울.
- 비숍: 바닥 X + 1 m 고리, 묶임 조건이면 금색 + 적 뒤 가장자리까지 금 띠 → 두 광선(어깨 양옆 → X)이 예고 동안 굵어짐 → 쏘면 두꺼운 광선 번쩍 → 감속 적 발밑 보라 고리·물결, 묶인 적은 **바닥 보라 구멍에서 금색 손 둘이 솟아 발목을 움켜쥠**(R99, 그 전엔 금 말뚝 4개) + 금 고리, 쏠 때 하늘에서 기둥.
- 나이트: 착지점 말굽(하늘) + 두 자리 원 + 조준 중 날아갈 호 → 날아가는 동안 하늘 리본, 말굽이 착지 순간까지 줄어듦 → 두 자리에 하늘 충격 고리 + 먼지. R99: 뛴 자리 말굽 도장, 하늘색 잔상, 착지 때 두 자리로 뻗는 갈래 줄 + 기둥 고리.
- 공통 맞음: 몸 2장면 흰색 → 2장면 때린 기물 색, 반원(밀린 쪽), 물방울, 충격 고리(R99), 멈춤(3~6장면, 시험장은 게임 전체), 흔들림, 화면 당김(R99). 별·글자·숫자 없음.
