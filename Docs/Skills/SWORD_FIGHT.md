# 소드 파이트 기물 스킬 — 시험 씬 (R91)

2026-10-09 시작. 승규 님 요청: "레그돌 테스트 씬 말고 **지금 소드 파이트에 있는 씬**에서 테스트, **A 디자인**으로". 스킬 내용은 기획서 8장 「기물 난투와 스킬 6개」를 **저장소의 소드 파이트 규칙**(모두 칼을 듦 · 장외 1점 · 체력 없음 · 폰은 스킬 없음) 위에서 본 것이고, 수치는 프리비즈 영상(`Tools/Previz/SwordFightSkills`, 10-08)과 같은 **시험 시작값**이다. 이펙트는 세 모드 공통으로 고른 **A 「잉크 테두리 장난감 체스」**(공용 부품 `SkillInkKit`, R90). 소리 없음.

- **시험 씬** `Assets/Scenes/SkillTest/SwordFight_SkillTest/SwordFight_SkillTest.unity` = 경기 씬 `SwordFight.unity`를 복사하고 경기 오브젝트(`Sword Fight · skill test`)에 `SwordFightSkillBed`를 붙인 것. 메뉴 **ChessFight → Sword Fight → Open Skill Test** (없으면 이 메뉴가 만든다). 칼·14 m 발판·장외 점수·부활·더미는 경기 그대로다. 원본 `SwordFight.unity`는 그대로.
- 폴더 `SkillTest/SwordFight` → `SkillTest/SwordFight_SkillTest`(같은 GUID, 승규 님이 10-08 Unity에서 바꾼 이름을 그대로 올림).
- **스킬은 이 씬에서만 켜진다.** 시험장이 모든 전투원에 `SwordFightSkills`를 붙일 때만 있다. 경기 코드에는 작은 연결만 더했다: `SwordFightPawn.Skills`(입력 거르기, 킹의 받아내기, 스킬 중 칼 자세), `Scripted`(시험장이 더미 칼질을 잠깐 직접 넣을 때 경기가 더미 입력을 비우지 않음). 스킬이 없으면 모두 그대로다.
- 네트워크 패킷에는 스킬이 없어 **오프라인만**.

## 조작 (임시)

**F = 조준 시작 → 좌클릭 = 발동 → 우클릭(또는 F 한 번 더) = 취소**(다른 스킬 시험 씬과 같은 방식, 10-09 승규 님 요청). 취소하면 쿨타임 없음. 킹은 조준 없이 F를 누르는 순간 자세.
기물: **1 킹 · 2 퀸 · 3 룩 · 4 비숍 · 5 나이트 · 6 폰** (또는 Z ◀ ▶ X). **F7** = 지금 기물 시험 배치(동쪽 가장자리 x = 7 쪽으로 더미를 세움), **F8** = 옆 적이 나를 벰(킹 시험) / 감속·묶인 적이 있으면 아군이 그 적을 벰(비숍 시험), **F9** = 더미 원위치, **F10** = 왼쪽 창 숨김. 창 버튼은 Esc로 마우스를 푼 뒤.

| 기물 · 스킬 | 동작 | 시험 시작값 (기획 쿨) |
|---|---|---|
| 킹 · 왕의 반격 | 우클릭 → **받아내기 자세 0.5초**(제자리). 그 사이 적 칼이 오면 막고 **반경 2.5 m 적을 2.8 m 밀어냄**(넘어짐) → 후딜 0.4초. 칼이 안 오면 **빈틈 0.6초** | 8초 |
| 퀸 · 꼬치 베기 | 조준 = 6 m × 1.2 m 줄(걸을 수 있음) → 떼면 **0.45초 예고**(제자리) → 꿰뚫기: **첫째 3.0 m · 둘째 2.1 m · 셋째 1.5 m** 밀림 → 후딜 0.5초 | 8초 |
| 룩 · 열린 파일 포격 | 조준 = 10 m × 1.5 m 통로 → 떼면 **0.5초 예고**(제자리) → 바닥을 타는 충격파 18 m/s: **4 m 안 2.6 m · 그 뒤 1.6 m** 밀림. 단단한 장애물에서 끊김(예고선도). 발동 중 방향 못 바꿈 → 후딜 0.4초 | 7초 |
| 비숍 · 관통 핀 | 조준 = 화면 가운데가 가리키는 바닥(8 m까지) → 떼면 **0.4초 예고** → 두 광선이 X로 모임: 반경 1 m 적 **감속 40% 1.5초**. **맞은 적 뒤 2 m 안이 가장자리(바닥 없음)면 묶임 0.8초**, 이 조건은 조준 때부터 X가 금색으로 보임 → 후딜 0.35초 | 8초 |
| 나이트 · 포크 강하 | 조준 = 착지점(1.5~6 m) → 떼면 **0.55초 도약** → 착지 때 **진행 방향 ±50°, 1.8 m 앞 두 자리(반경 1.2 m)** 적 2.4 m 밀림 → 후딜 0.35초. 두 자리는 뛰기 전부터 보임 | 7초 |
| 폰 | 스킬 없음 (규칙) | — |

- 시험장 기본 **쿨타임 2초**(Inspector `testCooldown`, 0 = 기획 쿨).
- 밀림 거리는 실제로 잰 값으로 맞췄다: 넘어뜨리며 수평 1.45 m/s를 주면 약 1 m(probe `calibrate`: 3 / 5 / 7 m/s → 2.01 / 3.45 / 5.13 m). 무거운 기물은 1/무게만큼 덜 밀린다(킹은 거의 안 밀림).
- 스킬에 맞으면 0.65초 넘어짐(칼 맞을 때와 같음), 부활 보호 중인 기물은 안 맞음. 스킬 준비·발동 중 넘어지면 끊기고 쿨이 돈다.

## 이펙트 (A)

경고 → 기다림 → 팍! → 남음 → 사라짐. 바닥 경고는 체스판 칸·고리이고 **보는 사람 기준 색**(내 것 크림 테, 우리 편 청록, 적 빨강 + 흐르는 줄무늬), 특별한 기물은 자기 색(킹 에메랄드, 퀸 금, 룩 주황, 비숍 보라, 나이트 하늘)으로 채운다. 준비 동안 차오르고 마지막 6장면에 꽉 참 → 2장면 하얗게 → 6장면에 사라짐(큰 원판은 하얗게 번쩍이지 않음: 화면을 덮어서). **조준(우클릭 누르는 동안)은 본인 화면에만 흐리게**.

- 킹: 앞에 에메랄드 아치(받아내기) + 반격 범위 고리 → 막으면 에메랄드 충격 고리·몸 번쩍 → 에메랄드 고리가 2.5 m로 퍼짐 + 먼지. 빈틈이면 발밑에 회색 줄무늬 고리.
- 퀸: 줄을 따라 금 테두리 칸 → 꿰뚫기 금 리본이 줄 끝까지 → 맞으면 금 반원·물방울, 넘어지면 금 잡힌 칸.
- 룩: 통로 칸(주황) → 내려치는 순간 발밑 흰 고리 → **주황 벽이 바닥을 달리고 지나간 칸이 하얗게 번쩍** + 먼지 → 장애물이면 충격 고리·돌 물방울.
- 비숍: 바닥 X + 1 m 고리, 묶임 조건이면 금색 + 적 뒤 가장자리까지 금 띠 → 두 광선(어깨 양옆 → X)이 예고 동안 굵어짐 → 쏘면 두꺼운 광선 번쩍 → 감속 적 발밑 보라 고리·물결, 묶인 적은 금 말뚝 4개가 내려꽂히고 금 고리.
- 나이트: 착지점 말굽(하늘) + 두 자리 원 + 조준 중 날아갈 호 → 날아가는 동안 하늘 리본, 말굽이 착지 순간까지 줄어듦 → 두 자리에 하늘 충격 고리 + 먼지.
- 공통 맞음: 몸 2장면 흰색 → 2장면 때린 기물 색, 반원(밀린 쪽), 물방울, 멈춤(3~6장면, 시험장은 게임 전체), 흔들림. 별·글자·숫자 없음.
