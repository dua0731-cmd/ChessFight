## 조작 (임시 키)

**F = 모든 스킬**(이 씬에서 F는 랩 상호작용이 아님), 기물 바꾸기 **Z ◀ / X ▶** 또는 왼쪽 창 버튼. 퀸·룩·나이트는 **F로 조준 → 좌클릭으로 실행**, 우클릭 또는 F 한 번 더 = 취소. 비숍은 F로 떠오르고 공중에서 조준해 좌클릭으로 쏜다.

## 이펙트 (A 「잉크 테두리 만화 장난감」)

순서는 언제나 **경고 → 기다림 → 팍! → 남음 → 사라짐**, 1초 = 60장면으로 센다.

- **경고는 바닥의 진짜 체스판 칸(1.5 m)**: 퀸은 검기 줄 4칸, 룩은 두 자리 칸, 비숍·나이트는 떨어질 곳 한 칸, 폰은 앞 두 칸, 킹은 손 닿는 원 둘레의 작은 칸 24개(시계처럼 3박자로 켜짐). **보는 사람 기준 색**: 내 것 크림, 우리 편 청록, 적 빨강 + 흐르는 사선 줄무늬. 특별한 기물은 칸을 자기 색(킹 에메랄드, 퀸 금, 룩 주황, 비숍 보라, 나이트 하늘)으로 채우고 보는 사람 기준 테두리를 두른다. 준비 동안 차오르고 **마지막 6장면에 꽉 참** → 실행 순간 2장면 하얗게 → 6장면 안에 사라짐. 퀸 조준 중의 흐린 줄은 퀸 본인 화면에만, 적은 준비 동작부터 본다.
- **맞으면** 몸이 2장면 흰색 → 2장면 때린 기물의 색. 충격 고리(흰 속 + 색 + 잉크)가 맞은 방향을 향하되 카메라 쪽으로 반쯤 돌아본다(옆에서 보면 선처럼 보여서). 둥근 물방울 3~5개가 밀린 쪽으로만. 멈춤 약 2~3 · 중 4 · 강 5장면(시험장에서는 게임 전체가 멈춤, 실제로는 두 기물만), 흔들림 0.04 / 0.08 / 0.12~0.16 m.
- **넘어지면** 누운 자리에 때린 기물 색의 **잡힌 칸**(1.1 → 1.0, 30장면 유지, 15장면에 사라짐) + 바닥 잉크 고리 + 크림 먼지 4개 + 몸 찌그러짐. 별·글자·숫자·튀는 조각·마법진·빛 기둥 없음.
- 킹: 금 홀(에메랄드 왕관 머리) → 에메랄드 물결(70%를 처음 40% 시간에) + 물결 끝을 타는 연기 뭉치 → 호위 받은 아군 발밑에 에메랄드·금 고리(끝나기 0.6초 전 세 번 깜빡). 호위로 버티면 에메랄드 막음 고리와 작은 찌그러짐.
- 퀸: 금 손잡이 흰 칼(잉크 테두리)이 손에 나타나고 준비 동안 칼날을 따라 흰 광이 미끄러짐 → 앞에서 금 초승달 휘두르기 → 금 초승달 검기가 줄을 따라 날아가며 바닥에 금 띠 → 벽이면 금 충격 고리와 먼지.
- 룩: 고른 아군 발밑 고리 + 두 칸 + 날아갈 호의 점선(막히면 회색) → 요청하면 아군 칸 둘레에 시계가 참 → 수락하면 두 칸이 함정문(어두운 구멍 + 호두나무 테)으로 열리고 **두 색 리본 아치**(룩 주황 반, 아군 색 반)가 양끝에서 자라남 → 내려앉은 칸이 각자 색으로 찍힘.
- 비숍: 45° 돌린 보라 마름모 칸 위에 떠오름(바닥에 남색 그림자 마름모, 보라 고리 두 개가 몸을 타고 오름, 0.25초마다 보라 방울이 떨어짐) → 보라 점선 호와 떨어질 칸 → 보라 띠를 두른 만화 돌 → X자 막대 두 개(흰 속·보라·잉크)가 6장면에 자라남 + 회보라 먼지 → 내려올 때 칸이 세 번 깜빡이고 연기로 터짐.
- 나이트: 떨어질 곳에 도는 **말굽 표식**(흰 속·하늘·남색 잉크, 내려올수록 작아짐) + 한 칸 → 발밑 흰 고리와 바람 뭉치 → 날아가는 동안 바람 리본 → 착지 바람 뭉치 고리 + 말굽 자국 → 납작해진 적은 하늘색 고리·물방울.
- 폰: 앞 두 칸(아주 짧게 차오름) → 떠나는 칸이 팀 색으로 찍힘(크림 테) + 발뒤꿈치 먼지 → 낮게 가속하는 동안 뒤로 쐐기 속도선 3개 → 부딪힌 적은 작은 고리. 몸을 낮추는 동안 몸 모양도 12% 낮아지고 조금 넓어짐.
