# 기물 컨셉을 잡기 위한 조사 (2026-11-26, 2차 기획)

사용자(11-26): "이번에는 조금 다른 방식으로 접근할꺼야. 각 기물의 컨셉부터 먼저 제대로 잡아보려 해. 그것도 각 기물당 1개만 정하지 말고, 여러개 설정해보고, 각각의 컨셉에 맞게 스킬들 2~5가지정도 구상해보고 그렇게 쭉 나온것들 중 가장 괜찮은것들을 골라보려고 해. 우선 컨셉부터 정해야 하는데, 이것도 마찬가지로 조사 먼저 진행해줘. 체스 각 기물별 유저들에게 느껴지는 이미지는 이미 했는데, 각 기물만의 플레이스타일, 전략적인 강점, 실제 중세 모티브, 강력함 등등... 내가 떠오른건 이정도인데 난 어떤걸 조사하면 좋을지 잘 못찾은거 같아. 그냥 너가 알아서 필요한것들 조사해줘."

사용자(같은 말에서): "스킬의 난이도? 맞춰야 하는 실력? 같은거도 각 기물마다 컨셉에 맞게 다 다르게 하면 어떨까? 예를들어 비숍은 맞추기 어려운 대신 더 강력해서 고수 유저들이 잘 다루고,, 룩은 쉽고 강력하지만 예측이 잘되서 초보자들이 자주 쓰는 그런식으로"

## 1. 무엇을 조사했나

컨셉은 "이 기물은 어떤 놈인가"에 대한 답이다. 답이 여럿 나오도록 여섯 갈래로 봤다.

| # | 갈래 | 컨셉에 주는 것 | 어디서 |
|---|---|---|---|
| 1 | **실제 모티브** (그 말이 본뜬 사람과 물건, 옛 이름들) | 그림과 소품. 지금과 전혀 다른 모습의 컨셉(비숍은 코끼리였다, 룩은 전차였다) | 위키백과, 루이스 체스 말, 체솔리스의 책 |
| 2 | **플레이스타일과 전략적 강점** | 스킬이 하는 일(멀리서, 뛰어넘어, 곧게) | [기물 성격표](CHESS_PIECE_CHARACTER.md), 위키백과 |
| 3 | **힘** (값, 닿는 칸 수, 혼자 할 수 있는 일) | 스킬의 크기와 등급 조합 | 위키백과, 성격표 |
| 4 | **다루기 난이도** (초보와 고수가 그 말을 어떻게 느끼나) | 스킬의 난이도(사용자의 새 생각) | 체스닷컴, 리체스 블로그, 나무위키 |
| 5 | **다른 게임의 선례** (체스 말을 캐릭터로 만든 게임들) | 남들이 잡은 컨셉, 피할 것 | FPS Chess, 컵헤드, 배틀 체스 |
| 6 | 유저들의 이미지와 밈 | 이름과 웃음 | 이미 했다: [커뮤니티 조사](CHESS_PIECE_COMMUNITY_IMAGE.md) |

## 2. 기물별

### ♟ 폰

| 갈래 | 찾은 것 |
|---|---|
| 실제 모티브 | **걸어 다니는 병사.** 이름은 "보병"을 뜻하는 옛말에서 왔다. 독일과 북유럽에서는 **농부**라고 부른다: 전쟁 때 끌려 나온 평민이 보병이었다. 태국에서는 값싼 조개 돈이다. 1300년쯤의 체스 책(체솔리스)은 폰 여덟에 **평민의 직업**을 하나씩 붙였다: 농부, 대장장이, 서기, 상인, 의사, 여관 주인, 성문지기, 건달 겸 심부름꾼 |
| 플레이스타일 | 앞으로만 간다. 한 번 나가면 못 돌아온다. 폰들이 선 모양이 판의 성격을 정하고 다른 말들의 길을 정한다. 서로 지켜 주면 단단하고 혼자면 표적이다 |
| 전략적 강점 | 싼 값이 무기다(폰이 노리면 퀸도 달아난다). 통과한 폰 하나가 상대 말 전부를 묶는다. 내주고 시간을 얻는다(갬빗). 끝줄에서 승격한다 |
| 힘 | 1점, 여덟 개. 노리는 칸은 둘뿐이다. 끝줄에 닿으면 9점짜리가 된다 |
| 다루기 난이도 | 움직임은 가장 쉽다. 그런데 폰 수는 되돌릴 수 없어서 고수도 어려워한다. 배우기 쉽고 잘 쓰기 어렵다 |
| 다른 게임 | FPS Chess: 정찰병. 머스킷과 달리기, 분신 폰을 불러낸다("폰은 수가 많을수록 세다"). 컵헤드: 머리 없는 폰 여덟이 천장에서 떨어져 뛰어다닌다(떼) |

### ♞ 나이트

| 갈래 | 찾은 것 |
|---|---|
| 실제 모티브 | **말 탄 기병.** 체스 말 가운데 움직임이 가장 오래됐고 한 번도 바뀌지 않았다. 옛 체스 말(루이스, 샤를마뉴)에서는 말 머리가 아니라 말 탄 기사다. 독일어로는 "뛰는 자". 중세의 기사: 마상 창 시합, 종자, 문장, 갑옷 |
| 플레이스타일 | 가까운 거리에서 싸운다. 남을 뛰어넘는다. 어디를 노리는지 읽기 어렵다. 좋은 자리 하나에 박혀 있을 때 가장 세다 |
| 전략적 강점 | 포크(둘을 한꺼번에). 나이트의 공격은 사이를 막을 수 없다. 말이 빽빽한 판에서 세다 |
| 힘 | 3점. 판 가운데서는 8칸, 가장자리에서는 4칸, 구석에서는 2칸을 노린다. 가장자리에서는 비숍에게 갇히기도 한다. 혼자서는 메이트를 못 한다 |
| 다루기 난이도 | 움직임이 가장 헷갈린다(세계 챔피언도 헷갈리기 쉽다고 했다). 초보는 나이트 포크에 가장 자주 당한다 |
| 다른 게임 | FPS Chess: 활(따라가는 화살)과 짧은 돌진. 컵헤드: 칼싸움 결투, 헐떡일 때가 허점이다. 배틀 체스: 영화 속 흑기사 패러디 |

### ♝ 비숍

| 갈래 | 찾은 것 |
|---|---|
| 실제 모티브 | **원래는 코끼리**였다: 대각선으로 두 칸을 뛰어넘는 약한 말. 1200년쯤 지금처럼 멀리 가게 됐다. 13세기 스페인 책에는 같은 움직임의 말이 **악어**로 나온다. 나라마다 이름이 다르다: 기수(이탈리아), **광대**(프랑스: 머리의 홈을 광대 모자로 봤다), **궁수**(옛 영어), **전령 · 달리는 사람**(독일과 북유럽), 미치광이(루마니아). 영어로 주교가 된 것은 16세기다. 주교(bishop)의 어원은 **"지켜보는 사람"**이다. 머리의 홈은 주교의 모자이고, 코끼리의 엄니라는 설도 있다. 루이스 체스 말의 비숍은 굽은 지팡이와 책을 들었다. 왕과 여왕 곁에 서는 조언자다 |
| 플레이스타일 | 멀리서 겨눈다. 한 수에 판 끝까지 간다. 길이 뚫려 있어야 산다. 평생 한 색 칸만 다닌다(판의 절반) |
| 전략적 강점 | 핀과 스큐어(두 말을 한 줄에 꿰어 얼린다). 구석에 앉아 긴 대각선을 겨눈다(피앙케토). 둘이 짝이 되면 값이 오른다 |
| 힘 | 3점. 13칸까지 노린다. 혼자서는 메이트를 못 한다 |
| 다루기 난이도 | 초보는 비숍을 나이트보다 낮게 본다. 비숍 쌍을 살리려면 실력이 꽤 있어야 한다. 멀리 보는 눈이 있어야 쓰는, 고수의 말이다 |
| 다른 게임 | FPS Chess: 산탄총, 성스러운 수류탄(나나 적을 띄운다), 활강. 컵헤드: 떠다니는 머리. 촛불을 다 꺼야 약점이 드러난다. 둘레에 향로가 떠다닌다 |

### ♜ 룩

| 갈래 | 찾은 것 |
|---|---|
| 실제 모티브 | 이름은 페르시아어 **전차**에서 왔다. 페르시아 전차는 옆면을 성벽처럼 꾸며 **"움직이는 작은 요새"**로 보였고 전장의 공포였다. 유럽에서 탑이 됐다(16세기 그림에는 **코끼리 등에 얹힌 탑**으로 나온다). 러시아와 태국에서는 **배**다. 인도에서는 코끼리라고도 부른다. 전설의 큰 새 로크와 이름이 같다. 옛 이름은 탑, 후작, 백작. 루이스 체스 말의 룩은 방패와 칼을 든 **보초**이고, 그중 몇은 방패를 물어뜯는 **광전사**다. "성"이라고 부르면 틀린 이름이라고들 한다 |
| 플레이스타일 | 가로세로로 멀리 간다. 처음에는 구석에 갇혀 가장 늦게 싸움에 끼고, 줄이 열릴수록 세진다 |
| 전략적 강점 | 줄 하나를 통째로 막는 벽이 된다. 킹을 지킨다(캐슬링). 통과한 폰을 뒤에서 민다. 끝판의 주인이다 |
| 힘 | 5점. 어디에 있든 14칸을 노린다(구석에서도 힘이 같다). 킹과 둘이서 메이트를 한다 |
| 다루기 난이도 | 움직임이 가장 단순하다(더하기 모양). 다루기 쉽다. 대신 길이 열려야 하고, 어디로 올지 뻔하다 |
| 다른 게임 | FPS Chess: 저격총, 갈고리, 벽 세우기. 컵헤드: 도끼를 가는 사형집행인. 머리들을 굴려 보낸다. 배틀 체스: 돌 괴물로 변한다 |

### ♛ 퀸

| 갈래 | 찾은 것 |
|---|---|
| 실제 모티브 | **원래는 왕의 재상(책사)**이었다: 대각선으로 한 칸만 가는 약한 말. 997년쯤부터 여왕이라고 불렸다. 15세기 말 스페인에서 지금의 힘을 얻었고(이사벨 여왕 때), 그때의 체스를 "미친 여왕의 체스"라고 불렀다. 이름: 귀부인(스페인, 이탈리아, 프랑스), 러시아에서는 지금도 재상, 옛 러시아에서는 **할멈**, **아마존**이라고도 했다. 루이스 체스 말의 퀸은 왕좌에 앉아 **손을 뺨에 대고** 있다(시름, 놀람, 못마땅함으로 읽는다). 중세에는 "퀸을 잃으면 판에 값진 것이 없다"고 했다 |
| 플레이스타일 | 룩과 비숍을 합친 말이다. 가장 빠르고 가장 멀리 닿는다. 공격을 이끈다 |
| 전략적 강점 | 한 수로 떨어진 두 곳을 노린다. 혼자 체크를 이어 간다. 던지면 가장 화려하다(퀸 희생) |
| 힘 | 9점. 27칸까지 노린다 |
| 다루기 난이도 | 초보가 가장 좋아하고 가장 먼저 꺼낸다. 그리고 날려 먹는다. 쓰기는 쉬운데 실수의 값이 가장 크다 |
| 다른 게임 | FPS Chess: 자동소총과 비행, 체력이 가장 많다. 공략 글이 "전통대로 가장 세다, 약하게 해야 한다"고 적었다. 컵헤드: 높은 곳에서 대포와 사자상을 쏟아낸다 |

## 3. 스킬의 난이도를 기물마다 다르게 (사용자의 생각에 대한 답)

**좋은 생각이다.** 체스가 원래 그렇다.

| 기물 | 체스에서 | 우리 게임에 옮기면 |
|---|---|---|
| ♜ 룩 | 움직임이 가장 단순하다. 곧고 뻔하다 | **쉽다.** 누르면 크게 된다. 대신 어디로 올지 보인다 |
| ♛ 퀸 | 초보가 가장 좋아한다. 쓰기 쉬운데 잃으면 끝이다 | **쉽다 ~ 보통.** 무엇이든 되는데, 헛치거나 넘어지면 크게 잃는다 |
| ♟ 폰 | 움직임은 쉽고, 잘 쓰기는 어렵다 | **쉽다.** 가까이서 작게 자주. 잘 쓰면 끈질기다 |
| ♞ 나이트 | 움직임이 가장 헷갈린다. 포크는 자리를 잡아야 나온다 | **어렵다.** 때와 자리를 맞춰야 한다 |
| ♝ 비숍 | 멀리 보는 눈이 있어야 한다. 고수의 말 | **가장 어렵다.** 멀리서 겨눠 맞혀야 한다 |

다른 게임도 그렇게 한다. 마리오 카트는 가벼운 캐릭터는 다루기 쉽고 무거운 캐릭터는 최고 속도가 높다. FPS Chess도 기물마다 무기와 역할이 달라 손에 맞는 기물이 갈린다.

**조심할 것 셋**

1. **"어려운 대신 더 강력"은 평균이 아니라 천장으로.** 어려운 기물이 평균까지 세면 고수만 이긴다. 쉬운 기물은 못 써도 반은 하고(바닥이 높다), 어려운 기물은 잘 쓰면 크게 터진다(천장이 높다). 이러면 "밸런스는 맞아야 해"와 함께 간다.
2. **기물을 못 고를 수도 있다.** 승격으로 기물이 정해지면 초보가 비숍이 되기도 한다. 어려운 기물도 대충 눌렀을 때 뭔가는 되어야 한다.
3. **빗나가는 것도 웃겨야 한다.** 어려운 스킬은 자주 빗나간다. 빗나간 장면이 웃기면 어려워도 재미있다.

## 4. 조사에서 보인 컨셉의 씨앗

아직 컨셉이 아니다. 조사에서 "이 기물은 이런 놈일 수도 있다"가 보인 곳을 이름만 적었다. 다음에 여기서 컨셉을 여럿 세운다.

| 기물 | 씨앗 |
|---|---|
| ♟ 폰 | 창과 방패의 보병 · 끌려 나온 농부(쇠스랑, 도리깨) · 직업 여덟(대장장이, 여관 주인, 의사, 성문지기…) · 떼로 다니는 졸병 · 승격을 꿈꾸는 졸병 · 얌체(앙파상, 갬빗) |
| ♞ 나이트 | 말(동물) · 마상 창 시합의 기사 · 뛰는 자 · 어디로 튈지 모르는 장난꾸러기 · 포크의 악몽 |
| ♝ 비숍 | 주교(성직자의 소품) · 저격수와 궁수 · 코끼리(원래 모습) · 광대 · 전령(달리는 사람) · 지켜보는 사람 · 악어 |
| ♜ 룩 | 성채(성벽, 성문, 해자) · 움직이는 요새(전차) · 방패를 물어뜯는 광전사 · 배 · 코끼리 등에 얹힌 탑 · 우직한 직진("더 루크") |
| ♛ 퀸 | 도도한 여왕 · 책사(원래 재상) · 미친 여왕(갑자기 가장 세진 말) · 손을 뺨에 댄 시름 많은 여왕 · 헌납의 아이콘 · 아마존(싸우는 여왕) |

## 5. 못 한 것

- 중세 전쟁사(보병 전술, 공성전, 기사의 실제 싸움)는 따로 찾아 읽지 않았다. 위키백과의 체스 말 항목에 나온 만큼만 적었다.
- 다루기 난이도는 "초보는 이 말을 가장 어려워한다"고 딱 잘라 말한 자료를 찾지 못했다. 체스닷컴과 리체스의 글, 나무위키를 모아 내가 읽은 것이다.
- 컵헤드의 보스는 공략 글의 요약으로만 봤고, 배틀 체스는 위키백과로만 봤다.
- 체솔리스의 폰 직업 목록은 판본마다 조금 다르다(서기 대신 직조공이 나오는 것도 있다).
