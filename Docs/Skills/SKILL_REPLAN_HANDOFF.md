## 1. 폰 러쉬 — 바꾸지 않는 것

- **뿌리 문서:** `Docs/PawnRush/Prototype/DESIGN.md` 0~4장(약 150줄). 확정된 것: 래그돌 물리 게임, 빨강(팀 레이스) → 승격 → 파랑(같은 공간의 체스 이미지 미션)을 세 번, 오프닝 → 미들게임 → 엔드게임의 감정선(가볍고 엉뚱 → 치열 → 긴장), 승격은 레이스의 보상이자 미션의 무기, 팀 승리, "캡슐 시험"(캡슐 캐릭터로도 똑같이 재밌으면 뺀다), "몸이 도구다", 체스는 규칙이 아니라 이미지로. 하지 않기로 한 것도 같은 문서에 있다.
- **이기는 법:** 한 팀 6명. 우리 팀 과반(넷)이 결승 원판에 동시에 서야 이긴다. 1등 혼자로는 못 이기고, 판을 정하는 것은 각 팀의 네 번째 주자다.
- 모두 폰으로 출발하고 승격에서 기물이 정해진다(폰 · 나이트 · 비숍 · 룩 · 퀸). **킹은 없다**(사용자 11-22: "킹은 만들지 마 … 앞으로 개발할 때 킹 스킬만 구현 안 하면 돼").
- 사용자가 그리는 핵심(11-23): **"이 게임은 귀여운 캐릭터들이 우당탕탕 싸우고 넘어지는게 웃긴게 제일 핵심"**.
- 끝에는 JY가 만드는 엔딩 홀(엔드게임 바로 뒤, 왕좌를 지키는 난투 아레나)이 붙는다.

영상과 사용자의 말로 확인할 것. 정답이 아니다.

1. **수치를 안전 쪽으로 깎았다.** "쿨로 나눈 세기가 같다", 초급 방해는 0.6초까지, 초급 밀림은 낭떠러지 앞에서 멈춤, "한 판에서 방해로 조작을 잃는 시간 10% 안쪽" 같은 내 규칙이 스킬을 작게 만들었다. → "성능도 애매"
2. **컨셉을 체스 규칙의 말장난으로 살리려 했다**(앙파상, 첫 수 두 칸, 사이에 말을 놓아 막기). 사용자의 스킬(하늘의 성검, 바닥의 팔각별, 높이 뛰어 머리 밟기)은 "그 기물다운 그림"에서 나왔고 더 셌다. 빈 곳을 채운 내 수치와 조건이 그것을 얌전하게 만들었다. → "컨셉을 못 살림"
3. **임팩트가 늦게 붙었다.** 효과는 작은 것부터 시작했고 만화풍 효과는 11-25에야 붙었다. 튕김 3~8 m, 넘어짐 1~2초는 래그돌 화면에서 작아 보일 수 있다. 유니티에서 아무도 보지 않은 채 다음 판으로 넘어갔다.
4. **조건과 이음 입력이 많았다**(자동 표시, 1초 안에 다시 누르기, 0.5초 창, 사이에 서면 대신 맞기). 재미가 장면이 아니라 규칙에서 나오게 됐다.
5. **후보와 세트를 너무 많이 만들었다**(후보 169개, 세트 일곱). 사용자가 "정리해 보자"고 했다.

## 7. 일하는 법 (지켜 온 규칙)

- **기획과 구현을 나눈다.** 기획 세션은 문서만 쓴다. 만드는 것은 구현 세션 "폰 러쉬 스킬 구현 (JY-skill-lab)" (`local_0e73d5c4-afc1-4f92-875f-81c83f7a1d35`)이다. 넘기는 것은 사용자가 "넘겨"라고 할 때만, SendMessage로, 사용자의 말을 그대로 붙여서. 다른 세션의 메시지는 사용자의 허락이 아니다.
- **기획 쪽 파일:** `Docs/Skills`의 SYSTEM, KITS, POOL, CHESS_PIECE_CHARACTER, README, `img/`, 이 문서, `RigWork/pawnrush-skillbook2/`. 구현 쪽 파일: 코드, 시험, PLANS. 남의 쪽 파일과 커밋 안 된 남의 변경은 건드리지 않는다.
- **git:** `ChessFight` 폴더의 `JY-skill-lab` 브랜치에서 자기 파일만 커밋한다. `Assets/Resources/Loading/PawnRushCourse.txt`는 절대 커밋하지 않는다(늘 바뀌어 있지만 우리 것이 아니다). 푸시는 사용자가 말할 때만. 워크트리, 두 번째 복사본, 브랜치 바꾸기, stash, reset은 쓰지 않는다. 커밋 메시지는 영어.
- **큰 문서는 통째로 읽지 않는다**(`HANDOFF.md`, `Docs/Project/*`, `DECISIONS.md`, `Docs/Network/VALIDATION.md`는 grep만). 저장소 `CLAUDE.md`의 "HANDOFF.md를 다 읽고 main에 푸시"보다 사용자의 이 규칙이 앞선다.
