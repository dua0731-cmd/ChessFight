## 5. 연출과 이펙트

사용자: "이펙트랑 연출은 스킬 구현 채팅에 알아서 맡기니 좀 별로라서, 그것까지도 너가 구상해서 넘겨줘". 그래서 이 장은 스킬마다 박자대로 무엇이 보이고 들리는지를 적었다. **이 장을 그대로 만든다.** 못 만들거나 줄인 것이 있으면 무엇을 왜 뺐는지 적어 둔다. 수치는 첫 시험값이다.

바탕은 전에 정한 것이다: 사용자(11-24) "폰러쉬라는 게임에 맞게 웃기고 코믹한 느낌이되 너무 허접하진 않고 퀄리티 좋게". 3인칭 그대로, 카메라의 방향은 건드리지 않는다. 세상의 슬로모션은 없다. 있는 부품을 쓴다: 잉크 테두리 장난감 부품(`SkillInkKit`), 만화 층(`PawnRushSkillFx.Comic.cs`), 꼰 밧줄 재질(`Skill Rope`), 편자 로고, 먼지(`Skill Dust`).

### 5.1 지금 것에서 본 것 (내가 모음 그림을 보고 적었다)

`Logs/FxSheets`의 앙파상!(Trip4), 성벽!(WallUp), 하이점프 & 내려찍기(HighStomp), 볼라스(Bolas)를 봤다. 사용자의 말은 "좀 별로"뿐이고, 아래는 내가 본 까닭이다.

- **가늘고 작다.** 볼라스의 줄, 하이점프의 빨간 선과 표적 고리는 조금만 멀어도 안 보인다.
- **준비가 없다.** 누르면 바로 나가서, 무엇이 올지 읽히지 않고 힘이 실리지 않는다.
- **맞는 순간이 작다.** 흰 펑이 머리만 하고 몸의 찌그러짐이 약하다.
- **물건이 통짜다.** 성벽이 회갈색 상자다. 벽돌도 줄눈도 없다. 설 때도 사라질 때도 연출이 없다.
- **글자가 겹친다.** "콰당!"과 말풍선 "홀리 헬!"이 한자리에 겹쳐 뜬다.
- **뒷맛이 없다.** 맞고 나면 그냥 끝난다. 웃음은 맞은 뒤의 한 박자에서 난다.

### 5.2 공통 규칙

| 무엇 | 규칙 |

| 네 박자 | 스킬 하나는 준비(무엇이 올지 보인다) → 나감 → 맞음(가장 큰 그림) → 뒷맛(웃음이 남는다)으로 읽힌다. 5.3의 표가 이 차례다 |
| 크기 | 카메라에서 15 m 떨어져도 읽혀야 한다. 던지는 물건은 실제보다 1.5~2배로 그린다. 줄은 굵기 6 cm부터, 머리 위 표시는 지름 0.7 m부터다 |

| 말풍선 | 표에 "말풍선"이라고 적은 것만. 말한 기물의 머리 위에 0.8초 |
| 색의 뜻 | 적에게 위험한 것(맞을 자리, 과녁, 적이 세운 벽의 밑동)은 빨강에 흐르는 사선 줄무늬다. 우리 편 것은 청록 테두리, 내 것은 크림이다. 비숍의 빛은 금빛이 도는 흰색, 룩의 돌은 모래색 벽돌, 폰의 밧줄은 실제 마 밧줄 색, 나이트의 편자는 광택 검정 테두리에 어두운 금색이다 |
| 먼지와 구름 | 매끈한 만화 구름과 지금의 먼지를 쓴다. 양은 적게, 대신 크게 한두 덩이 |
| 사라질 때 | 물건은 그냥 꺼지지 않는다. 끝나기 1초 전에 세 번 깜빡이거나 떨고, 무너지거나 흩어지며 0.3~0.5초에 사라진다 |
| 카메라 | 방향은 건드리지 않는다. 흔들림, 거리, 화각만 쓴다. 성벽 짓기는 사용자가 정한 대로 카메라가 분신을 따라간다 |
| 걸린 사람의 화면 | 표에 적은 것만. 화면을 가리지 않는다(가장자리와 위쪽만 쓴다) |

조금 움직이는 것(뒷발차기의 2 m, 퇴장!의 3 m, 히힝!과 스콜라 메이트처럼 가까운 적에게 붙는 것)은 "너무"는 아니라고 읽어 그대로 둔다. 사용자가 표 아래에서 이 말도 봤다.

### 9.2 돌아오기의 연출 (땅속 헤엄 · 더 루우욱! · 착석!이 함께 쓴다)

거대화의 "돌아올 자리"와 같은 표시를 쓴다. 웃음은 고무줄에 당겨져 끌려오는 몸이다.

| 박자 | 보이는 것 | 소리 |
|---|---|---|
| 쓰는 순간 | 쓴 자리 바닥에 그 기물 모양의 빛나는 발자국과 고리가 찍힌다(우리 편에게는 청록, 적에게는 빨강). 돌아올 때까지 남는다 | "찍" |
| 돌아가기 직전 (0.2초) | 몸과 발자국 사이에 고무줄 같은 빛줄이 팽팽하게 나타난다. 몸이 줄 쪽으로 살짝 끌린다 | "끼이익" 고무줄이 늘어나는 소리 |
| 돌아옴 (0.4초) | 몸이 길게 늘어나며 발자국으로 휙 날아온다. 오는 길에는 맞지도 않고 누구를 치지도 않는다 | "띠용—" |
| 내려섬 | 발자국 위에 내려서며 한 번 출렁인다. 발자국과 고리가 사라진다 | "뽁" |

- 더 루우욱!: 거꾸로 박힌 채 버둥거리다가, 줄에 당겨져 "뽕" 하고 뽑혀 날아온다.
- 착석!: 왕좌에 앉은 채로 줄에 당겨진다. 왕좌는 그 자리에서 펑 사라지고 퀸만 날아와 내려선다.
- 땅속 헤엄: 솟구친 몸이 공중에서 줄에 당겨져 날아와, 들어갔던 구멍 자리에 내려선다.
- 쓴 자리가 없어졌으면(무너진 발판 등) 가장 가까운 딛을 곳으로 돌아온다(구현 세션이 정한다).

### 9.3 낭떠러지 앞에서 멈추기의 연출 (직진! · 수평 룩)

끝에서 한 발로 서서 두 팔을 휘저으며 버둥대다(0.4초, 말풍선 "어, 어, 어!") 겨우 선다. 발끝에서 돌 부스러기가 아래로 떨어진다. 멈추는 것은 스킬의 움직임뿐이다: 버둥대는 동안 밀리면 떨어진다.

### 9.4 표적이 없을 때 (포크! · 엉덩방아)

나가지 않고 쿨도 쓰지 않는다(벽돌, 설교와 같다). 스킬 칸이 한 번 흔들리고 "삑" 소리가 난다.
