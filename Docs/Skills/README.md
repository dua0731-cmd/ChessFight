## 여는 법과 조작

1. Unity → **ChessFight → Pawn Rush → Open Skill Test** → Play.
2. 화면 **왼쪽 창**에서 기물을 고른다: **폰(기본) · 퀸 · 룩 · 비숍 · 나이트**. 키로는 **Z ◀ / X ▶**. 버튼을 누르려면 Esc로 마우스를 푼다.
3. **F = 모든 스킬** (R74 승규 님: "전체 키는 F로 통일(임시)". 그 전 G. 이 씬에서는 F가 랩의 상호작용(종·레버·갈고리 끊기)을 하지 않는다 = `LabGame.InteractKeyOff`). **룩·비숍은 F로 조준을 시작하고 좌클릭으로 쓴다**(우클릭 또는 F 한 번 더 = 취소). 조준 중 좌클릭은 다이빙, 우클릭은 잡기를 하지 않는다. **V = 룩 시험용으로 더미 4명을 내 앞 3.5 m에 2×2로 뭉쳐 세움**(룩을 고르면 저절로 한 번, 창 버튼도 있음). **시험용 쿨타임은 모든 기물 2초**(R72, Inspector `Pawn Rush Skill Bed → Skills → Test Cooldown` = 0이면 기획 쿨 v0.1로 돌아감, 자동 시험 도구는 기획 쿨로 잰다). 다른 키는 랩 원래 그대로다: E(폰 갈고리·나이트 L자 도약 = 퀸 오브 더 힐 것), Q, 좌클릭 다이빙, 우클릭 잡기, Tab 튜닝, R 리스폰, T 슬로 모션, F4 자유 카메라, F9 [7] 시험대.
