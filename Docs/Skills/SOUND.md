### 1차와 다른 점

| | 1차 R101 | 2차 R107 |

| 동전 소리 | 검사 없음(지금 검사로 보면 105개 중 23개가 걸림: 글로켄슈필·풍경·반짝이·금속 체스말 등) | 설명에 종·차임·딩·글로켄·짤랑·반짝이·금속을 쓰지 않음(`spec_v2.py`가 검사) + 만든 소리마다 `coin.py` 검사 |

### 동전 울림 검사 (`Tools/Sfx/PawnRushSkills/coin.py`)

1.8~12 kHz에서 한 음이 그 대역의 중간값보다 20 dB 넘게 솟아 0.09초 넘게 같은 높이(3 % 안)로 울리고, 그 소리의 가장 큰 곳보다 26 dB 안쪽이면 "울림"으로 본다. R104에서 뺀 퀸 오브 더 힐 넘어짐 소리(`Down`, 7.7 kHz 근처 짤랑 0.15초)가 걸리는 것으로 기준을 맞췄다. 나무 딱 소리의 1.2~1.6 kHz 울림은 걸리지 않게 아래쪽을 1.8 kHz로 잡았다.

### 만든 법과 다시 만든 것

- 새로 만든 소리 99개(ElevenLabs 작업판 「폰 러쉬 스킬 효과음 기물별 (R105)」 — 번호 확인 전에 붙인 이름, 기록 번호는 R107) + 1차에서 같은 재료로 만든 17개를 그대로 씀: 룩 C 번개 전체, 나이트 B·C의 도약·공중·착지·밟기, 퀸 A 전체와 B 예고, 폰 D 밀침.
- **19개를 다시 만듦**(거의 무음 또는 높은 울림). 처음 설명 → 고친 설명은 `spec_v2.py`의 `RETAKEN`과 `P`. 처음 설명: 폰 B 밀침 "Soft rubber toy bumping hard into another rubber toy, low rubbery bonk", 폰 B 부축 "…squeezed and let go, low squeak sliding upward"(삑 소리가 2.1 kHz로 울림), 폰 D 걸음·밀침, 폰 E 걸음·밀침·넘어뜨림, 룩 B 조준 칸·돌진(돌 긁힘이 3.4 kHz로 끽)·맞음, 룩 D 잠금(2.2 kHz 울림), 비숍 C 꽂힘·걸림·팽팽한 줄, 비숍 D 꽂힘·팽팽한 줄, 비숍 E 꽂힘, 나이트 D 착지·밟기.
- **잘라 쓴 것 8개** (`DERIVE`): 짧게 한 번 치는 북 소리는 다시 만들어도 계속 거의 무음이었다(1차 E 나이트 낮은 북도 다섯 번). 그래서 같은 벌의 긴 소리 앞부분을 잘라 음 높이만 바꿨다 — 폰 E 걸음·밀침(부축의 탐탐), 룩 E 조준 칸·잠금·맞음(벽에 쾅의 타이코), 룩 B 조준 칸(잠금의 돌, 조약돌 딸깍이 4.2 kHz로 울림), 비숍 C 꽂힘(걸림의 고무줄 탁), 나이트 D 착지(도약의 용수철).
- **높은 소리 살짝 깎은 것 5개** (`LOWPASS`): 룩 B 돌진 2.5 kHz, 비숍 E 사라짐 3 kHz, 비숍 B 사라짐 1.6 kHz, 비숍 C 팽팽한 줄 1.8 kHz, 비숍 D 팽팽한 줄 1.5 kHz.
- 남은 약한 울림: 룩 A 돌진(만화 휘슬, 가장 큰 곳보다 20 dB 작음), 비숍 C 무장·비숍 B 사라짐(2 kHz 근처 0.1초). 들어 보고 거슬리면 바꾼다.
- 생성 118번(99 + 다시 19), 약 1,190크레딧.
- 다듬기·붙이기는 1차와 같다(`build.py`). `SPEC=spec_v2`로 돌리면 `gen2/` → `out2/`.

## 다섯 방향

다섯 기물 모두 같은 다섯 방향이다. 한 방향으로 통일해도 되고 스킬마다 달리 골라도 된다.

| | 방향 | 소리 | 퀸 오브 더 힐 시안(R100)에서는 |
|---|---|---|---|
| A | 나무 체스말 | 진짜 나무 체스말과 체스판: 딱·탁·또르르, 나무가 구르고 쏟아짐 | B |
| B | 만화 장난감 | 용수철·삑삑이·슬라이드 휘슬·뿅 | C |
| C | 묵직한 쾅 | 짧고 묵직하게 박히는 액션 타격: 퍽·쾅·쿵 | D |
| D | 이펙트 그대로 | 화면 이펙트(디자인 A)와 같은 재료: 퀸 불 폭발, 룩 번개, 나이트 바람, 비숍 마법 줄, 폰 잉크 도장 | 없음 |
| E | 장난감 악기 | 기물마다 악기와 음: 폰 마림바, 퀸 글로켄슈필, 룩 팀파니, 비숍 하프, 나이트 우드블록 | 없음 |

듣기 전 추천은 **D**다. 화면의 불·번개·바람·마법 줄과 같은 재료라 소리만 들어도 어떤 스킬인지 알기 쉽다. 체스 느낌을 더 살리려면 A, 더 장난스럽게 하려면 B.

## 순간 21개와 시간표

퀸 오브 더 힐 시안(R100)은 스킬마다 가장 중요한 한 순간만 만들었다. 이 시안은 **스킬의 순간마다 따로** 만들고 실제 타이밍에 맞춰 이어 붙였다. 그래서 페이지의 ▶는 스킬 한 번을 실제 속도로 들려주고, 작은 버튼은 그 순간만 들려준다. 시간표 수치는 [DESIGN](DESIGN.md)과 `PawnRushSkillParams`(지금 값)에서 가져왔다.

| 기물 | 순간(소리 하나씩) | 시안 시간표(초) | 나중에 Unity에서 소리를 낼 곳 |
|---|---|---|---|
| 폰 | 걸음 · 밀침 · 넘어뜨림 · 부축 | 걸음 0 → 두 번째 걸음 0.45(3반음 높게) → 곧게 밀침 0.58 · 걸음 1.50 → 대각선 넘어뜨림 1.62 · 걸음 2.70 → 부축 2.82 | `PawnStep` · `PawnHit`(곧게/대각선) · `PawnHelp` |
| 퀸 | 예고 · 터짐 | F 0.30 → 0.35초 예고(끝 0.38초만) → 터짐 0.65 | 예고 시작(스킬 단계) · `QueenBlast`(`QueenHit`은 터짐에 포함) |
| 룩 | 조준 칸 · 잠금 · 돌진 · 맞음 · 벽에 쾅 | 칸 4개 0·0.1·0.2·0.3(점점 높게) → 좌클릭 잠금 0.80 → 돌진 1.10(0.75초) → 맞음 1.22·1.34·1.46(한 음씩 높게) → 4번째 멈춤 1.58(낮게) · 잠금 2.60 → 돌진 2.90 → 벽에 쾅 3.20 | 조준·잠금(스킬 단계) · 돌진 시작 · `RookHit`·`RookStop` · `RookWall`(바리케이드 `RookBarricade`·내리꽂기 `RookSlam`은 아직 따로 안 만듦) |
| 비숍 | 던짐 · 꽂힘 · 무장 · 걸림 · 사라짐 | 좌클릭 던짐 0.30 → 꽂힘 0.62 → 무장 1.12 → 걸려 늘어남 2.00 → 넘어뜨림 2.35 → 사라짐 3.50 | 발사 · `BishopWire` · 무장(0.5초 뒤) · `BishopTrip` · 줄이 사라질 때 |
| 나이트 | 도약 · 공중 당 · 착지 · 머리 밟기 · 어지러움 | 도약 0 → 공중 F 0.75 → 착지 1.40 · 도약 2.20 → F 머리로 2.70(공중 당 2반음 높게) → 머리 밟기 3.00 → 어지러움 3.10 → 옆 착지 3.30 | `KnightLeap` · `KnightTurn`/`KnightHome` · `KnightLand` · `KnightStomp` · 어지러움(1.2초) |

이어 붙이는 법: 소리마다 "시작"(그 순간에 시작), "가장 큰 곳"(맞는 순간에 가장 큰 소리), "끝"(그 순간에 끝남) 중 하나로 맞춘다. 같은 소리를 여러 번 쓸 때는 음 높이만 바꾼다(룩 맞음 1·2·3, 폰 두 번째 걸음).

## 만든 법

1. 순간 21개 × 방향 5개 = 105개 설명문(영어, 소리 하나씩·짧고 구체적으로 — 모델 안내: 여러 소리를 한 문장에 넣으면 섞여 흐려짐). 길이는 순간마다 0.5~2초, 설명 따르기(prompt influence) 0.5, 한 번씩 생성.
2. 한꺼번에 보내면 ElevenLabs가 "요청이 너무 많다"(429)며 거절한다. 3~4개씩, 30초~1분 간격으로 나눠 보냈다.
3. 결과는 서명된 주소(2시간)로 받는 mp3(44.1 kHz 스테레오)다. 상태 조회 결과가 길면 대화 도구가 파일로 저장해 주므로, 그 파일에서 주소를 뽑아 내려받았다(한 번에 세션 20개를 물어야 파일로 저장된다).
4. 모음 판(파형 + 소리 그림)으로 105개를 모두 봤다. **9개가 거의 무음이거나 너무 작았다**(A 룩 조준 칸·나이트 착지·나이트 머리 밟기·비숍 무장, C 폰 밀침·비숍 사라짐, D 폰 밀침, E 나이트 착지·나이트 머리 밟기). 설명을 더 또렷하게 고쳐 다시 만들었다. E 나이트 착지는 "낮은 북" 설명으로 다섯 번 모두 작게 나와 "우드블록 똑"(1초)으로 바꿨고, E 머리 밟기는 큰 소리가 끝에서 잘려 0.8초로 늘렸다. 버린 것까지 모두 121번 생성, 약 970크레딧.
5. 다듬기(`Tools/Sfx/PawnRushSkills/build.py`): 모노, 38 Hz 아래 제거(한 소리에 느린 치우침이 있었음), 앞뒤 빈 곳 자르기, 한 번만 나야 하는 순간(걸음·조준 칸·맞음·밀침·공중 당)은 첫 소리만 남기기(모델이 걸음 하나에 "휙휙휙" 세 번을 주기도 함), 순간마다 크기 맞추기, 시간표에 붙인 뒤 다시 크기 맞추고 -1 dBFS로 막기.
6. 페이지: 스킬마다 Unity 녹화(R90)에서 자른 장면 4~6장, 시간표(재생 위치·지나간 순간 표시), A~E 다섯 줄(▶ 전체, 순간 버튼, "이걸로"), 아래 줄에 고른 것 요약과 복사. 소리 130개(데모 25 + 순간 105)는 `sfx-data.js` 하나에 담았다.

`Tools/Sfx/PawnRushSkills/README.md`. 설명문·순간·시간표는 `spec.py` 한 곳에 있다. ElevenLabs 생성은 대화의 ElevenLabs 커넥터로 하고(노드 id는 `nodes.json`, 최종 소리를 만든 세션 id는 `sessions.json`), 내려받은 mp3를 `gen/`에 두면 `build.py` → `page.py`가 데모와 페이지를 다시 만든다. mp3와 장면 그림은 저장소에 넣지 않았다(페이지와 ElevenLabs 작업판에 있음).
