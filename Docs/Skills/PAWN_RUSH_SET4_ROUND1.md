## 1. 먼저 할 일: 스킬트리(K 창)

사용자의 말은 0장의 마지막 줄이다. 아래는 내 풀이이고, 창을 아는 구현 세션이 더 맞게 고쳐도 된다.

| 무엇 | 어떻게 |
|---|---|
| 바로 보이는 것 | K 창을 열면 스킬 목록에 이 문서의 서른다섯 개만 기물별로 보인다 |
| "폐기된 스킬" 탭 | 새로 만든다. 지금까지 있던 스킬을 모두 이 탭으로 옮긴다: 3판, 그 전의 세트들, 원래 폰 러쉬 스킬, 옛 궁극기, 승규 님의 스킬. 지우지는 않는다. 이 탭에서 칸에 넣어 볼 수는 있다 |
| 세트 줄 | 옛 세트 버튼(3판, 3안-b …)도 폐기 탭 안으로 옮긴다 |
| 고쳐 쓰는 것 | 뒷발차기, 성수병, 직진!(직선 돌파)처럼 있던 것을 고쳐 쓰는 스킬은 새 목록에 고친 모습으로 두고, 옛 모습은 폐기 탭에 둔다 |
| 이름이 겹치는 것 | 새 "퀸 희생!!"과 옛 궁극기 "퀸 희생"은 다른 스킬이다 |
| 칸 | 지금처럼 어느 스킬이든 어느 기물의 어느 칸에나 넣을 수 있다. 게임에 들어갈 칸은 기물마다 2개다 |

## 2. 공통 규칙 (첫 시험값)

| 무엇 | 값 |
|---|---|
| 키 | 스킬은 들어 있는 칸의 키 하나로 쓴다(F 또는 E). 다시 누르기가 있는 스킬도 같은 키다 |
| 겨눔 | "겨눈 적"은 그 스킬의 거리 안에서 조준점(화면 가운데)에 가장 가까운 적이다. "겨눈 곳"은 조준점이 가리키는 바닥이다. "겨눈 쪽"은 조준점의 방향이다 |
| 조작 | 쓰는 동안에도 걷고 뛴다. 표에 "조작 없음"이라고 적은 때만 끊긴다. 카메라는 돌리지 않는다 |
| 누가 맞나 | 적만 맞고 적만 걸린다 |
| 등급과 쿨 | 초급 6초 · 중급 12초 · 상급 30초. 맞혀도 쿨은 돌아오지 않는다. 표적이 있어야 나가는 스킬은 표적이 없으면 나가지 않고 쿨도 쓰지 않는다 |
| 날리기 세 가지 | **살짝** = 2 m, 높이 0.5 m · **뻥** = 5 m, 높이 2 m · **쾅** = 8 m, 높이 3.5 m. 3판의 밀치기(`S3Push`)는 0.6 m쯤밖에 안 떠서 낮고 짧았다. 이번에는 높이 띄운다 |
| 넘어짐 | 날아가 떨어지면 물리대로 넘어졌다가 일어난다. 이것은 CC가 아니다 |
| 낭떠러지 | 지키지 않는다. 날아가다 떨어지면 떨어진다(3판 초급의 "낭떠러지 앞 멈춤"은 쓰지 않는다) |
| CC | 한 사람에게 한 번에 하나다. 새 CC가 걸리면 앞의 것은 끝난다. 걸린 채로 넘어지고 날아가는 것은 그대로 일어난다 |
| 말풍선 | 표에 따옴표로 적은 말("홀리 헬!", "댕~", "체크!")은 맞은 적이나 쓴 사람 머리 위에 만화 말풍선으로 띄운다 |
| 이번 범위가 아닌 것 | 칸이 열리는 때(1코스 · 2코스의 미니게임 장소), 승격, 폰의 처음 스킬, 지원 스킬. 킹은 만들지 않는다 |

## 3. 방해(CC) 일곱 가지

걸려도 조작은 살아 있다(콰당!만 빼고). 길이는 4장의 표에 스킬마다 적었다.

| CC | 몸의 변화 (첫 시험값) | 보이는 것 | 지금 코드 |
|---|---|---|---|
| **콰당!** | 넘어진 채 조작이 없다 | 대자로 뻗는다. 머리 위에 별, X 눈 | 넘어진 채 두는 것이 있다 |
| **헤롱헤롱** | 가려는 방향이 좌우로 흔들린다(±35도, 1.2초에 한 번 오간다). 밀리는 거리가 1.5배다 | 머리 위에 별이 돌고 눈이 뱅글거린다 | 비슷한 것이 있다 |
| **지침** | 스태미나가 0이 되고 차지 않는다: 달리기와 다이빙을 못 한다. 점프 높이 60% | 땀방울, 내민 혀, 처진 어깨 | 스태미나가 있다 |
| **무거움** | 이동 속도 60%, 점프 높이 50%, 밀리는 거리 절반 | 몸이 무쇠 색이 되고 걸음마다 쿵. 얹힌 물건(돌, 왕관)이 보인다 | 있다(`HeavyLeft`) |
| **묶임** | 깡충형: 걷기와 달리기를 못 하고, 점프 키로 1.2 m씩 깡충 뛴다(0.5초에 한 번). 제자리형: 발이 박혀 못 간다(팔은 쓴다) | 다리의 밧줄, 구덩이, 옷핀 | 제자리형은 있다. 깡충형은 새로 만든다 |
| **미끌미끌** | 빨라지기, 멈추기, 꺾기가 20%만 듣는다 | 발밑에 거품과 물기 | 성수 웅덩이의 미끄러짐이 있다. 몸에 붙는 상태로 만든다 |
| **쪼꼬미** | 몸 크기 50%, 이동 속도 70%, 점프 높이 60%, 밀리는 거리 2배 | 작아진 몸, 높은 목소리 | 없다 |

## 6. 알아 둘 것

- **비슷한 것끼리 견주려고 함께 만든다.** 룩의 직진!과 잔디깎이, 더 루우욱!과 넘어간다~!, 비숍의 성수병과 먹구름, 향로와 설교. 사용자가 해 보고 하나씩 남긴다.
- **폰과 비숍에는 내 이동을 돕는 스킬이 없다.** 사용자가 그렇게 골랐다.
- **세기의 균형은 아직 맞추지 않았다.** 등급별 쿨만 같게 두었다. 해 보고 맞춘다.
- 온라인 동기화를 어디까지 할지는 구현 세션이 정한다.
