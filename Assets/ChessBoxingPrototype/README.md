# ChessFight — 체스복싱 조작 프로토타입

R161 · 2026-10-25 · Unity 6000.3.11f1 · `JY-chessboxing_testgame` · 싱글플레이 플레이어 대 AI

**상태: 피격 물리와 기본 전투를 실제 Play에서 확인한 손맛 초안. 사용자 체감·완성도는 미확인.** 사용자가 제시한 27.1초 참고 영상에서 맞으면 몸이 흔들리고 연타에 균형을 잃는 반응을 이번 목표로 삼았다. 가드·회피와 기존 A 방식 손 선택, 가까운 어깨 카메라·몸 반투명, 이동 범위가 제한된 글러브는 유지한다. 잡기는 이번 범위에 포함하지 않는다.

## 실행

Unity에서 Play를 종료한 뒤 **ChessFight → Chess Boxing Prototype → Create or Open Test Scene**을 선택한다. 전용 씬 `Scenes/ChessBoxingPrototype.unity`에서 Play를 누르고 Game 뷰를 클릭한다. 2초 뒤 시작한다. 스크립트 변경은 Play를 종료한 상태에서 적용한다.

## 조작

| 입력 | 동작 |
|---|---|
| W / A·D / S | 상대에게 전진 / 상대 주위를 좌우 이동 / 후퇴. 옆 이동은 전진의 80%, 후퇴는 70% |
| 마우스 왼쪽 / 오른쪽 | A 방식: 왼손 / 오른손 선택. 중앙에서는 직전 손 유지 |
| 마우스 위 / 아래 | 머리 높이 / 몸통 펀치 선택. 화면 아래에 현재 손·높이 표시 |
| 좌클릭 | 선택한 펀치를 즉시 시작. 누른 순간 손·높이를 확정 |
| 우클릭 유지 | 마우스 방향으로 글러브 가드. 누른 채 방향 전환 가능 |
| Space | 왼쪽·오른쪽 슬립 / 위 더킹 / 아래 풀백 |
| Tab | AI 대전 ↔ 정지 연습 상대 |
| R / Esc | 재시작 / 일시정지·계속 |
| J / L | 펀치 / 가드 보조키 |

마우스 입력은 화면 중앙의 고정 기준으로 읽는다. 카메라가 이동해도 화면 속 캐릭터를 새 입력 원점으로 사용하지 않는다. 상단 더킹은 현재 시험하는 설계안이다. 플레이어의 훅·어퍼컷 선택 입력은 아직 없다. AI의 어퍼컷은 하단 방어 확인에 사용한다.

## 이번 구현 범위

- 조금 물러난 3인칭 카메라. 마우스 좌우에 따라 어깨 쪽이 바뀌고, 위·아래에 따라 높이와 몸통 구도가 달라진다. 화각은 일정하게 유지한다.
- 상대의 머리·몸통을 가릴 때 플레이어 몸 전체가 반투명해진다. 글러브는 불투명하게 유지한다.
- Pawn의 몸·얼굴·다리·발 리깅을 유지한다. runtime 복제 메시에서 팔·손을 제거하고, 정해진 범위 안에서 움직이는 큰 글러브를 별도로 표시한다.
- 양손 기본 펀치, 방향 가드, 슬립·더킹·풀백, 스태미나, 간단한 AI. 가드는 글러브 접촉 경로를 기준으로 처리한다.
- 기존 다운·기상·KO·재시작 흐름을 유지한다. 실제 Play에서 다운→기상→서기와 기본 체력 100의 KO 흐름을 확인했다.

## R161: 피격 시 휘청임과 연타 다운

**상태: 피격 물리와 기본 전투를 실제 Play에서 확인한 손맛 초안. 사용자 체감·완성도는 미확인.** 사용자가 제시한 27.1초 참고 영상에서 맞으면 몸이 흔들리고 연타에 균형을 잃는 반응을 이번 목표로 삼았다. 가드·회피와 기존 A 방식 손 선택, 가까운 어깨 카메라·몸 반투명, 이동 범위가 제한된 글러브는 유지한다. 잡기는 이번 범위에 포함하지 않는다.

피격 직후 잠시 몸의 앞뒤·좌우 균형 복원력을 낮추고, 몸·머리에 서로 다른 충격을 주어 부위가 뒤늦게 따라오도록 했다. 상대를 향하는 좌우 회전은 유지한다. 쉬는 글러브는 접촉에 더 잘 밀리고, 공격·가드 중인 글러브는 버티도록 조정했다. 머리를 실제로 밀었는데 타격 판정은 빠지던 경우를 줄이도록 글러브 충돌도 전투 판정에 전달한다. 마지막 피격 후 1.1초 동안 연타 누적이 회복되지 않아, 이어 맞으면 다운으로 연결된다. 무릎까지 독립적으로 꺾이는 전신 래그돌 구현은 아니며 발은 현재 시각 자세로 처리한다.

실제 Play의 단타 대조에서 기존 몸 기울기 0°가 수정 후 최대 17.91°로 바뀌었다. 최신 검사에서 머리는 월드 기준 최대 약 0.222m 움직였고 약 0.42~0.44초 뒤 자세가 안정됐으며, 단타만으로 넘어지지는 않았다. 연타 검사는 공격 접수 4회·적중 4회 뒤 체력 64에서 다운→기상→서기를 확인했다. 머리/몸통 양손 펀치 4/4 적중, 하단 가드 어퍼컷 4회 차단·칩 피해 4, KO는 14회 시도·12회 적중 뒤 13.76초에 체력 0이었다. AI는 10초 동안 7회 적중해 플레이어 체력이 37이 됐다.

글러브의 접촉 반응 조정 뒤 선회 검사는 방향 오차 약 2°·4회 모두 적중을 확인했다. 슬립 중 몸통도 낮추도록 보정한 최종 회피 대조는 **무회피 피해 9 대비 좌우 슬립·더킹·풀백 모두 피해 0·가드 0**이었다. 다음은 사람이 직접 느끼는 휘청임·회복 시점·연타 다운과 시야를 확인할 단계다. 전신 다리 물리, 장시간 안정성·플레이어 빌드는 미검증이다. 상세 수치와 로그 검사 범위는 `Docs/Network/VALIDATION.md` R161에 기록한다. 공유 물리·폰 러쉬·프리팹·설정은 수정하지 않으며 커밋·푸시는 하지 않았다.

## 작업 경계와 파일

코드·생성물은 `Assets/ChessBoxingPrototype` 안에서 분리한다. 기존 폰 러쉬·공유 물리·공유 프리팹·ProjectSettings·다른 팀원의 변경사항은 수정 범위 밖이다. `Generated` 원본은 유지하며 메시·재질 변형은 runtime 사본에만 적용한다. 전역 시간·중력·입력 설정·Build Settings는 바꾸지 않는다.

`CBControl`은 손·방향 선택, `CBMatch`는 입력·경기·HUD, `CBOrbitCamera`는 시점·가림 판단, `CBFighter`는 전용 물리·전투, `CBGloveContact`는 실제 글러브 충돌 전달, `CBPawnVisual`은 팔 제거·글러브·몸 투명화, `CBBrain`은 오프라인 AI를 담당한다. `CBSettings`에서 전용 설정을 조정한다. Editor의 명시적 Play 검사 기록은 `Library/ChessBoxingR160`에 저장한다.

잡기·패대기·탄성 로프·의자·체스 라운드·네트워크·로비 연결은 이번 범위에 포함하지 않는다. 링 로프는 현재 고정된 시각 표시이고 경계는 단단한 임시 벽이다.
