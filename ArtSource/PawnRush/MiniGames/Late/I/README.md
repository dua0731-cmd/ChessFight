# I · 국왕 침실 아트 (R511)

G 행차 회랑(R504)·H 체스 홀(R510)과 같은 3단계(윗궁) 방이다. 다른 방과 같은 순서로 만든다:
컨셉 시트 → 재질 견본 → 재사용 목록 → Tripo용 에셋 시트 → 사용자 Tripo FBX 손질 → Unity 연결.
불빛(촛불·등)과 흔들리는 천(커튼·깃발)은 코드로 붙인다(11-07 규칙). 다른 방에 있는 모델·재질은 그대로 가져다 쓴다(11-08 규칙).
