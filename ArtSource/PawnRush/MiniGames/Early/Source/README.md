사용자가 준 AI 생성 원본이다. 고치지 않고 보관하고, 손질한 결과는 따로 만든다. `R502_*` 파일(성탑·돌 블록·권양기·성문)은 C 도개교 작업이 쓴다([재질 견본 README](../Materials/README.md)). 이 문서는 D 쇠살문 누각(R505) 것을 적는다.

## R505 · D 캡스턴 (`R505_CapstanBase_RoyalWooden.fbx`)

사용자가 "회전 에셋"으로 준 FBX(원래 이름 `Royal Wooden Base`). 쇠띠 두른 나무 드럼, 리벳 띠 2줄, 나무 뚜껑(왕관 없음), 금 끝 막대 4개, 바닥 받침 8개.

| 항목 | 가져온 그대로 (Blender 5.2) |
|---|---|
| 크기 | 1.00 × 1.00 × 높이 0.47 (1 m 상자에 맞춰 줄여짐) |
| 메시 | 1개, 떨어진 조각 576개 |
| 삼각형 | 100,000 |
| 텍스처 | 베이스 컬러 4096², 노멀 2048² (FBX 안에 포함). 거칠기·AO 없음 |
| 회전축 | 위에서 본 상자 가운데 |
| 막대 | 대각선(45°) 방향, 반지름 0.21~0.67(금 끝 0.50~), 높이 0.029~0.139(가운데 기준) |
| 드럼 | 몸통 반지름 약 0.24, 받침 포함 0.33 |

게임 숫자(`MgCapstan`): 드럼 지름 1.4 m·높이 1.8 m(충돌), 뚜껑 지름 1.8 m·1.8~2.1 m(충돌 없음), 막대 반지름 0.75~3.0 m·높이 0.40~0.62 m(폰 허리)·폭 0.2 m, 0·90·180·270°, 막대만 돌고 드럼은 서 있음.

검사: 한 배율로는 안 맞는다(드럼 기준이면 막대가 2 m까지만 뻗고 허리보다 높음, 막대 기준이면 막대가 1 m 넘게 높고 0.45 m 굵기). 그래서 나눠서 맞췄다.

## R505 · D 팀 쇠살문 (`R505_TeamGate_StoneArchPortcullis.fbx`)

사용자가 준 FBX(원래 이름 `Stone Arch Portcullis`). **두 부품이 옆으로 떨어져 들어 있다:** 왼쪽 크림 돌 아치(나무 들보·받침 포함), 오른쪽 둥근 머리 쇠살문(리벳 테·창살·아래 뾰족 끝 5개).

| 항목 | 가져온 그대로 |
|---|---|
| 크기 | 폭 1.00 × 깊이 0.15 × 높이 0.48 |
| 메시 | 1개, 떨어진 조각 3,918개, **500,000 삼각형** |
| 텍스처 | 베이스 컬러 4096², 노멀 2048² (포함) |
| 아치 | x −0.50~0.075(폭 0.575), 높이 0.484, 깊이 0.146. 문 구멍 폭 0.3125 × 높이 0.406 (폭:높이 = 1 : 1.30) |
| 쇠살문 | x 0.11~0.50(폭 0.39), 높이 0.416(뾰족 끝 0.044 포함), 두께 약 0.05 |

게임 숫자: 팀 문(`TeamGate`)은 스테이션(구간 x ±12, z 4) 안 x −2~2·높이 0~4.6·z 23~23.4 → **구간 z 27~27.4, 통로 한가운데**. 완료하면 1.2초에 4.6 m 올라 위 벽(`Gate pocket cover`, 높이 6~10.2) 속으로 들어가고, D는 진척만큼 0.4 m까지 들린다(`SetLift`). 앞 아치(`Team portal front`)는 구간 z 23.8, 구멍 폭 4.5 × 높이 5.8(폭:높이 1 : 1.29), 뒤 아치 z 29.9, 통로 벽 z 24~30.

검사 결과(AI 관찰, Unity 미반영):
- **아치는 한 배율로 맞는다.** 구멍 4.5 m 기준 14.4배: 구멍 높이 5.85 m(게임 5.8), 전체 폭 8.3 m·높이 7.0 m·깊이 2.1 m. 앞 아치 자리(z 23.8)에 두고 게임 아치 그림만 끈다. 바깥 기둥(x 14.25~16.1)은 옆 벽 앞, **안쪽 기둥(x 7.9~9.75)은 중앙 성문 날개(x 6.35~9.93, 앞면 z 24.34) 앞에 겹쳐 선다** — 성문 날개 일부가 가려진다. 기둥만 가로로 좁히거나 그대로 둘지 결정 필요.
- **쇠살문은 팀 문에 붙인다.** 폭 4.4 m 기준 약 11.4배: 높이 4.7 m(뾰족 끝 0.5 m 포함, 게임 문 4.6 m), 두께 0.55 m. 게임 문(`TeamGate`)에 붙이면 진척 0.4 m 들림과 완료 4.6 m 상승을 그대로 따라간다. 머리가 둥글어서 직사각형 게임 문보다 위 모서리가 비지만, 통로(구멍 높이 5.8 m) 안이라 보이는 틈은 없다.
- 50만 삼각형 → 아치 약 12,000 + 쇠살문 약 6,000으로 줄인다. 두 팀이 같은 모델을 쓴다.
- 리벳이 밝은 구리·금빛이다. 장식이므로 무광 황동 쪽으로 낮춘다. 쇠는 이미 짙은 쇠라 그대로 둔다.
